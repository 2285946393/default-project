# 生成展示页

把一整个目录的 NovelAI 出图，自动生成「第N轮」风格的展示页。

## 为什么做这个

你 `pages/` 里有 39 个 `第N轮-xxx.html`，每个都是手写的 HTML：图片路径、说明、seed 全手工填。
出完图要拼页面很费时间，而且容易漏。

这个脚本直接从 PNG 里读参数，一次生成。

## 用法

```bash
cd "C:\Users\有花无实\Documents\Default Project"

# 最简：目录名当标题，输出到 pages/目录名.html
python tools\生成展示页.py "assets/卡提希娅专场-第36轮"

# 指定标题和输出
python tools\生成展示页.py "assets/V5双人" --title "第40轮 · V5双人" --out "pages/第40轮-V5双人.html"
```

## 会自动提取的信息

从每张 PNG 的 NovelAI 参数里读：

| 信息 | 来源 |
|---|---|
| 尺寸 | 图片本身 |
| seed | `Comment` JSON 的 `seed` |
| 模型 | `model_name`（显示成 `NAI V5`） |
| 画师 | prompt 里的 `artist:xxx`，自动去重 |

## 自动排除的文件

这些是处理过程中的衍生物，不会被当成成品列出来：

- `xxx_clean.png`（上传器剥参数生成的）
- `xxx_masked.png`（打码工具导出的）
- `xxx_打码.png`（旧命名）

## 分组

按文件名第一个下划线前的部分分组。比如：

```
B1_cartethyia_seated.png   → B1 组
B2_cartethyia_wet.png      → B2 组
B3_towel_slip.png          → B3 组
```

目录里只有一组时不显示分组标题，多组时自动加 `<h2>`。

## 生成后要手动补的

脚本只能读机器能读的信息。这些还得你自己写：

- **副标题的说明**（比如「六张全是卡提希娅 · Z2 配方」）
- **顶部的 `.box` 提示块**（改法说明、踩坑记录）
- **每张图的描述文字**（`figcaption span` 里的内容）

脚本生成的是骨架，你打开 HTML 往里填文字就行。样式和现有页面完全一致。
