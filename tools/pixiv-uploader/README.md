# Pixiv 半自动上传器

给「NovelAI 出图 → 手动打码 → 传 Pixiv」这个流程做的小工具。

## ⚠️ 最重要的一件事：Pixiv 会保留你的生成参数

实测结论（用带参数的原图真传后下载回来验证）：

```
上传前：PNG 有 6 个 tEXt 块，Comment 里是完整 prompt + seed
Pixiv 上：原样保留，6 个 tEXt 全在
下载回来：seed、prompt、uc 全都能读出来
```

**谁下载你的原图，谁就能看到你的完整提示词和种子。**

所以工具**默认在上传前自动剥掉参数**：生成一份 `_clean` 副本去上传，原图一个字都不动。

剥参数的方式是**直接删 PNG 的 tEXt 块**（不重新编码），所以：

- 像素和原图**完全一致**（已用 numpy 逐像素比对验证）
- 画质零损失
- 文件只小几 KB

不想剥的时候，把界面里「上传前清除生成参数」的勾去掉就行。

## 参数怎么留 —— 不用另写 md

**不用让 AI 出图时额外写 md，也不要重命名。**

NovelAI 的 PNG 里 `Comment` 字段是一个完整 JSON：

| 字段 | 内容 |
|---|---|
| `prompt` | 正向提示词（带 `{{}}` `[[]]` `1.2::` 权重） |
| `uc` | 负面提示词 |
| `seed` | 种子 |
| `steps` / `scale` / `sampler` | 步数 / CFG / 采样器 |
| `model_name` | 模型名 |

工具直接读这个，所以：

- **永远和图片对得上** —— 不存在 md 和图片错位的问题
- **不需要重命名** —— 文件名不用动，工具内部用绝对路径记
- **画师名自动提取** —— `artist:xxx` 会被单独挑出来排在标签最前面

参数会存进 `_上传清单.json` 留底，随时点「看参数」能查。

## 为什么是「半自动」

因为你的流程里**打码必须手动**：

```
① 选图 → 读 PNG 参数 → 存进 _上传清单.json
② 你去打码 → 回来点「匹配打码图」→ 打码版挂到对应记录上
③ 点「开始上传」→ 浏览器逐张填好
```

另外，打码工具重存图片时通常会把元数据洗掉，所以参数必须在打码**之前**就抢下来存进清单。

|---|---|
| `/upload/` | ❌ 404 |
| `/illustration/upload` | ❌ 404 |

## 实测确认的字段选择器

在你的账号登录态下逐个验证过：

| 字段 | 选择器 | 说明 |
|---|---|---|
| 文件 | `input[type="file"]` | |
| 标题 | `input[name="title"]` | |
| 说明 | `textarea[name="comment"]` | |
| 标签 | `input[placeholder="标签"]` | **必填**，上限 10 个 |
| 年龄限制 | `input[name="x_restrict"]` | `general` / `r18` / `r18g` |
| 性描写 | `input[name="sexual"]` | **必填**，`false`=无 / `true`=有 |
| AI 生成 | `input[name="ai_type"]` | **必填**，`aiGenerated` |
| 公开范围 | `input[name="restrict"]` | `public` / `private` |

### 三个坑，都踩过了

1. **标签必须逐字输入再按回车**。用 `fill()` 直接塞值 React 收不到，计数还是 0/10。要用 `type()`。
2. **「性描写」必须选**，不选投稿按钮永远是灰的。而且这一行**要等年龄限制选完才渲染出来**。
3. **页面顶部导航栏也有一个「投稿」按钮**，那个永远可点。要点的是表单**底部**那个，用 y 坐标区分。点错了会以为提交成功，其实什么都没发生。

## 用法

双击 `启动.bat`。

### 单张图
1. 「选单张图…」挑一张
2. 检查标题/标签，勾好 R-18 / 性描写 / 不公开
3. 点「保存修改」
4. 去打码，回来「选打码图…」指定
5. 「开始上传」

### 一整个文件夹
1. 「选文件夹…」选目录
2. 工具扫出所有图，读参数，自动填标题和标签
3. 逐条检查修改
4. 去打码，把打码图存回**同一个文件夹**，文件名以原文件名开头即可
5. 回来点「匹配打码图」
6. 「开始上传」

### 首次上传要登录
第一次点「开始上传」会弹出浏览器：

1. 手动登录 Pixiv
2. 登录完**别关窗口**，程序会自动继续
3. 登录态存进 `pixiv_auth.json`，以后免登录

## 几个实际要注意的

- **每张之间会随机等 35~75 秒**。Pixiv 有频率风控，连发会锁号。
- **上传中途崩了不会丢进度**。每传完一张就写清单，重开继续传剩下的。
- **「跳过此张」**：某张不想传，标成 skipped，不会被上传。
- **R-18 和性描写是两件事**：R-18 是年龄分级，性描写是内容申报，都要如实选。
- **代理**：如果你的网络需要代理访问 Pixiv，`uploader.py` 里的 `launch()` 要加 `proxy` 参数。

## 文件说明

| 文件 | 作用 |
|---|---|
| `启动.bat` | 双击这个 |
| `gui.py` | 界面 |
| `core.py` | 参数提取 + 去参数 + 清单管理 |
| `uploader.py` | 浏览器自动化上传 |
| `_上传清单.json` | 存在图片目录里，可手工编辑 |
| `pixiv_auth.json` | 登录态，**别外传** |

## 如果上传页改版了

`uploader.py` 顶部的 `SEL_*` 都是多候选列表，改版时按当前页面调整对应那一组就行。改版后如果某张卡住，浏览器会停在填好的页面上，你手动点一下投稿也能完成。
