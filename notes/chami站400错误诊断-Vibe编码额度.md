# chami 站 400 错误诊断 —— 根因是 Vibe 编码额度

> 2026-10-14 深夜。连续四次撞 400，最后定位到真因。
> **教训一句话：400 先看后台额度，别从 prompt 猜。**

---

## 一、真因（已确定）

后台写得很清楚：

```
Vibe编码次数  0    每日上限3次
```

**参考图在页面上还留着「✓ 已生成」的旧标记，但编码额度已经归 0。**
提交生成时服务端要校验参考图 → 校验失败 →
前端把这类失败统一显示成：

```
参数校验或生成失败: 请求失败: 400
```

---

## 二、我的误判（必须记录，别再犯）

| 我的猜测 | 怎么验证的 | 结论 |
|---|---|---|
| 数字权重 `35::` 太大，超上限 | 降到 `5::` 还是 400 | ❌ 不是 |
| 语法 `N::...::` 本站不支持 | 改用 `{}` 后仍 400 | ❌ **证据不足，未证实** |
| **参考图编码额度用尽** | 后台显示 `VIBE编码次数 0` | ✅ **真因** |

> ⚠️ **"数字权重不能用"这个结论没有验证过，别当事实用。**
> 本次 400 与权重无关，两件事必须分开。

---

## 三、解法

1. ★ **`.naiv4vibe` 文件可以直接拖进「氛围模式」** ——
   文件里自带 `encodings`（base64 二进制），**不需要重新编码、不消耗 Vibe 编码次数**。
   页面那行字就是证据：`点击或拖入图片 / .naiv4vibe / .json 文件`
2. **Vibe 编码每天只有 3 次**，次日重置。
3. **每日签到 +50 生图额度**（与 Vibe 编码是两条额度，别混）。

## 五、⛔ 危险按钮位置（重要更正）

**换 API Key 的「重新生成」在 Dashboard 主页右上角。**

而**绘图区的提交按钮**文案会在 `立即生成 / 再次生成 / 重新生成` 之间来回变
（正常 → 提交中 → 失败后），**它是安全的**。

**两者不要混淆** —— 之前把绘图区的按钮当成危险按钮，导致不敢点、白等。
