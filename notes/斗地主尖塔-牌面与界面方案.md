# 斗地主尖塔 — 牌面与界面方案

> 用户要求：「先做一个 1234 出牌。然后做杀戮尖塔版的牌型。就是**把所有斗地主的牌替换成杀戮尖塔的牌。两种。一种是让人快速上手。一种是更有意思。**」
> 界面要求：「只需杀戮尖塔可以选中的几个角色，然后以那种**坐着的姿势在一个桌子上面**就行了。
> 先简要地把**头像的位置**变动一下（一般玩家斗地主头像放在什么地方，人物模型放在什么地方）。**UI 优化我会让别人去做**。」
> 另：「**不用考虑怎么对玩家造成伤害，杀戮尖塔有现成的攻击 mod。**」

---

## 第 0 步：先做「1234 出牌」版（不做任何换皮）

**先把玩法跑通，再谈好看。**

用最朴素的数字牌（3~10 / J / Q / K / A / 2 / 大小王），把这条链跑通：

```
发牌 → 定地主 → 轮流出牌 / 要不起 → 有人出完 → 判胜
```

这一步的产出是**一个能玩的斗地主**（穿尖塔的壳，但牌面还是数字）。
规则内核已经就绪（`projects/dou-spire-rules/`，跟权威实现 27471 条零差异），
接下来补的是**叫地主 + 轮次指针 + 界面 + 电脑出牌**。

**为什么先做这步**：换皮随时能做，玩法错了要返工。先把"能不能玩"验掉。

---

## 第 1 版：快速上手版（"数字还在，只是穿了尖塔的皮"）

### 核心思路
**点数保留、规则一个字不改**，玩家零学习成本。只是把牌面画成杀戮尖塔的卡。

### 牌面长什么样
一张牌 = 一张尖塔风格的卡：

| 位置 | 内容 |
|---|---|
| 左上角 | 尖塔的**费用宝石**（画着点数，红/绿/蓝圆珠的样式） |
| 正中 | **大号点数**（3 / 4 / … / K / A / 2 / 小王 / 大王）——玩家扫一眼就知道大小 |
| 下方小字 | 尖塔里的**卡名**（给味道，不影响规则） |
| 边框颜色 | 尖塔的卡牌类型配色 |
| 卡背 | 尖塔的卡背（螺旋/尖塔剪影） |

### 花色 → 尖塔的四种卡牌类型（纯装饰，斗地主本来也不看花色）

| 花色 | 换成 |
|---|---|
| ♠ | **攻击**（红） |
| ♥ | **技能**（绿） |
| ♦ | **能力**（蓝） |
| ♣ | **诅咒**（紫） |

### 13 个点数 → 13 个"强度台阶"（名字只是装饰，大小永远看数字）

给每个点数配一个尖塔里由弱到强的名号，让牌有味道，但**玩家判断大小只看那个大数字**：

| 点数 | 名号（装饰用） |
|---|---|
| 3 | 打击 |
| 4 | 防御 |
| 5 | 毒刺 |
| 6 | 铁斩波 |
| 7 | 顺劈斩 |
| 8 | 燃烧之血 |
| 9 | 旋风斩 |
| 10 | 极限防御 |
| J | 恶魔形态 |
| Q | 腐化 |
| K | 完美打击 |
| A | 双发 |
| 2 | 屏障 |
| 小王 | **诅咒之钥** |
| 大王 | **觉醒** |

> 名字可以随便换，反正规则只看点数。**这一版的价值就是"不用学"。**

## 第 2 版：有意思版（"牌本身在讲尖塔的故事"）

### 核心思路
**点数换成尖塔的怪物**，玩家靠"我知道这个怪多强"来判断大小；
**牌型换成尖塔的机制名**，出牌时的播报也换。

### 13 个点数 → 13 个怪物（按"幕数 + 强弱"排，玩家凭直觉认大小）

| 点数 | 怪物 | 为什么排这儿 |
|---|---|---|
| 3 | 颚虫 | 第一幕最弱 |
| 4 | 酸虫 | 第一幕杂兵 |
| 5 | 小恶魔 | 第一幕杂兵 |
| 6 | 菌菇怪 | 第一幕杂兵 |
| 7 | 强盗 | 第一幕杂兵里最烦 |
| 8 | 哨卫 | 第一幕精英 |
| 9 | 双持刺客 | 第一幕精英 |
| 10 | 六火巨兽 | 第一幕 Boss |
| J | 青铜傀儡 | 第二幕精英 |
| Q | 书页守卫 | 第二幕 Boss |
| K | 时间吞噬者 | 第三幕 Boss |
| A | 觉醒者 | 第三幕最终 Boss |
| 2 | **心脏** | 真结局 Boss |
| 小王 | **腐化之心** | 比心脏更高的存在 |
| 大王 | **尖塔本身（Spire）** | 终极 |

> 风险（必须先说）：这一版**要玩家记得住 13 个怪的强弱**。
> 所以建议**牌面上仍然小字标着点数**，怪物是主角、数字是拐棍。
> 不然上手会懵 —— 这就是它和"快速上手版"的取舍。

### 牌型 → 尖塔机制（出牌时的称呼与播报）

| 斗地主牌型 | 尖塔版称呼 | 播报（举例） |
|---|---|---|
| 单张 | 打击 | "一记打击。" |
| 对子 | 双重施法 | "双发！" |
| 三张 | 能力牌 | "能力就绪。" |
| 三带一 | 召唤随从 | "带着随从上了。" |
| 三带二 | 精锐小队 | "精锐出动。" |
| 顺子 | **连击链** | "连击 ×5！" |
| 连对 | 双线连击 | "双线并进！" |
| 飞机 | 群体施法 | "群体施法！" |
| 四带二 | 遗物爆发 | "遗物共鸣！" |
| 炸弹 | **爆发** | "爆炸！" |
| 王炸 | **觉醒** | "它醒了。" |

> **数值完全不动**，只换称呼和播报 —— 这样"有意思"不会破坏斗地主本身的平衡。

### 可选加强（你先别急，等上面两版跑起来再说）
- 出"连击链"给一点屏幕震动 / 音效
- 出"觉醒（王炸）"时全屏白闪 + 专属音效
- 每局结束按"你打出了几次连击链 / 几次爆发"给个结算小称号

## 界面方案（按你的要求：只定位置，不做美化）

### 标准斗地主的位置惯例（拆的是通用做法，不是我瞎编）

| 东西 | 常规位置 |
|---|---|
| **自己的手牌** | 屏幕**最底部**，横排成一排 |
| **自己的头像/信息** | **左下角**（有的版本在底部中间偏左） |
| **左手玩家** | **左侧偏上**：头像 + 剩余张数 + 他刚出的牌 |
| **右手玩家** | **右侧偏上**：镜像 |
| **出牌区** | **桌面正中央**（最近打出的牌堆在这儿） |
| **底牌（3 张）** | **屏幕顶部中央**，叫地主前扣着、叫完翻开 |
| **轮到谁** | 那个座位高亮 / 头像描边发光 |

### 套到"杀戮尖塔角色围桌而坐"

```
┌──────────────────────────────────────────────┐
│        [底牌 3 张]        [倍数/分数]          │
│                                              │
│  ┌────────┐                        ┌────────┐ │
│  │左家头像│                        │右家头像│ │
│  │剩 12 张│                        │剩 15 张│ │
│  └────────┘                        └────────┘ │
│                                              │
│         ╭──────────────╮                     │
│    [左家]│   牌 桌 中 央  │[右家]              │
│    角色  │  （出牌区）   │ 角色               │
│   侧坐   ╰──────────────╯  侧坐              │
│                                              │
│            [自己角色·背影]                     │
│  ┌────────┐                                  │
│  │自己头像│  ← 手牌整排铺在最底部              │
│  └────────┘                                  │
└──────────────────────────────────────────────┘
```

| 位置 | 放什么 | 怎么摆 |
|---|---|---|
| 桌面中央偏下 | **牌桌**（八边形/椭圆木桌） | 尖塔篝火房那种质感 |
| 桌子**正下方** | **自己的角色** | **背对镜头**，只见背影和肩膀 |
| 桌子**左侧** | 左家角色 | 侧身，面朝右 |
| 桌子**右侧** | 右家角色 | 侧身，面朝左 |
| 屏幕四角 | **头像 + 剩余张数** | 左下自己 / 左上左家 / 右上右家 |
| 桌面中央 | 出牌区 | 左家出的牌略偏左、右家略偏右，一眼看出是谁出的 |
| 顶部中央 | 底牌 3 张 + 地主标识 | 叫地主后翻开 |
| 屏幕最底 | 自己的手牌 | 横排，扇形铺开 |

### 4 人 2v2 时怎么变

- 自己的角色仍在桌子**正下方**，**对家**坐到桌子**正上方**（也是背影）
- 左右两侧各一人 → 变成"四人围桌"
- 头像改到**四个角**：左下(自己) / 左上(左家) / 右上(右家) / 右下或左上偏内(对家)
- **队友描边一种颜色、对手另一种颜色**，一眼看出谁跟谁一队

### 交给做 UI 的人时要说清的三件事
1. **位置优先**：先把"谁坐哪、头像在哪、牌在哪、底牌在哪"摆对，美观后置。
2. **状态要能看出来**：轮到谁、谁是地主/哪队、各自剩几张 —— 这三个必须有明显反馈。
3. **手牌 17 张的排布**：原版战斗手牌只有 5 张，斗地主是 17~20 张。
   到实现时给你 2~3 个方案挑（扇形铺开 / 分两行 / 可横向滚动）。

## 顺序（建议）

1. **1234 出牌版**（纯数字，跑通玩法）← 现在该做这个
2. 界面按上面的位置摆上（能看就行）
3. **快速上手版**换皮（零学习成本）
4. **有意思版**换皮（怪物 + 机制名）
5. 电脑出牌 AI（先照 rlcard 那套朴素规则，见拆解笔记 §五）
