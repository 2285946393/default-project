# 尖塔任务 · 梗任务设计案

> 2026-09-22 夜。目的：把《杀戮尖塔2》社区的梗做成任务 + **非金币奖励**，塞进 quest-spire。
> 所有「二代有没有这个东西」都在这台机器的游戏文件里核对过（`ilspycmd` 反编译），不是猜的。

## 一、查证结果：素材有哪些

### 二代本体**有**的（能直接当奖励发）

| 东西 | 内部类型名 | 稀有度 | 效果 | 备注 |
|---|---|---|---|---|
| 锚 | `Relics.Anchor` | 普通 | 每场战斗开始获得 10 格挡 | 船三件套之一 |
| 角夹 | `Relics.HornCleat` | 罕见 | 格挡被清空时获得 14 格挡 | 船三件套之二 |
| 船长之轮 | `Relics.CaptainsWheel` | 稀有 | 格挡被清空时获得 18 格挡 | 船三件套之三 |
| **假锚** | `Relics.FakeAnchor` | **事件** | 每场战斗开始获得 **4** 格挡 | 官方中文名就叫 **「锚???」**，商场卖 50 块 |
| 化学X | `Relics.ChemicalX` | 商店 | X 费牌的 X 值 **+2** | 就是你说的「X 药」 |
| Claw | `Cards.Claw` | — | — | 已经在用了（爪爪爪） |

**关键笑点**：船三件套在二代是**整整齐齐全都在**的，但二代**没有**一代那个「修船」的后续。
也就是说——攒齐三件套以后，游戏什么都没给你。空着一个坑，正好让任务系统来填。

### 二代本体**没有**的

- **枯枝**（Dead Branch）：本体确实没有。但社区有人复刻了，中英文两边都有：
  [枯木枝干遗物 MOD（3DM）](https://dl.3dmgame.com/patch/386487.html)、
  [Dead Branch Mod（Nexus 1330）](https://www.nexusmods.com/slaythespire2/mods/1330)。
  → 说明「心心念念」是真的，而且**我们可以自己复刻一根**，不用依赖别人的 mod。

### 顺带发现

- 二代有 `CardType.Quest` / `CardRarity.Quest` —— **官方自己就有「任务卡」这个类别**。奖励做成任务卡是原生的味道。
- 5 个角色：铁甲战士 / 潜行者 / **故障机器人** / 亡灵法师 / 摄政王。
- X 费牌有干净的判定字段：`card.EnergyCost.CostsX`（bool），不用猜。

## 三、融合设计（5 组）

### ① 「船长的执念」— 三件零件拼成一艘船

- **条件**：本局同时拥有 锚 + 角夹 + 船长之轮。
- **奖励**：**一艘帆船**（「随身物」：战斗开始 +15 格挡；本场第一次格挡被清空时再 +20 格挡）。
- **笑点/爽点**：一代那艘破船在二代没人管，我们把坑填上——三件零件真的拼成一条船。
- **为什么成立**：二代三件都在、又没后续，这个坑本来就是空的。
- **⚠️ 实现方式（重要）**：船**不是遗物**，是挂在任务册上的永久效果 + 任务面板里的「随身物」一栏。
  原因见下面第七节：纯 dll mod 造不出带中文名的遗物。

### ①b 「锚???」怎么处理（原本想当奖励，放弃了）

「锚???」（`FakeAnchor`）是**假商人卖的假货**，不是船的一部分，所以**不当船的奖励**。
想用它的话得单独做一个「打假」方向的任务（见 ⑤）。

### ② 「枯枝还魂」— 把玩家最想要的补上

- **条件**：本局消耗 20 张牌。（现有「破釜沉舟」是消耗 12 张给钱，这个是它的进阶版）
- **奖励**：一根**枯枝**（「随身物」）：之后每消耗一张牌，随机一张牌加入手牌。
- **笑点**：本体没有、玩家求了半年的东西，被一个任务 mod 做出来了。
- **⚠️ 实现方式**：跟船一样是「随身物」，不是遗物。

### ③ 「展望未来」— 你说的 X 药

- **条件**：本局打出 3 张 X 费牌。
- **奖励**：**化学X** 遗物（这个是游戏本体真有的，名字是游戏自带的）+ 一张**随机的 X 费牌**进卡组。
- **笑点**：正反馈闭环——给你 X 药，再给你 X 牌，你就想再打 X 牌。
- **说明**：原本想做成「让你挑一张 X 牌」，但挑牌要弹选择界面，而任务可能在打牌的瞬间完成，
  这时候弹选牌窗很打断手感。改成直接给一张随机的、带获得动画。

### ④ 「鸡煲三部曲」— 故障机器人专属梗

只在玩**故障机器人**时才会抽到（其他角色不会看到这些任务，不然莫名其妙）。

| 任务名 | 条件 | 对应梗 |
|---|---|---|
| 还在启动 | 一场战斗的前 3 个回合一张牌都不出，然后赢下来 | 「他在通电」 |
| 回响形态 | 单回合内把**同一张牌**打出两次 | 「你说得对 你说得对」 |
| 严父在上 | 打赢一场精英战 | 「鸡煲严父」小红 —— 这次是你赢了 |

- **奖励**：球类 / 故障机器人相关的遗物或牌。
- **需要**：任务系统要支持**限定角色**（新机制，不难）。

### ⑤ 「打假」

- **条件**：拿到「锚???」之后，再赢下一场首领战。
- **奖励**：金币 / 一张任务卡。
- **笑点**：接着①的梗往下讲。

## 四、要动的东西（技术上都已确认可行）

| 要做的 | 怎么做 | 确认情况 |
|---|---|---|
| 奖励发**遗物** | `await RelicCmd.Obtain<FakeAnchor>(player)` | ✅ 已经在用同一套（发任务册） |
| 奖励发**卡牌** | `var c = owner.RunState.CreateCard(ModelDb.Card<T>(), owner);` → `CardPileCmd.Add(c, PileType.Deck)` | ✅ 照抄游戏自己的 `AddCurseToDeck` |
| 奖励**让玩家挑一张卡** | `CardFactory.CreateForReward(player, n, options)` | ✅ 接口在 |
| 完成任务时**给个提示** | RitsuLib 自带「通知提示」教程 | ✅ 有现成文档 |
| 任务**限定角色** | 给 `QuestDef` 加一个可选角色字段，抽候选时过滤 | 新写，简单 |
| 判定「拥有某遗物」 | 进房间时扫 `Owner.Relics` | 新写，简单 |
| **奖励卡**（战斗结算界面多一张卡片可点） | RitsuLib 的 `ModCustomReward` 基类 + `combatRoom.AddExtraReward(...)` | ✅ 有完整中文文档，但要写本地化 json |

**唯一有风险的一条**：自己造「枯枝」要随机生成牌，得走 `RunState.Rng` 才稳；单机随便，但我会走正规接口。

## 五、三个选项（要你拍板）

**A. 只做「梗任务三连」** ← **已选，已实现**
船长的执念（→ 拼出一艘船）、枯枝还魂（→ 枯枝）、展望未来（→ 化学X + 一张 X 牌）。
奖励 = 本体遗物 / 卡牌 / 自己实现的「随身物」，完成时弹个提示。不碰游戏原有的奖励界面。
→ 改动最小，最快能玩到。

**B. A + 鸡煲三部曲**
再加 3 个故障机器人专属任务。会多一个「角色专属任务」的小机制。
→ 内容最多，梗最足。

**C. B + 原生奖励卡**
再接 RitsuLib 的自定义奖励：完成任务后，**战斗结算界面多一张卡片**让你点着领取，像游戏原生的。
→ 最像官方做的，但要写本地化文件、工作量和坑都最多。

## 六、踩到的一个硬限制：纯 dll mod 造不出带中文名的遗物

翻游戏本体代码确认的：

```csharp
// MegaCrit.Sts2.Core.Modding.ModManager
string path = $"res://{current.manifest.id}/localization/{language}/{file}";
// 同文件里还有：Path.Combine(mod.path, modId + ".pck")
```

也就是说 **mod 的本地化表是从 `res://<ModId>/localization/<语言>/<表名>.json` 读的，
而 `res://<ModId>/` 只有打了 pck 才会存在**。本 mod 是 `has_pck: false` 的纯 dll，
所以：

- 我们自己新建的遗物 **拿不到 `.title` / `.description`**，界面上会是内部 key（很难看）；
- 顺带一提，**现有的「任务册」遗物也有同样的问题**——它每次开局都发给玩家，
  但它在遗物栏里的名字同样是没有本地化的。

**所以梗任务的奖励分成两类：**

| 类型 | 做法 | 例子 |
|---|---|---|
| 游戏本体**已经有**的东西 | 直接发，名字/描述都是游戏自带的 | 化学X（`RelicCmd.Obtain<ChemicalX>`）、卡牌 |
| 本体**没有**的东西 | 做成「随身物」：挂在任务册上的永久效果 + 我们自己的面板里显示中文 | 船、枯枝 |

**要真正修掉这个限制**，得给 mod 打一个 pck（项目里 `GodotExe` 和 `RunPckExport` 的开关都在，
就是现在关着）。那件事会动到目前能跑通的构建链，所以留作单独一步。
