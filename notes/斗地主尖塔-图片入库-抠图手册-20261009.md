# 斗地主尖塔 · 图片入库（抠图）手册

> 脚本：`projects/dou-spire/tools/poker-assets.py`（`--set poker|gilded`、`--dry`、`--only`）。
> 体检图出在 `Default Project/assets/_入库预览/入库预览-<set>.png` —— **左半边深绿台面、右半边浅灰**，
> 同一个素材压在两种底色上都不该有描边。看不懂就先看体检图。
>
> **★ 要带 cv2 的解释器：`D:\software\Python\python.exe`**（默认 `python` 没有 cv2，会 ImportError）。

## 1. ★★ 底色分两种，处理方式**相反**（最容易翻车的一条）

| 底色 | 做法 | 为什么 |
|------|------|--------|
| **白底**（奶油白 / 骨白） | **从四边泛洪**（`flood_background`），**绝对不要用全局色键** | 主体里本来就有大片奶油白（骨白筹码、牌面留白、徽章高光），全局色键会**在主体上打出洞** |
| **洋红底 `#FF00FF`** | 泛洪 **＋ 必须再加 `kill_bg_color`** | 泛洪只从四边进，**进不去被笔画围住的洋红块** —— 见下面第 2 条 |

## 2. ★★ 洋红底：字母的**闭合孔洞**必须单独处理

`kill_bg_color(rgb, a, key, tol)` = **「颜色就是底色」的像素一律抠掉**。

**为什么泛洪不够**：`8` 的两个圈、`4` 的三角、`6`/`9`/`10` 的圈、`J`/`Q`/`K` 的圈 ——
这些洋红块**被笔画围住**，四边泛洪进不去，于是被当成"主体"留下来。
`clean_mask` 也救不了：它只填**≤400px** 的洞，而这些孔洞比它大。

**插入位置（顺序不能动）**：
```
flood_background → alpha_from_bg → despill → clean_mask → kill_bg_color → bleed_edges
                                              ↑ 必须在它之后      ↑ 在它之前
```
- **必须在 `clean_mask` 之后** —— 否则 `clean_mask` 会把 `kill_bg_color` 打出来的洞又填回去。
- **必须在 `bleed_edges` 之前** —— 外扩要吃到"已经干净"的 alpha。
- ⚠️ **只在洋红底开**。白底素材千万别开（主体里就有大片奶油白，一开就打洞）。

**★ 洋红底的合成图没有 alpha** → `run_split`（并排切分）原本会直接抛
"切分模式要求原图带 alpha"，已改成**先色键抠一遍再切列**。

## 3. ★★ alpha 外扩（`bleed_edges`）必须做

**症状**：抠完图边缘有一圈**淡描边**，越缩越明显。

**原因**：透明区的 **RGB 里仍然留着底色**（alpha 置 0 不等于 RGB 清干净）；
`cv2.resize(INTER_AREA)` 是**四通道各自平均**，于是底色被平均进边缘像素的 RGB —— 而那里 `alpha≠0`。

**解法**：用 `ndimage.distance_transform_edt(mask, return_indices=True)` 拿到每个透明像素**最近的不透明像素**
的坐标，把它的 RGB 抄过去。这样透明区的 RGB 也是"主体色"，缩图时不会污染边缘。

## 4. ★ OpenCV 在 Windows 读不了中文路径（**静默失败**）

`cv2.imread` / `cv2.imwrite` 走 ANSI `fopen`，路径里有中文就直接返回 `None` / 静默不写。
工程路径里全是中文（`有花无实`、`德州扑克`…），所以**一律**：

```python
im = cv2.imdecode(np.fromfile(path, np.uint8), cv2.IMREAD_UNCHANGED)
cv2.imencode(ext, img)[1].tofile(path)
```

## 5. 并排切分：按"实体"投影，别按列

一张图里并排 5 个筹码 / 10 个牌型图标时，**半透明辉光会把相邻实体粘成一坨**。
用 alpha 的**列投影**找空档，阈值很关键：

- `alpha > 4` → 只切出 **8 块**（辉光连在一起）
- `alpha > 80` → 切出 **10 块**（正确）

**经验：先用 `--dry` 看切了几块，对不上再调阈值。**

## 6. ★ 认哈希名图（用户丢过来的图名字是哈希）

**最快的方法：拼一张联系表缩略图**（~250px 一格、浅灰底、每格标 `#序号`）用肉眼看 ——
比写脚本猜快得多。

**★ 分「普通牌面底」和「高亮/选中牌面底」时，别只看平均亮度** ——
实测两者只差 **2.1**（203 vs 205），**不可靠**。改用 **金色像素占比**（0.31 vs 0.42）
再**并排放大**确认。

## 7. ★ 满幅背景图是唯一"不抠图"的一类

像 `bg/hall.png`（大厅背景）这种整屏背景：**整幅画满、不要品红、不要透明、不要留边**，
直接放进 `assets/bg/`，**不进抠图脚本**。写提示词时也要提醒美术「这张不抠」。
