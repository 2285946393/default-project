# 八千代辉夜姬 · 日语台词（FishAudio 生成用）

> **用法**：下面每个灰框里是一句话，**点框子右上角复制**，贴进 FishAudio 生成。  
> **音色**：八千代月见（要日语系音色，中文音色念日语会露馅）  
> **语速**：调慢一点更贴她（软糯妹系）
>
> 一共 14 类 × 2 句 = **28 句**，总时长大概 80~90 秒。免费额度 7 分钟，够用。

## 15 / 16. 抢地主（额外两句，2026-10-07 补）

**抢地主是开局前的一个环节**（轮着表态"抢/不抢"，连续两家不抢就收摊），  
不在上面 14 类里，所以单独两句。**要短、有劲**（这是抢的动作，不是出牌）。

### 15. 我抢地主

```
いくよ～！
```

**意思**：上啦～！（短促、有冲劲）

### 16. 我不抢

```
うーん、やめとくね
```

**意思**：嗯～算了啦～

**备选（想换的话）**：

| 位置        | 换什么                                |
| --------- | ---------------------------------- |
| **15 抢**  | `もらった～！`（拿到啦～！）/ `いくよ、いくよ～！`（要来咯～） |
| **16 不抢** | `パス～`（过～）/ `むりむり～`（不行不行～）          |
