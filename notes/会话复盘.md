- 通过 hash 比对定位到 `_720.jpg`（1080×1080 高清原图），导出为 `guanmain.jpg` 入库。**以后发图都能走这条路取原图。**

### 5. Hero 改成了游戏官网式的"半屏出血"立绘
- 用户第一版嫌"小相框+贴纸只显示一小部分"，改成：
  - 立绘 `position:absolute` 贴右缘、顶到底出血铺满右半屏，左侧 `linear-gradient` 渐隐入背景
  - 全屏**樱花飘落**动效层（双层 DOM：外层下落 / 内层左右摇摆 + 旋转），`prefers-reduced-motion` 关闭
  - 移动端流式布局 + 底部 mask 渐隐
- 实测：文字列与立绘**零重叠**、CTA 首屏可见、无横向滚动。

### 6. 全流程都有验证闭环
- 每次改完都：`node --check` 语法 → 起本地 server → Playwright 实测像素分布/网格空洞/链接可达/console 错误 → 桌面 + 移动双端。
- 修掉了图片懒加载误报、`height` 属性顶掉 `aspect-ratio`、emo 卡片显隐导致的 `brokenImgs` 假阳性等。

### 7. 踩坑即总结（沉淀进本 MD 与全局指令）
- 中文路径在 PowerShell 会乱码（显示问题，文件正常）；Python 脚本按字节读写。
- 临时目录残留 `struct.py` 会遮蔽标准库 → 报"module 'struct' has no attribute"。
- PowerShell here-string 转义坑（`\"` 传给 Python 会坏）。
- `height` 属性本身是有效的 presentational CSS，会顶掉 `aspect-ratio` → 改用容器 `aspect-ratio` + 子图 `height:100%`。
- flex 垂直居中的父级里，负 margin 无法顶到 header 边缘 → 出血布局直接改用 `position:absolute`。

## 四、把本地作品做成网页端（思路清单）

你的 12 个作品都是"双击即跑的单文件 HTML"，天然适合静态托管，**不需要任何后端**。

### 方案对比（按省事程度排）

| 方案 | 做什么 | 优点 | 缺点 |
|---|---|---|---|
| **① Vercel 拖拽部署（最推荐）** | 打开 vercel.com → New Project → 直接把 `Default Project` 文件夹拖进去，一次搞定 | 免 git、免命令行、HTTPS、全球 CDN、国内基本可用；`作品展馆.html` 天然当入口 | 免费额度偶尔需要改项目名 |
| ② GitHub Pages | 把作品推一个 GitHub 仓库，开 Pages | 免费、永久 | **你系统没装 git**，得走网页上传，一次要传十几个文件较麻烦 |
| ③ Netlify / Cloudflare Pages | 拖拽或连仓库 | 同 Vercel | 大陆访问 Vercel/Netlify 比 Cloudflare 稳一点 |
| ④ 国内对象存储托管 | 腾讯云 COS / 阿里 OSS + 静态网站 | 大陆访问最快 | 要备案/买域名，成本高，适合正式运营 |

### 推荐落地路径
1. **先走 ①Vercel 拖拽**，2 分钟把整个文件夹拖上去，得到 `https://xxx.vercel.app`。
2. 分享链接到 QQ 群（`作品展馆.html` 就是首页，群号 574612434 已内置）。
3. 需要大陆更稳时，再换 ④ 或加域名。

### 我能在网页端化上帮你做的

- 做一个**一键部署脚本**（如 `deploy.ps1`：自动打包、调 Vercel CLI 或生成上传指引）。

- 如需要，加一个极简访客计数（纯前端，可不接后端）。
