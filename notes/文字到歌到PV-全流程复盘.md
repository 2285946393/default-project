## 二、四个阶段

### 第 1 步 · 词（2022 → 2026）

诗写于 2022 年 6 月、高二结束前后，是每晚放学回家所见景象的汇总；写法上假想了一个
"已经不再是学生、某天翻到这首诗"的未来自己。2026-09-13 连同另外 88 首一起搬进博客说说区。

### 第 2 步 · 曲（海绵音乐）

- 站点：`haimian.com`（网易，免费，网页版，零下载）
- 生成出两版：《月落五千年》4:19 / 《浸月》4:02。用了前者。
- 参数：75 BPM / D 大调 / 4/4；钢琴分解和弦 + 弦乐组 + 古筝点缀 + 风铃沙锤；女声

### 第 3 步 · 画面（JIZURA）

- **歌词 68 句**（含 1 行落款），原诗一字未删
- **时间轴不用手敲**：faster-whisper 转写 → 拿秒数写进 `timing.lineTimes`
- **部件 20 种**，全是"一进场就出字"的排版类；风格走深蓝（深海）
- 导出 3840×2160

### 第 4 步 · 合成与投稿

- 试过"绿幕导出 → 抠绿 → 叠到自己照片的模糊底上"，能跑通，但对比度不够，最终仍用深蓝原版
- 投稿：标题带【文字PV】+ 身份钩子；简介是**创作者自述**（背景 + 三步制作 + 为什么现在做）

## 三、踩过的坑（按重要程度）

1. **⚠️ ASR 按"段"映射会吞掉句尾。** Whisper 会把相邻两小句并成一个识别段，
   只取段首几个字，段尾短语就整句消失。这次丢了 8 处（身份还是学生 / 无不浸浮其中 /
   亦有草木暗自生长 / 夜空隐约透露 / 历史的厚重与压迫 / 是勾肩搭背的欢声笑语 / 少年少女的骑行）。
   **正确做法：拿原文按 `，、？` 切句，逐句反查，不能只看时间点。**

2. **⚠️ 改时间轴必须"改 json → 重新打开"。** 在同一个浏览器会话里手填输入框不生效，
   旧状态会盖回来。（《滥俗的歌》那次白填了一轮。）

3. **⚠️ Whisper 在伴奏密、人声被盖处会整体提前。** 1:43「那虎落平川的才子」被提前了 9 秒。
   这类段落要人工校准。

4. **一顿一顿唱的短句要拆成独立行。**「小酌/痛饮/豪喝/醉」原本一行，等于四个词一起提前出场；
   拆成四行、各占各的秒才对。

5. **"和风物件"和"几何图形"类部件是先出景、后出字**，每句开头有 0.5～2 秒空档，
   看着像纯黑屏（49 秒那片黑就是这么来的）。要"立刻见字"只能用排版类。

6. **"全屏大字"类部件（首字撑屏、字撑破画面）不要用**，用户明确否掉。

7. **手填的逐行时间不驱动渲染**，JIZURA 只认「轻点同步」；能用 json 就别在界面上填。

8. **1.8 GB 的视频在内置浏览器里传会崩标签页**（196 MB / 415 MB 都稳）。
   超过 1 GB 先压成 1080p。

9. **界面显示 ≠ 工程实际值。** 用「只换风格」摇到"深海"，保存出来的 json 里
   `style` 仍是上一个值。**摇出来的风格存不住**，要固定风格得知道它的 key。

## 四、工具链

| 环节 | 工具 |
|---|---|
| 词 → 曲 | 海绵音乐 `haimian.com` |
| 词 + 曲 → 画面 | JIZURA `852wa.github.io/JIZURA`（MIT，纯前端） |
| 自动对轴 | `faster-whisper`（small 模型，CPU int8，262 秒约 3 分钟） |
| 裁水印 / 抠绿 / 模糊垫底 / 降分辨率 | ffmpeg |

## 五、这条链路为什么值得

- **版权干净**：词是自己写的，曲是生成的，不欠第三方
- **对轴可自动化**：以后凡是自己生成的歌，都能用 ASR 造一份 LRC，不用敲几十下
- **画面可换**：绿幕导出 + 后期合成，背景随便换，不用重跑 JIZURA

## 六、下次的固定顺序

1. 词定稿 → 按 `，、？` 切句，逐句核对（**这一步不能省**）
2. 生成曲 → 明确写"女声" → 裁掉结尾 AI 水印
3. ASR 转写 → 拿秒数写 json → **重新打开工程**
4. 逐行配部件（只用排版类，避开和风物件和全屏大字）
5. 导出 → 超过 1 GB 就先压 1080p → 投稿
