# 本地画图怎么用（M365 Gateway）

> 记录时间：2026-09-20
> 用途：本机直接出图，不用开浏览器、不用买会员。

---

## 一、能画什么

你本机跑着一个叫 **M365 Gateway** 的小程序，它把微软的 Copilot 画图能力转成标准接口。
我这边（DSH）和你 opencode 那边都能直接调它出图。

**现在唯一能用的画图通道就是它。** 另外两条都挂了，见第四节。

---

## 二、开图前必须先做的一件事

**双击打开 `D:\work\m365-copilot2api-windows-amd64.exe`**

- 它会在后台起一个本地服务，端口 `4141`
- 窗口别关，关了图就画不出来
- 电脑重启后要重新双击

判断它有没有在跑：任务管理器里找 `m365-copilot2api-windows-amd64` 这个进程。
或者浏览器打开 `http://127.0.0.1:4141/v1/models`，能看到一串模型名就是好的。

---

## 三、模型名

```
gpt-image-2
```

就这一个能画图。旁边那些 `gpt-5.x`、`claude-sonnet` 是聊天模型，不能出图。

调用方式（OpenAI 标准格式）：

```
POST http://127.0.0.1:4141/v1/images/generations
Authorization: Bearer m365_你的密钥
Content-Type: application/json

{
  "model": "gpt-image-2",
  "prompt": "你要画什么",
  "n": 1,
  "size": "1024x1024"
}
```

返回里 `data[0].url` 就是图，是个本地地址，直接下载就能存成 png。

1. **地址写错了**。配置里是 `https://www.agnes-ai.com/v1`，那是官网首页，不是接口，

   要去 `platform.agnes-ai.cn` 后台重新生成一个。

## 五、画图提示词怎么写（实测经验）

### 有用的套路

**画真人写实（cosplay 那种）**，堆这些词：

```
photorealistic, real human person, shot on 85mm lens, soft studio lighting,
shallow depth of field, high detail skin texture, professional photoshoot
```

**画三视图 / 建模参考**，堆这些词：

```
character model sheet, three-view turnaround, orthographic,
front view / side view / back view, full body head to toe, neutral standing pose,
flat lighting, no shadows, clean white background, consistent proportions across all views
```

**画手办 / PVC 模型**，堆这些词：

```
PVC anime figure, 1/7 scale, collectible, glossy plastic material,
visible seam lines, display base, studio product photography, softbox lighting,
blurry room background, toy
```

### 实测结论

- **三视图出得最好**，结构清楚、比例统一，直接能拿去建模或者做手办参考。
- **真人 cosplay 能出**，模型不拒。想要写实感就强调"real human / photorealistic / 照片参数"。
- **默认容易出动画插画风**，不给写实词就会给你 Q 版或者二次元插画。
- **双人图容易崩**，两个人以上容易画串。要双人就把两人特征写清楚，用 GIRL A / GIRL B 分开描述。
- 尺寸固定 `1024x1024` 就行，出图约 1254×1254 像素。

## 八、2026-10-04：账号全挂了，查清了原因

**现象**：调 `/v1/images/generations` 和 `/v1/chat/completions` 全是 `502 upstream_error`，
连"画一个红苹果"这种最普通的提示词也 502；`/v1/models` 能列出来，说明是账号侧的问题。

**根因**（把网关的日志抓出来看到的原文）：

```
[token-refresh] account=2285946393@office.bo.edu.kg failed:
Refresh invalid_grant: AADSTS5000224: We are sorry, this resource is not available.
```

**5 个账号（同一个租户 `a636d8ab-26fd-41a5-b1bb-1f28c3363342`，域名 `office.bo.edu.kg`）全部同样报错。**
`AADSTS5000224` 是**租户层面被停用**的意思，不是"登录过期"——
所以**在管理界面重新登录也救不回来**，这批免费教育版账号（连租户）已经被微软清掉了。

佐证：租户的 OIDC 元数据 `https://login.microsoftonline.com/<tid>/v2.0/.well-known/openid-configuration`
仍然返回 200（目录还在），但所有令牌刷新都被拒；`usage.jsonl` 里最后一次成功记录停在 09-24 13:53。

**怎么办**：换一批新的可用账号重新授权（`http://127.0.0.1:4141/` 管理界面里加），
或者换个出图渠道。这两条都得先有账号来源，agent 这边没法自己变出来。

**顺手发现的安全提示**（日志里一直在喊）：

```
[security] WARNING: M365_MASTER_KEY not set;
refresh tokens are encrypted with a built-in public fallback key.
```

也就是 `accounts.json` 里的 refresh token 用的是**内置的公开兜底密钥**加密的，
谁拿到这个文件都能解。不想这样，就给网关设一个环境变量 `M365_MASTER_KEY`（随便一串长随机值），
设完重新授权一次账号。
