# 千岁语音 → Windows 系统音效

日期：2026-10-05
状态：**✅ 已配好并验证**

---

## 一句话

把「茑町千岁」语音包配成了 Windows 的系统声音：开机登录、UAC 弹窗、
清空回收站、插拔 U 盘、电池警报、系统通知、默认响声……全都换成千岁。

## 文件在哪

- 原始下载：`D:\BaiduNetdiskDownload\茑町千岁`（百度网盘下下来的）
- **正式位置**：`D:\software\茑町千岁语音\`（已从下载目录复制过来，下载目录清掉也不怕）
- 原始系统声音备份：`D:\software\茑町千岁语音\_original-sounds-backup.reg`

## 配了哪些（17 处）

写在注册表 `HKCU\AppEvents\Schemes\Apps\...` 里，直接改的是各事件的 `.Current`
（也就是"当前方案"，所以改完立即生效，不用重启）。

| 声音文件 | 事件名 | 什么时候响 |
|---|---|---|
| 开机语音.WAV | `WindowsLogon` | 开机登录 |
| Windows用户账户控制.WAV | `WindowsUAC` | UAC 弹窗 |
| 清空回收站.wav | `EmptyRecycleBin`（Explorer 根下） | 清空回收站 |
| 关键性停止.WAV | `SystemHand` | 关键错误 |
| 感叹号.wav | `SystemExclamation` / `SystemAsterisk` | 感叹号/信息 |
| 系统通知.WAV | `SystemNotification` / `Notification.Default` | 系统通知 |
| 默认响声.wav | `.Default` | 默认响声 |
| 电池不足警报.WAV | `LowBatteryAlarm` | 电池不足 |
| 电池严重短缺警报.WAV | `CriticalBatteryAlarm` | 电池告急 |
| 设备连接.WAV | `DeviceConnect` | 插上 U 盘等设备 |
| 设备中断连接.WAV | `DeviceDisconnect` | 拔掉设备 |
| 设备未能连接.WAV | `DeviceFail` | 设备连接失败 |
| 消息闪屏振动.WAV | `MessageNudge` | 消息提醒 |
| QQ提示音.wav | `Notification.IM` | 即时消息通知 |
| 微信提示音.wav | `Notification.SMS` | 新短信通知 |

## 音量与长度（2026-10-05 追加：用户说「太大了」「一直发一直响」）

**问题**：原包比 Windows 原生音效响 8~17 dB；QQ 那条本身 2.8 秒（还是三句话拼的），
连着一来消息就叠成一片。

**处理**（用本机 ffmpeg 重编码，全是 16-bit PCM 48kHz）：

| | 原来 | 现在 |
|---|---|---|
| 系统音效（14 个） | 峰值约 0 ~ -7 dB | **峰值统一压到 -9.5 dB**（≈ Windows 原生） |
| QQ提示音 | 2.8 秒 / 峰值 0 dB | **1.2 秒 / 峰值 -17 dB**（≈ QQ 原提示音） |
| 微信提示音 | 0.86 秒 / 峰值 0 dB | 峰值压到 -14 dB |

- QQ 那条按静音位置切在 `0.10s ~ 1.30s`（第二句话从 1.34s 才开始，正好避开），
  结尾加 0.25 秒淡出。
- **原始大声完整版**全部留在 `D:\software\茑町千岁语音\原音量\`，想换回去直接从那儿拿。

## QQ 提示音怎么装的

QQ 的音效在安装目录里：`D:\software\qq\versions\<版本号>\resources\app\resource\msg.wav`
（`msg.wav` 就是新消息提示音；同目录还有 `ringtone-*.mp3` 是语音/视频通话铃声）。

- 已替换，原文件备份成同目录的 `msg.wav.original-bak`
- ⚠️ **QQ 每次升级会新建一个版本目录**，提示音会被换回默认 ——
  到时候双击 `D:\software\茑町千岁语音\装到QQ.cmd` 自动重新装（脚本会自己搜版本目录）
- 换完要**重启 QQ** 才生效
- 替换时如果 QQ 正开着可能占文件，脚本会提示先退 QQ

## Claude Code（cc）的提示音（2026-10-05 加）

cc 本身没声音，用它自带的 **hooks** 接上：

| 时机 | 事件 | 放哪个 |
|---|---|---|
| 一轮回答干完 | `Stop` | `D:\software\qiansui-sounds\done.wav`（系统通知裁短版，1.2 秒） |
| 需要你确认 / 等着你 | `Notification` | `D:\software\qiansui-sounds\need-you.wav`（感叹号裁短版，1.2 秒） |

- 写在 `C:\Users\有花无实\.claude\settings.json` 的 `hooks` 段。
- ⚠️ **路径用纯英文目录 `D:\software\qiansui-sounds\`**，因为 hook 命令要过一层
  shell，中文路径容易踩编码问题。
- 命令长这样（`PlaySync` 会等播完，所以音效必须短，否则拖慢 cc）：
  `powershell -NoProfile -ExecutionPolicy Bypass -Command "(New-Object System.Media.SoundPlayer '<wav>').PlaySync()"`
- **三个文件都加了 hooks**：`settings.json` + `settings.deepseek.json` + `settings.tokenplan.json`——
  不然下次双击切换线路的脚本会把 hooks 覆盖掉。
- 改完要**新开一个终端**再运行 `claude` 才生效。

## 怎么还原

双击 `D:\software\茑町千岁语音\_original-sounds-backup.reg`，确认导入，完事。

（或者在「设置 → 系统 → 声音 → 声音方案」里选回「Windows 默认」。）

## 还没做的

1. **微信本体里的提示音没换**：微信的音效文件在它自己的安装目录里，
   要换得照 QQ 的办法找出来替换（系统设置改不到）。
2. **通话铃声没换**：`ringtone-caller / callee / accept / hangup` 那几个还是 QQ 默认的，
   千岁语音包里没有对应的素材。
3. **没做成"可选方案"**：现在是直接改成当前方案（设置里会显示成"自定义"），
   不是在下拉列表里多一个"茑町千岁"。要那个得写 `AppEvents\Schemes` 的方案结构，
   更麻烦、也更容易搞坏，暂时没做。

## 复现脚本

| 脚本 | 干什么 |
|---|---|
| `%TEMP%\apply-sounds.py` | 把 wav 写进注册表（系统音效） |
| `%TEMP%\normalize-sounds.py` | 批量把峰值压到目标值（调用 ffmpeg） |
| `%TEMP%\trim-qq.py` | 裁剪 + 压缩 QQ 提示音 |
| `D:\software\茑町千岁语音\apply-qq.py` | 装进 QQ（带自动找版本目录） |
| `D:\software\茑町千岁语音\装到QQ.cmd` | 双击版，QQ 升级后用 |

逻辑很简单：系统音效是 `winreg.CreateKey(...\事件名\.Current)` + `SetValueEx('', REG_SZ, wav路径)`；
音量是 `ffmpeg -af volume=<N>dB`；裁剪是 `atrim + afade`。下次换语音包照抄就行。
