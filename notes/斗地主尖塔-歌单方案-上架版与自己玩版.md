## 一、结论（一句话）

**上架的包里不放别人的商业歌；但"自己想听什么"这件事完全满足 —— 分成两套歌单。**

- **自己玩版**（本机）：想放什么放什么。只在自己机器上，不上传、不分享。
- **上架版**（工坊）：只留自己生成的 / 免费授权的歌，或者干脆空着让玩家自己丢。

技术上本来就支持 —— 音乐是从磁盘读文件的，两套只是"同一个目录里有没有歌"的区别。
工具已经写好了，一条命令切换。

## 二、用户举的两个例子，怎么回应

**先承认：这是真的，而且工坊上很常见。** 大量 mod 直接把别人的歌塞进去。
用户的羡慕是合理的，不能装作没这回事。

但这两个例子和我们的处境**不一样**，差别在两处：

### ① "辉夜姬用自己电影的歌" —— 有一层我们没有的"说法"

那个 mod 是《超时空辉夜姬》的**同人 mod**：它是那部作品的粉丝延伸，
歌和内容是一体的，"用那部电影的歌"在叙事上说得通。

我们的 mod 是"斗地主 + 杀戮尖塔"，跟任何一首日文 OP 都没有这层关系 ——
塞进去就是"一首不相干的流行歌出现在一个不相干的 mod 里"。

> ⚠️ 注意别把这话说成"它有授权"：**法律上两者一样，都是没授权的使用。**
> 它活着是因为没人投诉（赌赢了），不是因为它合规。
> 区别只是它有一层"同人作品自带的说法"，我们没有。

### ② 《雨爱》那个更直接 —— 杨丞琳的商业流行曲，纯赌

## 三、真正决定这件事的是"赌注大小"，不是"能不能"

| | 辉夜姬 / 五条悟 那类 mod | 我们的 `3815233309` |
|---|---|---|
| 当前状态 | 正常公开 | **被 Steam 自动内容检查挂起、已隐藏**（2026-10-08 02:26 实测仍在藏，已 5h21m） |
| 订阅数 | 有 | **浏览 1 次 / 订阅 0** |
| 赌输的代价 | 下架 | 下架 **＋ 账号记一次版权** → 连带 QuestSpire / 凛冬尖塔一起被看 |
| 赌赢的收益 | 一整套 OST | 一套**几分钟就能换掉**的背景音乐 |

**收益是"换个背景音乐"，代价是"整个账号"。** 这个赔率不值得下。

还有一层更实际的：

- Steam 的自动扫描**已经盯上我们了**（大概率是之前那两个外链触发的，已拆掉）。
- 外链要人去判断，**音频指纹是机器直接能匹配的** —— 这时候往包里塞商业歌，
  等于给扫描器递了一个明确的、可自动识别的目标。
- 而且我们本来就在等这一轮审查结束才能上传，等于把"再审查一轮"叠上去。

## 四、解法：两套歌单

### 目录分工

```
projects/dou-spire/
    music-private/          ← 个人歌库（本机，不会打包、不会同步）
        table/  tense/  climax/  win/  lose/
    assets/music/           ← 工程素材（编译时同步进游戏，会被打包）
        table/  tense/  climax/  win/  lose/

D:\...\Slay the Spire 2\mods\DouSpire\assets\music\   ← 游戏目录（直接生效）
```

### 工具：`tools/music-switch.py`

```bash
cd "C:\Users\有花无实\Documents\Default Project\projects\dou-spire"

# 看现在是哪一版
python tools\music-switch.py status

# 上架前自检（有歌就返回非 0，可以挂进构建流程）
python tools\music-switch.py check

# 把个人歌库的歌全部导入 → 切到"自己玩版"
python tools\music-switch.py private

# 把 mod 里的歌全部撤走 → 切回"上架版"
python tools\music-switch.py public
```

- `private` 会自动建好 `music-private/` 的 5 个槽位文件夹；
  丢进去的 mp3 / flac / m4a **不用先转格式**，脚本调 `import-music.py` 那套流程转 .ogg + 响度归一化，
  转完直接拷进游戏目录（免编译）。
- `public` 是**挪走不是删掉** —— 全部移到 `music-private/_撤下备份/<时间戳>/`，
  想找回随时拿。**不删用户的东西。**
- 端到端实测过：空库 → 造一首测试音 → private（转码+同步）→ status/check 报"自己玩版" → public → check 通过。
  测试残留已清理。

### 上架前的三条检查

1. `python tools\music-switch.py check` 通过（= mod 里没有任何音乐文件）
2. `workshop.json` 的 `changeNote` 里**别写**"包含 XX 首歌"之类的话
3. 包体大小别突然变大（`148MB` 是现在的基线，多出一大截就是歌没撤干净）

## 五、想要"日系动画 OP 那种味道"怎么办

> ⚠️ **2026-10-08 修正**：这一节最初写的是"温柔女声 / 梦幻治愈 / 轻爵士"，
> 用户实测反馈"**难听，没有那种打牌的感觉，完全不会想玩第二次**" ——
> 那套偏好是写诗做歌用的，跨场景套用等于没有偏好。
> **已整节换成民乐方向**，完整拆解见 `notes\斗地主尖塔-背景音乐-打牌感方案.md`。

用户真正想要的不是"日系 OP"，是**牌桌的感觉**。斗地主 BGM 的公式：

**唢呐（灵魂）＋ 二胡/板胡 ＋ 琵琶轮指 ＋ 小锣梆子 ＋ 中快板 120BPM ＋ 纯器乐循环**

| 槽位 | 提示词 |
|---|---|
| `table` | `（要求：中国民乐，唢呐主旋律＋琵琶轮指＋二胡副旋，轻快诙谐，市井茶馆的牌桌感，中快板 120BPM，小锣梆子点缀，纯器乐无人声，循环耐听，不要有明显结尾）` |
| `tense` | `（要求：中国民乐紧张版，板胡急促＋锣鼓渐密，速度逐渐加快，压迫感，纯器乐无人声，循环结构）` |
| `climax` | `（要求：唢呐高音齐鸣＋锣鼓爆发，喜庆炸裂，开场第一秒就是高潮，15 秒左右，纯器乐）` |
| `win` | `（要求：民乐喜庆收尾小段，唢呐上扬＋小锣收，得意洋洋，8 秒左右，纯器乐）` |
| `lose` | `（要求：二胡滑音下坠，泄气滑稽，带点自嘲不悲伤，8 秒左右，纯器乐）` |

生成完：`python tools\import-music.py <文件> --cue <槽位> --to-mod`（AI 水印用 `--keep 256` 裁）。
