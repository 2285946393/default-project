# 粒子生命 · Particle Life（中文单文件版）

一个会自己"活"起来的数字生态缸：屏幕上每个颜色是一个**物种**，任意两个物种之间只有"喜欢靠近 / 讨厌远离 / 互不理睬"三种关系。规则简单到一句话能说完，却会自发涌现出会**旋转、追逐、吞噬、共生、迁徙**的彩色活体结构——而且没有任何两个世界是一样的。

- 改造自开源项目 **hunar4321/particle-life**（MIT 许可），重写了高性能空间网格核心与经典分段力模型，自建全中文界面。
- **零依赖、零联网、零安装**：双击 `粒子生命.html` 即可离线运行（推荐 Chrome / Edge）。

---

## 最上瘾的玩法

1. **疯狂随机世界**：按 `R` 或点 🎲，每个世界的"物种关系"随机生成——有的世界万物和谐抱成一颗会呼吸的球，有的世界是捕食者追着猎物满屏跑，多刷几次总能遇到惊艳的。

2. **亲手改写"社会规则"（核心）**：右上角的**物种吸引矩阵**就是这个宇宙的基因——
   - 行 = "谁"，列 = "对谁"；格子**越绿越吸引、越红越排斥、深色=中立**；
   - **单击格子**在 −1 / 0 / +1 间切换；**按住左右拖动**连续微调；
   - 改一个格子，整个生态几秒内连锁重组，非常直观地看到"一条规则如何改变一个文明"。
   - 「对称」让两物种互相态度一致；「归零」回到互不往来。

3. **用手搅动世界**：
   - **按住左键拖动**：在光标形成引力井，把粒子吸过来、牵引整个族群迁徙；
   - **Shift / 右键拖动**：斥力，一把把它们吹散，看它们重新聚集。

4. **物种 1～7、六套配色**：按数字键 `1`-`7` 增减物种；`←` `→` 切换霓虹深渊 / 熔岩余烬 / 极光森林 / 星云糖果 / 赛博朋克 / 深海荧光。

5. **开"自动演化"**：勾上后世界会每隔一阵自己随机突变一条关系，你就坐着看一个生态如何漂移、崩塌、重生。

## 参数滑块都在调什么

| 滑块 | 作用 |
|---|---|
| 每族数量 | 每个物种的粒子数，越多越绵密（吃性能） |
| 作用半径 | 粒子能"感知"到多远的邻居，越大越容易抱团 |
| 力强度 | 吸引/排斥的猛烈程度 |
| 惯性黏度 | 越大越黏滞沉稳，越小越灵动易飞散 |
| 粒子大小 / 拖影长度 | 视觉质感：更大更连续，拖影越长越有流光轨迹 |

## 快捷键

- `空格` 暂停 / 继续　·　`R` 随机新世界　·　`O` 只重新散布
- `S` 关系对称化　·　`G` 隐藏 / 显示面板　·　`P` 保存图片
- `←` `→` 换配色　·　`1`～`7` 物种数量

## 小提示

- **同一个"世界种子"永远生成同一个世界**：底部种子号会写进网址（#后面的数字），把链接发给朋友，打开就是和你一模一样的生态；也可以手动输入种子号精确复现。
- 卡顿就调低"每族数量"或减小"作用半径"；它用空间网格做了加速，普通电脑几千粒子可流畅运行。
- 想找好看的结构：多按 `R`，遇到"会自己旋转的稳定细胞"时停手，盯着看特别解压。
