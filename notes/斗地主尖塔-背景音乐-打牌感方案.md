## 二、认领：上次那 5 条提示词是错的

我在 `斗地主尖塔-音乐系统.md` 第六节给的是：

```
温柔女声演唱，梦幻治愈，轻爵士钢琴与弦乐，慢速，无鼓点，适合长时间循环播放
```

这是**咖啡馆背景乐**。放在斗地主上，当然没有打牌感 —— 因为：

- ❌ **没有唢呐**（斗地主的灵魂）
- ❌ **没有锣鼓**（"炸"的感觉）
- ❌ **没有弹拨**（"出牌"的噼里啪啦）
- ❌ **速度慢了一半**
- ❌ **还有人声**（循环会烦，而且抢戏）

**根因**：我把 `notes\AI音乐生成-偏好与操作.md` 里"温柔女声 / 梦幻治愈 / 不暗黑"
那套偏好直接套过来了。**但那条规矩是给你写诗做歌用的（JIZURA 歌词 PV），
和"牌桌 BGM"是两个完全不同的用途。** 我串了。

> 教训：**用户偏好是有适用范围的，跨场景套用等于没有偏好。**
> 这次的判据就是用户的原话 —— "没有那种打牌的感觉"。

## 三、"打牌感"到底是什么（拆解）

斗地主 BGM 的听觉公式，六条：

| # | 要素 | 为什么 |
|---|---|---|
| 1 | **唢呐** | 一响就知道要斗地主了。穿透力强、喜庆、带点"土"——**这是灵魂，没有它就不是斗地主** |
| 2 | **二胡 / 板胡** | 市井、诙谐、带点苦相。斗地主是"三教九流"的牌桌，不是宫廷雅乐 |
| 3 | **琵琶轮指 / 扬琴 / 古筝快速弹拨** | 对应"出牌"的节奏感 —— 噼里啪啦 |
| 4 | **小锣 / 梆子 / 木鱼点** | "炸"的瞬间感、节奏骨架 |
| 5 | **中快板 110~130 BPM + 明快大调** | 有摇摆感、市井味，不能慢 |
| 6 | **纯器乐、无歌词、结构循环** | 一局几分钟要循环十几遍；有歌词会分心，有"结尾"会别扭 |

> 一句话：**斗地主 BGM = 唢呐带头、锣鼓打底、弹拨跑动、循环耐听的市井民乐。**

## 四、修正后的提示词（海绵音乐）

风格要求直接写在歌词框末尾（提交按回车，点按钮没用）。

| 槽位 | 提示词 |
|---|---|
| `table` 平时 | `（要求：中国民乐，唢呐主旋律＋琵琶轮指＋二胡副旋，轻快诙谐，市井茶馆的牌桌感，中快板 120BPM，小锣梆子点缀，纯器乐无人声，循环耐听，不要有明显结尾）` |
| `tense` 紧张 | `（要求：中国民乐紧张版，板胡急促＋锣鼓渐密，速度逐渐加快，压迫感，纯器乐无人声，循环结构）` |
| `climax` 高潮 | `（要求：唢呐高音齐鸣＋锣鼓爆发，喜庆炸裂，开场第一秒就是高潮，15 秒左右，纯器乐）` |
| `win` 赢 | `（要求：民乐喜庆收尾小段，唢呐上扬＋小锣收，得意洋洋，8 秒左右，纯器乐）` |
| `lose` 输 | `（要求：二胡滑音下坠，泄气滑稽，带点自嘲不悲伤，8 秒左右，纯器乐）` |

> ⚠️ 海绵音乐可能要求填歌词。纯器乐就把风格写在框里、歌词留空或写「纯器乐」，
> 看工具给不给无词模式；不给的话就让它哼唱（别要歌词）。

**和上次的区别**：乐器从"爵士钢琴＋弦乐"换成"唢呐＋琵琶＋二胡＋锣鼓"，
速度从慢速提到 120，人声从"温柔女声"改成"纯器乐"。**这才是斗地主。**

## 七、群友说"一般不会有事"—— 哪里对，哪里对我们不成立

用户截图里群友的意见：

> "都是懒得追究" / "具体版权问题 b 站有人说过" / "一个二创视频你追究的话很没面子"
> "一般不会有问题" / "出问题也都会发消息给你，你下架 mod 就行" / "很少会直接追究" / "别怕"

### 说得对的部分（不装看不见）

- **"懒得追究"是对的。** 版权方发 DMCA / 起诉的成本高于收益，大多数确实不管。
- **"很少直接追究"是对的。** 起诉是最后手段，最常见的结局就是"收到通知 → 下架"。
- **"二创视频追究很没面子"这个观察很敏锐** —— 版权方对同人圈动手的公关代价确实高。

### 但对我们具体不成立的四点

1. **我们的条目此刻正被 Steam 自动内容检查挂起**（2026-10-08 02:26 实测仍隐藏，已 5h+）。
   群友讨论的是"版权方会不会追究"，**没人考虑到我们自己已经站在审查窗口里**。
   外链要人去判断，**音频指纹是机器直接能匹配的** —— 这时候塞商业 BGM 等于主动递靶子。

2. **0 订阅 / 1 次浏览。** 那些"活得好好的"mod 是**有订阅量**的 —— 赌赢了有人看。
   我们赌赢了没人看，赌输了整包没了。

3. **DMCA 记在账号上，不是记在那个条目上。** 群友没提这条。
   连带 QuestSpire / 凛冬尖塔 一起被看。

4. **最关键：你要的东西不需要赌。** "打牌感"是**风格**问题，不是"必须用那一首"的问题。
   唢呐＋锣鼓＋弹拨这一套，免费能拿到，AI 也能做。

## 八、如果就是要那一首原版

**那就自己玩版**，工具已经做好了：

```bash
# 1. 把歌丢进个人歌库（本机，不打包、不同步、不上传）
#    projects\dou-spire\music-private\table\

# 2. 一条命令导入并同步进游戏

# 3. 游戏里 F9 收桌、再 F9 开桌
```

上架前跑一次 `python tools\music-switch.py public` 把歌撤走
（挪进 `_撤下备份`，不是删掉）。**编译时也会自动提醒一次。**
