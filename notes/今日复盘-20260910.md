### 3. 粒子宇宙（用户满意）

**基础项目**：JFCY2718/cosmic-playground
- 纯 vanilla JS + Canvas 2D，零依赖
- 6种视觉模式：星系、极光、星云、矩阵、烟花、星场

- 鼠标引力场、左键爆炸、右键黑洞、滚轮缩放

**性能优化（关键）**：
- 默认粒子数：1500 → 800
- 连线渲染粒子数：300 → 120
- 连线最大距离：100 → 80
- 用 `globalAlpha` 代替颜色字符串拼接（避免每帧 45000 次字符串操作）
- 用 `Math.sqrt(dx*dx+dy*dy)` 代替 `Math.hypot()`（更快）
- 效果：从 2FPS 提升到流畅

**美化改造**：
- 隐藏默认 HUD（FPS/粒子数/模式）和复杂控制面板

## 三、关键技术经验

### WebGL/Canvas 项目调试

1. **静默失败是最大的坑**
   - 混淆/Haxe编译的JS常依赖特定DOM元素和全局函数，缺失不报错
   - 外部资源（纹理、CSS、JS）缺失会导致初始化卡住，无任何提示
   - 解决：用 `window.onerror` 捕获，检查控制台，逐一确认依赖文件

2. **初始化时间**
   - WebGL 项目（尤其 raymarching）需要 5-10 秒校准/编译着色器
   - 期间画面全黑或显示加载文字，不要误判为失败
   - 解决：等待足够时间后再截图验证

3. **性能优化**
   - Canvas 2D 连线渲染是 O(n²)，粒子数 > 200 就会卡
   - 每帧大量字符串拼接（颜色+alpha）非常慢
   - `Math.hypot()` 比 `Math.sqrt(dx*dx+dy*dy)` 慢
   - 解决：限制连线粒子数，用 globalAlpha，用手写距离计算

### GitHub 项目下载

1. **GitHub 直连被墙**：`git clone` 和 zip 下载均 Connection reset
2. **jsDelivr CDN 可用**：`https://cdn.jsdelivr.net/gh/<owner>/<repo>@<branch>/`
3. **raw.githubusercontent.com 也可用**：大文件更稳定
4. **项目结构不确定时**：先下载 index.html，从引用路径找到 CSS/JS 文件名

## 四、今日收获

1. **"互动"的真正含义**：不是能旋转缩放就算互动，而是用户的操作能创造新的视觉内容。引力场、爆炸、黑洞——用户在改变世界，而不只是看世界。

2. **颜色丰富 ≠ 多套预设**：分形有6套预设但用户觉得"全都一个颜色"，因为每套预设内部色调统一。粒子宇宙的霓虹配色成功是因为同屏有粉/青/红多种颜色混合。

3. **性能是体验的基础**：2FPS 的星系再好看也没法玩。优化后流畅运行，体验完全不同。

4. **先检查再动手**：流体项目重复了，如果先 `ls` 用户目录就能避免。

5. **极简 UI 是正确方向**：隐藏滑块和遥测，只留最核心的控制按钮，画面干净，用户专注于内容本身。
