# 环境事实（踩过的坑）

- **当前模型不支持图像输入**：用户发截图/图片必然报 "Cannot read image (this model does not support image input)"。不要反复重试，第一次就明确告知，并主动提供替代方案：
  - 用 Python + Pillow 程序化分析图片（`pip install pillow`）：`quantize()` 提取主色占比、按 8x8 网格求平均色推断布局分区（页眉/页脚/卡片位置）、平均亮度判断明暗主题、饱和度>0.45 的颜色即强调色候选。这套方法可以把"视觉风格"量化成配色表，足以做风格迁移。
- **PowerShell 控制台显示 UTF-8 中文必乱码**（GBK 控制台），只是显示问题，文件本身正常。诊断中文文件内容时，用 Python 脚本按字节读取，脚本写到临时目录再执行。
- **Playwright 禁止 file:// 协议**：测试本地 HTML 先起服务器 `python -m http.server <端口>`（workdir 设为项目目录），用完 `Get-NetTCPConnection -LocalPort <端口> | Stop-Process` 关掉。
- **Playwright evaluate 可能跑在错误的标签页上下文**（返回的内容和页面对不上）：先 `browser_tabs list` 确认当前标签，必要时重新 navigate。
- 临时脚本目录：`C:\Users\有花无实\AppData\Local\Temp\opencode`（已存在，可直接用）。
- 端口可能被其他应用占用：如果页面内容和预期完全不符，先怀疑端口冲突/标签页不对，用 `Invoke-WebRequest` 直接请求验证服务器返回。
- **git 现已可用**（2.55.0，2026-09 装的）。此前"没有 git"的旧记录作废；老的 zip 安装替代方案（Releases 下 zip → Expand-Archive → 拷进 `.opencode/skills/`）在需要钉版本时仍然好用。
- **npm 11 有 install-scripts 拦截机制**：新装依赖后若报 scripts 被忽略，`npm install-scripts approve <pkg...>` + `npm rebuild`（sharp、unrs-resolver 都这样处理过）。全局装包同理（vercel CLI 的 esbuild 警告可忽略）。
- **re.sub 的 replacement 参数会把 `\n`/`\1` 当转义处理**，往文件里写多行文本必须用 lambda 替换（`re.sub(pat, lambda m: text, s)`），否则 TS/JS 双引号字符串会被真实换行写坏（踩过：siteConfig.ts systemPrompt 整站 500）。
- **vercel CLI 登录**：`vercel login` 走 device auth，输出 `https://vercel.com/oauth/device?user_code=XXXX-XXXX` 给用户点；后台进程被杀会导致授权成功但本地凭证没写入，`whoami` 仍是 Logged out——重新 login 即可。
- **webfetch 抓 github.com 仓库页会 Transport error**：改用 Playwright 浏览器打开；但 `raw.githubusercontent.com` 可以直接 webfetch 抓 README 原文。
- **raw 大文件下载会大面积超时**（小文件秒通不代表大文件能通）：换原作者官网直连当主源（如 ourednik.info 实测 250KB/s），或用 `curl.exe -sL --compressed`（文本传输省 80%）。大批量下载用 Python 预算制脚本：`.part` 原子写 + `as_completed(timeout=)` + 末尾 `os._exit(0)`，缺哪个补哪个。
- **"改了代码页面没变"先排浏览器缓存**：无头 Edge 全新 user-data-dir 也会启发式缓存旧 HTML，报错信息与旧代码一致而服务器返回已是新内容时，URL 加 `?nc=随机数` + `--disk-cache-size=1` 再下结论。CDP 杀无头进程要按 user-data-dir 过滤命令行，绝不按进程名乱杀。

# JS/HTML 验证流程

- 验证单文件 HTML 里的 JS：正则提取 `<script>(.*?)</script>` 内容写入临时 .js 文件，`node --check` 验证。
- `node --check` 报错行号是**脚本内部行号**，不是 HTML 文件行号，换算时要加 script 标签前的偏移。
- **保留字（`default`、`class` 等）作对象键必须加引号**；多行对象字面量要检查每个属性后的逗号（曾因 `grom:[...]` 数组结尾缺逗号导致下一行 `default` 解析错位，报错信息有误导性）。
- 报错信息里中文显示为乱码时，用 Python `open(path,'rb')` 按字节定位真实内容，别猜。
