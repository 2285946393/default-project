## 四、踩坑（今天新交的学费）

1. **`*.vercel.app` 被墙**：网站活着 ≠ 国内 HR 能打开。修法是把自有域名绑上去（今天铺完管道）。
2. **Vercel 域名认领的 403 是烟雾弹**：CLI 报"Not authorized"不告诉你真因（要 TXT 验证）；直接调 API 才拿到验证值。
3. **重加域名会轮换验证值**：删了重加一次，TXT 就作废一次，得跟着改——教训是别手痒重复 add。
4. **DSH 插件/皮肤折腾翻车**：把自己整坏到桌面崩溃、网页端打不开，重启不恢复。改皮肤/插件这类"动自己家"的操作，先备份再动手。
5. **免费 key 的不可靠性实测**：一晚上"通了/成功"发了几十条，21:06 五连重试。官 key 留着干正事，免费 key 只配打杂。
6. **整段替换代码会吞掉标记区间内的所有东西**：重写烟花场景时，夹在新旧标记之间的 `resize()` 和整个游戏状态段被一起吃掉，页面直接坏掉。**替换完必须立刻 `node --check` + 跑一遍**，标记的边界要先看清。
7. **旧标签页缓存会让人怀疑代码坏了**：改完怎么测都不生效，其实是浏览器一直给旧版本。**每次验收开缓存穿透的新标签**（`?v=时间戳`）。
8. **放置游戏的升级必须"眼睛看得见"**：第一版升级只改数字，被批"跟原来一模一样"。数字变大的同时，画面里要有对应的东西出现（船、灯、星河）——这条是产品层设计的通用道理。
9. **通用夜景 = 毫无特色**：星星+月亮+写字楼剪影是所有 demo 的默认答案。找场景身份要从主题本身长出来（烟花是中国的 → 水乡 + 河灯 + 倒影）。
