# 斗地主尖塔 · 整局流程示例（终端版输出存档）

> 这是 `bash run.sh -- --demo 20261006` 的原始输出，**三家全部交给电脑**，把一整局打到底。
> 留着它是为了：接手 UI 的人能一眼看清"每一屏上都有哪些信息、什么时候变"。
> 种子固定，结果可复现（`bash run.sh -- --demo 20261006` 一模一样）。

## 这一屏上有四块信息 —— 正好对应游戏里 UI 的四个位置

| 终端里的位置 | 游戏里该放哪 | 说明 |
|---|---|---|
| `底牌：` | **屏幕顶部正中**，三张横排 | 开局就亮，人人可见 |
| 三个座位的 `剩 N 张` + `← 场上最大` | **屏幕两侧/四角的头像**，头像是玩家自己的角色立绘 | 头像旁飘一个数字就是剩牌数；谁最大给谁一个高亮 |
| `场上：现在最大的是谁出的什么` | **桌面正中央** | 也就是牌桌上"别人打出来的那堆牌" |
| `我的手牌（N 张）` | **屏幕底部**，横排 | 序号 = 选中哪些牌 |
