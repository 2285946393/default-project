# 凛冬尖塔 · M3.2 已落地（建筑上战场 + 容量系统）wb

> 2026-10-06 17:35。**build 0 错 0 警，已部署**（`FrostSpire.dll` 77312 B）。
> 本轮把用户三次强调的「**建筑能放在场上挡伤害**」真正做出来了 —— 之前 M3.1 的建筑只是挂在玩家身上的 Buff。

---

## 一、这轮解决了什么（对照用户原话）

用户原话：「凛冬前线就是各种效果建筑堆在一起，去打伤害。感觉和能力牌很像。**只是建筑还能放在场上挡伤害**」

**M3.1 的做法**：建筑 = 挂在**玩家身上**的 Power（`IceWallPower` 等）→ **不在场上、不挡伤害**。❌ 与用户意象不符。

**M3.2 的做法**：建筑 = **一个我方阵营的 Creature**（站在场上、有血、会被打、能挡伤）。✅ 对了。

## 三、★ 核心技术发现（都是反编译实证，不是猜的）

### 3.1 怎么造「我方站场生物」（建筑的正解）

```csharp
CombatSide { None, Player, Enemy }

// ICombatState.CreateCreature(monster, side, slot) + CreatureCmd.Add
var building = combat.CreateCreature(new IceBulwarkM().ToMutable(), CombatSide.Player, slot: null);
await CreatureCmd.Add(building);
```

**关键区分**（三个概念互不相同）：
- `IsMonster` — 是生物（有血有模型）
- `IsPet` — 是宠物（有 `PetOwner`，**会主动协战**）← 民兵走这条（`PlayerCmd.AddPet`）
- `IsEnemy` — 是敌方（`Side == Enemy`）

**建筑 = `IsMonster && !IsPet && !IsEnemy`** —— 站场、不动、只挨打。

### 3.2 「静态物体」的已验证样板 = 本体 `BigDummy`（训练假人）

```csharp
protected override MonsterMoveStateMachine GenerateMoveStateMachine()
{
    var idle = new MoveState("FROST_BUILDING_IDLE", IdleMove, new HiddenIntent());
    idle.FollowUpState = idle;                    // 自己循环
    return new MonsterMoveStateMachine(new List<MonsterState> { idle }, idle);
}
private static Task IdleMove(IReadOnlyList<Creature> targets) => Task.CompletedTask;
```

**三个要点**：
1. 用 **`HiddenIntent`**（不是 `SleepIntent`）—— 训练假人就这么写
2. **`FollowUpState = self`** —— 永远待机
3. `VisualsPath` 是 `protected override`，v1 借 `creature_visuals/defect`（训练假人的视觉）

### 3.3 容量模型（照抄 MT2，见设计案第七节）

```csharp
GetUsedCapacity() = Σ「我方非玩家存活生物」.Size
CanDeploy(size)   = GetUsedCapacity() + size <= 5
```
- **容量 5 点**（MT2 真值）
- **冰垒 / 箭塔各占 2 点** → 一场最多摆 **2 座 + 剩 1 点**
- 满了牌变灰（`IsPlayable` override）

### 3.4 ⚠️ `state.CreateCard` 必须传 canonical

```csharp
public CardModel CreateCard(CardModel canonicalCard, Player owner)
{
    CardModel cardModel = canonicalCard.ToMutable();   // ★ 要求 canonical
    ...
}
```
→ **用 `state.CreateCard<T>(p)` 泛型版**（内部 `ModelDb.Card<T>()`），不要 `new CardX()`。

### 3.5 ⚠️ PowerModel 隐藏用 `IsVisibleInternal`

```csharp
protected override bool IsVisibleInternal => false;   // 不是 ShouldShowInStatusBar（不存在）
```

## 四、实测步骤（下一步必做）

1. **先在 mod 管理器打开 FrostSpire**（⚠️ 上次查是 `is_enabled: false`，不开等于没装）
2. 开「凛冬模式」，进一局 → 应收到 3 张卡（民兵 / 冰垒 / 箭塔）
3. **打个怪，然后打「冰垒」** → 看：
   - 场上是否多了个**站着的东西**（借训练假人模型）
   - 敌人打你时，伤害是否**转到冰垒头上**（冰垒掉血、你不掉）
   - 冰垒碎了 → 替伤是否失效
4. **打「箭塔」** → 每回合开始，是否**所有敌人一起掉血**
5. **容量**：先打冰垒 + 箭塔（2+2=4），再打第三座 → **应该变灰打不出**
