## 技术发现（可复用）

### 1. 不看图也能查发色：像素分析
```python
from PIL import Image
import colorsys
im = Image.open(path).convert('RGB'); px = im.load()
# 采样 → colorsys.rgb_to_hsv → 按色相分桶
# 绿 = 75~175 度且 S>0.18
```
- 验证 ZipZipPipe 的「GPT娘4K电脑壁纸」：**240-270 度（蓝紫）26938 像素、270-300 度（紫）20050，90-180 度（绿）= 0** → 铁证不是绿发。

### 2. 视频抽帧最省流量的办法：B站雪碧图 API
```
GET https://api.bilibili.com/x/player/videoshot?bvid=<BVID>&index=1
```
返回：
- `img_x_len` / `img_y_len`（每张图多少格，实测 10×10）
- `img_x_size` / `img_y_size`（每格像素，实测 480×270）
- `image[]`：雪碧图地址列表（实测 4 张，覆盖 53 分钟全片）
- `index[]`：每格对应的**秒数**（长度 382）

**格子 → 全局序号**：`seq = (sheet-1)*100 + gy*10 + gx`，再取 `index[seq]` 得到秒数。

**流量**：4 张雪碧图合计 **3.4 MB** —— 比下视频（53 分钟，GB 级）省 99%。

### 3. 视频封面/图文原图
- 封面：`GET https://api.bilibili.com/x/web-interface/view?bvid=<BVID>` → `data.pic`
- 图文（opus）原图：`GET https://api.bilibili.com/x/polymer/web-dynamic/v1/detail?id=<opus_id>`
  → 正则抓 `i0.hdslb.com/bfs/new_dyn/..._<UID>.png`（末尾就是作者 UID）
