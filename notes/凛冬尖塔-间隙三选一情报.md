# 凛冬尖塔 · 间隙补给「三选一」情报（wb → ZCode）

> 起源：ZCode 16:14:59 自己发现的思路 ——
> 「quest-spire 当年放弃官方选牌界面是因为拿不到 `PlayerChoiceContext`——但我们的间隙钩子**手里就有**这个 context！」
> **这条思路完全成立，且官方有现成样例。** 下面是逐条实证。

---

## 一、结论：能用**游戏原生选牌界面**，官方有标准写法

`CardSelectCmd.FromChooseACardScreen` 就是干这个的，**官方用它做"战斗内三选一"**。

### 签名（sts2.dll）

```csharp
public static async Task<CardModel?> FromChooseACardScreen(
    PlayerChoiceContext context,      // ← ZCode 的 choiceContext 参数正好是它
    IReadOnlyList<CardModel> cards,   // ← 候选牌（上限 3 张！）
    Player player,
    bool canSkip = false)
```

### 官方文档原话（照抄，非推断）

> Begins card selection for the given player, selecting from a small list.
> **Only works with a small number of cards (right now 3 or fewer). Good for in-combat card generator effects like Attack Potion.**
> If the player is the local player, this brings up the card selection screen.

**「Good for in-combat card generator effects」——官方明说了这是战斗内用的。** ZCode 的顾虑（quest-spire 当年没做成）在这里被官方文档直接推翻。

## 二、★ 官方标准样例：`AttackPotion`（照抄就能跑）

`MegaCrit.Sts2.Core.Models.Potions.AttackPotion` 的完整实现（反编译原文）：

```csharp
List<CardModel> cards = CardFactory.GetDistinctForCombat(
        player,
        player.Character.CardPool.GetUnlockedCards(player.UnlockState, player.RunState.CardMultiplayerConstraint)
              .Where(c => c.Type == CardType.Attack),
        3,                                          // ← 三选一
        player.RunState.Rng.CombatCardGeneration)
    .ToList();

CardModel cardModel = await CardSelectCmd.FromChooseACardScreen(choiceContext, cards, player, canSkip: true);

if (cardModel != null)
{
    cardModel.SetToFreeThisTurn();                  // 战斗内免费打
    await CardPileCmd.AddGeneratedCardToCombat(cardModel, PileType.Hand, base.Owner);
}
```

### ★ 和 ZCode 现有 `GrantSupplyCardAsync` 的差距 = 4 行

ZCode 现在写的是：

```csharp
var cards = CardFactory.GetDistinctForCombat(Owner, pool, 1, Owner.RunState.Rng.CombatCardGeneration).ToList();
if (cards.Count == 0) return;
await CardPileCmd.AddGeneratedCardsToCombat(cards, PileType.Hand, Owner, CardPilePosition.Bottom);
```

**改法（对齐官方样例）**：

```csharp
var cards = CardFactory.GetDistinctForCombat(Owner, pool, 3, Owner.RunState.Rng.CombatCardGeneration).ToList();
if (cards.Count == 0) return;
var picked = await CardSelectCmd.FromChooseACardScreen(choiceContext, cards, Owner, canSkip: true);   // ★ 新增
if (picked == null) return;                                                                            // 玩家跳过
await CardPileCmd.AddGeneratedCardToCombat(picked, PileType.Hand, Owner);                              // 单数版
```

**注意三个点**：
1. **`GrantSupplyCardAsync` 需要多传一个 `PlayerChoiceContext choiceContext` 参数**（从 `BeforeSideTurnStart` 的第一个参数直接透传）——**现有钩子手里就有**。
2. 最后一步换成**单数** `AddGeneratedCardToCombat`（因为它只加一张），签名是
   `(CardModel card, PileType newPileType, Player? creator, CardPilePosition position = Bottom)`——`position` 有默认值，可省。
3. `canSkip: true` 让玩家能跳过。跳过返回 `null`，必须判空。

**这不是"要做新功能"，是填 4 行洞。** 现有 `GrantSupplyCardAsync` 的池子取法、RNG 取法、守卫全部可复用。

## 三、★ 硬约束（必须知道，否则会崩）

| 约束 | 内容 | 后果 |
|---|---|---|
| **上限 3 张** | `if (cards.Count > 3) throw new ArgumentException("Only works with less than 3 cards")` | 传 4 张直接**抛异常** |
| **0 张** | `if (cards.Count == 0) { ReportSoftlock(); return null; }` | 返回 null + 报 Sentry，不崩但会记录 |
| **返回值可空** | 玩家跳过 / 远程玩家异常 → `null` | **必须判空**，否则 NRE |
| **多人的本地/远程分支** | 本地玩家弹屏幕；远程玩家等它选 | 单人局走本地分支，无需特殊处理 |

**给 ZCode 的建议**：既然上限就是 3，**`GetDistinctForCombat` 的 `count` 直接写死 3**，别动态算（池子小于 3 时它自然会少给，`FromChooseACardScreen` 也能处理 1~2 张）。

## 四、附带发现：`UndoEndTurnIfNecessary`（这个很妙）

`FromChooseACardScreen` 内部第一件事就是：

```csharp
UndoEndTurnIfNecessary(player);
// 实现：if (CombatManager.Instance.IsPlayerReadyToEndTurn(player) && ... CurrentSide == Player)
//           CombatManager.Instance.UndoReadyToEndTurn(player);
```

**含义**：如果玩家已经点了「结束回合」，这个方法会**自动把"结束回合"撤销**，把控制权还给玩家选牌。

**对我们特别重要**：ZCode 的 M2 v1 设计里，**「点结束回合 = 叫下一波」**。
如果波次刷在 `BeforeSideTurnStart`（新回合开始时），此时玩家的回合刚开始，`IsPlayerReadyToEndTurn` 一般是 false，**碰不到这个分支**——没问题。

但如果将来想在「玩家点结束回合的瞬间」弹选牌（而不是下一回合开始），**这个保护会救一命**。记一笔，M2.5 可能用得上。

## 五、给 ZCode 的落点

1. **M2.5 的「补给改三选一」可以直接用官方界面**，不用自研浮层（原计划「照 QuestSelection 手艺做自己的选牌浮层」**作废**，省一大堆活）。
2. 改动集中在 `GrantSupplyCardAsync`：**加一个 `choiceContext` 参数 + 4 行**（见二）。
3. 记得把 `PileType` 相关的 using 检查一遍（`CardSelectCmd` 在 `MegaCrit.Sts2.Core.Commands`，与现有 `CardPileCmd` 同命名空间，**不用加 using**）。
4. **`CardModel.SetToFreeThisTurn()`** 官方样例里有——间隙补给要不要"本回合免费"？v1 决定权给 ZCode（我倾向**不加**：补给是资源，免费就打乱数值了）。
