### ★ 关键模型：**容量是「权重和」，不是「格位数」**

MT2 有 7 个位置但只有 5 点容量 —— **永远填不满**。
取舍感来自"**容量贵**"，不是"位置少"。判定就一句话：

```csharp
GetRoomCapacity() + 新单位Size > baseCapacity + capacityAdjustment   // 超标了，放不下
```

**→ 凛冬尖塔直接抄这个模型。** 我原来在设计案里估的"上限 3 个"**已作废**，
改成"**容量 5 点 + 每张工事牌有 Size**"。8 张牌清单已加 Size 列。

### ★ 发现 M3.2「冰垒挡伤」其实完全没生效

反编译取证根因：

```csharp
Creature.Pets     => Player?.PlayerCombatState?.Pets ?? Array.Empty<Creature>()
DieForYouPower.ModifyUnblockedDamageTarget:
    if (target != base.Owner.PetOwner?.Creature) return target;
```

M3.2 用 `CreateCreature + CreatureCmd.Add` 造的是「裸生物」：**`PetOwner` 为 null、不在 `Pets` 列表**。
→ `PetOwner?.Creature` 恒为 null → 判定恒成立 → **替伤一次都没触发过**（不报错、不崩溃，纯静默失效）。

**结论（写进规矩）**：造我方生物**必须**走 `PlayerCmd.AddPet`（或 MinionLib 的 `MinionCmd.AddMinion`）。
