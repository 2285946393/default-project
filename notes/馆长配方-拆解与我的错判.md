## 三、拆解：他到底做对了什么

### 1. ★ 用了权重块（这是最该学的一条）

- **正向**：`2::( …… 一整串细节 …… )::` —— 把核心细节簇**整体加权到 2 倍**
- **负面**：`4::multiple views, simple illustration, chibi, wrong hands, wrong feet ……::` —— 4 倍权重

我给的所有提示词**一次都没用过权重块**。这是最大的差距之一。

### 2. ★ 提示词密度极高

数一下：正向约 **50+ 个概念**，其中一大半是**特效 / 氛围词**：
`floating / glowing / gradient / blending / bright / 虚化 / 漩涡 / 雾气粒子 / 分层构图 / double exposure`

我的提示词偏"描述客观内容"（谁在哪做什么），他的偏"堆视觉特效"。
**顶级卡面的观感 = 特效词密度，不是内容词准确度。**

### 3. 质量词放在中间，不是最后

`very aesthetic, masterpiece, no text` 出现在**第二行**，后面还接了一大堆内容。
（官方写法指南说质量词必须放最后 —— 但他就是这么用，且效果顶级。
说明这条不是铁律。）

### 4. 结构顺序

```
主体 + 花/粒子 + 角色名 + 构图词 + 服装/头发动态 + 光效
→ 质量词
→ 眼睛/表情细节
→ 2::(核心细节大权重块):: 
→ 收尾（服装/场景/手部动作/机位）
```

### 5. 题材：二游角色

`hiyuki (Wuthering waves)` = **鸣潮**的角色。
二游角色在训练数据里量大质高，本身就容易出好图。

### 6. `cleached hands` 是拼错的

应该是 `clenched hands`。**馆长也会拼错字**，不影响出图 —— 别因为一个词写错就慌。

## 四、关于中文：**中文基本是无效的**

他写了大量中文：`金属质感反光在刀刃上 / 分层构图 / 自下而上红白渐变 / 飞行 / 雾气粒子 /
樱花树 / 水墨 / 线型排列的千纸鹤划过背景 / 燃烧的白色鸟居 / 鸟居 / 神社 / 铃铛 /
冰霜旋风 / 漩涡 / 高楼大厦 / 飘动的红丝带 / 浮世绘在剑中 / 虚化 / 擦拭剑 / 和服 / 伸出两根手指摸剑刃`

**但权威写法指南（nai5-prompting，基于 962 条真实提示词）明确写：**

> **角色名和作品名只认 ASCII** —— 必须是 danbooru 的英文或罗马音写法，
> **不用中文名代替规范标签**。

**结论**：模型对中文是 out-of-distribution，**认不出这些中文的意思**。
它们大概率是**无害噪声**（不坏事，但也不起正面作用）。

**证据**：他画里的关键元素其实**英文里也都有** ——
`glowing white torii`（鸟居）、`red sky`、`cityscape`、`mountains`、`snow flakes`、`ice sword`、`holding sword`。
真正让画面成立的，是**英文那部分**。

**所以：别学他写中文。** 把中文想法翻成英文 danbooru 标签，效率更高。

## 五、修正后的正确流程

1. 先写**内容**（角色、姿势、场景）—— 英文 danbooru 标签
2. **堆特效/氛围词**（这是观感的关键，宁多勿少）：
   `floating hair, glowing light lines, light particles, gradient, double exposure, blending, bright, soft glow, rim light, depth of field, layered composition`
3. 加**质量词**：`very aesthetic, masterpiece, no text`
4. 用 **`2::(核心细节簇)::`** 把最重要的那组（光效 + 道具 + 氛围）整体加权
5. 负面词里放 **`4::wrong hands, wrong feet, mutated hands, extra fingers, simple illustration, chibi::`**
6. 参数：**Scale 5、CFG 0.2、启用多样性 ON**、832×1216、Euler Ancestral / Karras、28 步
7. **画师串可选** —— 馆长的「正向提示词」框里**没有画师串**。
   （但截图只显示了「提示词」这个标签页，**画师串有可能放在站内的「前置 / 后置」字段里，截图没展开** —— 这点还没证实，别下死结论。）
