# 全息镭射卡 · 做法与原理

成品：`pages/全息镭射卡.html` —— 单文件、双击就能开、零依赖、能导出图片。
素材与中间产物：`assets/全息镭射卡/`（四层图 + card.glb）。
生成器：`tools/holo-card/make_card.py`。

## 再做一张怎么改

1. 准备渲染器（**不用装 Blender**）：clone `https://github.com/HRuiCcc/RuiC-card-skill`，
   用它 `assets/web-template/` 里的 `style.css` / `app.bundle.js` / `index.html`（MIT，保留版权声明）。
2. 改 `make_card.py`：

   | 想改什么 | 改哪 |
   |---|---|
   | 卡名 / 称号 / 编号 / 文案 | `main()` 里的 `cfg` |
   | 人物长相 | `draw_character()` |
   | 背景 | `make_background()` |
   | 文字和卡框 | `make_text_layer()` |

3. 跑：

   ```
   python tools/holo-card/make_card.py --vendor <web-template 目录> --out pages/全息镭射卡.html
   ```

## 踩过的坑（下次别再踩）

- **不用 Blender**：Blender 便携版 380MB，而且 `download.blender.org` 这边直连 403（要开代理）。
  卡牌几何很简单，直接用脚本写成 glTF 就行：
  正面 6.3×9.45 圆角矩形 + 背板 + 侧边 + 两条压边（外圈镭射、内圈古金）。
- **UV 要按 glTF 约定翻转**：`v = 0.5 - y / 卡高`。
  渲染器里是 `vUv = 1 - uv.y` 配 `flipY=true` 的纹理，两处翻转叠起来画面才是正的——
  照抄 Blender 的 UV 值会上下颠倒。
- **文字层两条硬规矩**：
  1. 阴影**先画**、文字后画（反了会变成"挖空字"，我第一版就中招）；
  2. 卡框要画在文字层里——这一层不参与景深，框才会死死贴住卡边。
- **贴图当线性色用**：着色器最后 `pow(2.2)` 再转 sRGB，所以 PNG/JPG 里画什么颜色、卡上就是什么颜色，
  不用自己预压暗。
- **几何无关灯光**：卡面材质不吃法线，`NORMAL` 随便填 `(0,0,1)` 也不影响。
