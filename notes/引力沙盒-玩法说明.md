# 引力沙盒 · Gravity Sandbox 玩法说明

双击 `引力沙盒.html` 即可在浏览器中离线运行，无需联网、无需安装。

## 核心玩法

**按下定位置，拖出方向和速度，松开就诞生一颗星。**

- 左键在画布空白处按下 → 拖动（虚线箭头显示初速度方向和大小）→ 松开，天体出现在按下的位置，按你拖出的方向飞出去。
- 拖得越长，初速度越大；拖的方向就是它出发的方向。
- 天体之间遵循真实牛顿引力：互相吸引、绕行、合并、引力弹弓甩出。

## 七种天体

| 天体 | 特点 |
|---|---|
| 小行星 / 卫星 | 质量小，容易被甩飞，适合做"尘埃" |
| 行星 / 巨行星 | 中等质量，能稳定绕恒星转 |
| 恒星 | 大质量发光，会脉动，是星系的中心 |
| 红巨星 | 超大质量，能撕碎小星系 |
| 黑洞 | 质量最大，带旋转吸积盘，吞噬一切靠近的天体 |

## 六个预设场景

- **太阳系**：经典的太阳+六行星，看稳定轨道。
- **双星共舞**：两颗恒星互相环绕，周围行星在混沌中寻找轨道。
- **三体混沌**：三颗恒星的经典三体问题，永远不会重复。
- **星系碰撞**：两个星系对撞，最壮观的预设，天体被拉扯、撕碎、重组。
- **黑洞吞噬**：一个黑洞+60颗天体，看漩涡式吞噬。
- **随机星团**：随机生成，每次都不一样。

## 操作

- **左键拖拽**：放置天体（方向长度=初速度）
- **右键 / 中键 / Shift+左键 拖拽**：平移相机
- **滚轮**：缩放（以鼠标位置为中心）
- **空格**：暂停 / 继续
- **G**：隐藏 / 显示右侧面板
- **P**：保存当前画面为 PNG
- **C**：清空宇宙
- **R**：随机生成一个新星团

## 参数调节

- **时间速度**：0～5倍，快进看星系演化。
- **引力常数 G**：调大引力更强、更容易合并；调小更松散。
- **拖尾长度**：0～400帧，长拖尾看轨道弧线，关掉更干净。
- **发光效果 / 天体名称**：按需开关。

## 好玩技巧

1. **星系碰撞里丢一颗黑洞**：选黑洞，在两个星系之间拖放，看它同时吞噬两个星系。
2. **造双星**：放两颗恒星，给它们相反方向的初速度，看它们互相绕转，再丢行星进去。
3. **引力弹弓**：让一颗小行星近距离掠过大质量天体，会被加速甩出去。
4. **慢放看合并**：时间速度调到0.3，看两颗恒星碰撞合并的爆炸细节。
5. **调大 G**：引力常数拉到3，整个星团会快速坍缩成一个大天体。

## 技术说明

基于牛顿引力 N-body 物理，子步半隐式欧拉积分（高速稳定不爆炸）、软化引力避免奇点、碰撞合并动量守恒、发光天体与黑洞吸积盘渲染。参考 Genicleito 轨道模拟器的天体类型设计重写，零依赖单文件。
