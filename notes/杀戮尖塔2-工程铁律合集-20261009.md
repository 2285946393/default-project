## 3. 加载顺序 / 开关 mod

- **停用 mod 用游戏设置里的开关**，不是挪 `mods/` 目录。
  ⚠️ `ReadModsInDirRecursive`（`ModManager.cs:550`）是**递归**的 → 建 `_disabled/` 子目录 **等于没关**。
  ⚠️ `mod_list` 为空时设置页的勾选框**静默无效**（本机实测是 `null`）。
  ★ API：`ModSettings.IsModDisabled(id, source)`。
- **★★★ 顺序真相**：
  `RemoveDisabledMods`（`:481`，双来源去重）→ `SortModList`（`:345`，**Kahn 拓扑排序**，
  优先级 = `mod_list` 里的下标，不在表里给 `999999999`）→ 加载 → **`:289` 回写 `settings.save`**。
  → **① 手动顺序只是平局决胜、存不住；② 唯一可靠的持久状态是 `IsEnabled`。**
  ★ 日志里搜 `Mods have been re-sorted` 能看到它确实重排了。
- **★★★ 真 bug（`:293`）**：回写用 `FirstOrDefault(m => m.Id == mod.manifest?.id)`，**只按 `Id` 丢了 `Source`**
  → 同 id 双来源拿到**同一个** `IsEnabled`，按来源分别开关会被吞。
  绕法（`ModPresetManager`）：按 `(Id, Source)` 抄快照 → `CallDeferred` 等 `State == Initialized`（≤120 帧）→ 写回。
- ★ **免费权威顺序表**：`…/.combatsolver-precombat/process-<pid>/startup-mods/`
  （本机实测 `33_LoadOrderManager` → `34_RitsuLib` → `42_CombatSolver` → `51_BaseLib` → `70_DouSpire`）。
- **日志在 `%APPDATA%\SlayTheSpire2\logs\`**（**不在游戏目录**）。

## 4. ★★ 程序集解析：mod 的「兄弟托管 dll」不会被自动找到

游戏把 mod dll 拉进**默认 ALC**（`ModManager.cs:954`），而**默认 ALC 不探被加载 dll 所在目录**
→ 旁边放 `Dep.dll` **解析不到**（`HandleAssemblyResolveFailure` `:1165` 只特判 `sts2,` / `0Harmony,`）。

> **规则：要带自己的托管依赖，必须自己 `Assembly.LoadFrom(自己目录/xxx.dll)` 或挂 `Resolving` 回调，
> 且要足够早（`[ModuleInitializer]` / mod init）。**
> ★ 用当前 ALC：`AssemblyLoadContext.GetLoadContext(typeof(壳).Assembly).LoadFromAssemblyPath(path)`。
> ★ 完整实现抄 `JmcModLib.Dispatch.BootstrapDependencyResolver`（见 §5）。

**★ 连带坑**：BaseLib 的 `PostModInitPatch.LatePostInit()`（挂在 `ModelDb.InitIds` 的 Prefix 上）
会对**所有 mod 类型**的每个静态字段执行 `CheckSpecialSpireField`，第一行就是 `Type fType = field.FieldType;`
**且没有 try/catch** → **mod 里任何静态字段的类型都不能来自「加载不到的」程序集**，否则启动弹错误框。

## 5. ★★★ 「壳 + 版本化实现」＋ 怎么写 `settings.save`

### 5.1 壳 + 版本化实现（这套结构见过 6 次）

RitsuLib / 尖塔：琐事 / 意图图 / LoadOrderManager / RandomForeseer /
**`JmcModLib.Dispatch`（`<Mod>.dispatch.json` + `runtimes/<游戏版本>/*.Runtime.dll`）—— 最规范，优先抄。**

- 入口 `[ModInitializer]`；版本探测 `ReleaseInfoManager.Instance.SemVer`；
  取 `minGameVersion <= 宿主` 里**最高的**那个实现。
- ★ 选中后**同步 `manifest.version` + `mod.version`**，否则依赖校验 / Mod UI / 联机列表看到的是**壳版本**。
- ★ **游戏会把 mod 目录下每个 `.json` 都当清单递归解释** → 多版本子目录里**别放 `.json` 清单**，用 `.manifest`。
- PCK 挂载 / 失败上报 / 适配成本实证 → `notes/杀戮尖塔2-拆解-模组预设同步-20261009.md` §2/§8。

### 5.2 怎么写 `settings.save`

`MegaCrit.Sts2.Core.Modding`：`ModSettings`（`mods_enabled` / `mod_list`）、
`SettingsSaveMod`（`id` / `source` / `is_enabled`）、`ModSource{None, ModsDirectory=1, SteamWorkshop=2}`。

- ★ **`Id` 单独不唯一，必须配 `Source`** → 唯一键 `"{id}::{source}"`。
- 读：`SaveManager.Instance.SettingsSave.ModSettings.ModList`；
  写：塞回 `.ModList` → `SaveManager.SaveSettings()`。★ 写盘要包 try/catch 并回滚内存。
- **★★ 写盘前做账户隔离守卫**：运行时账号（`PlatformUtil.PrimaryPlatform` → `GetLocalPlayerId`）
  必须 == 路径里的账号（正则 `[/](steam|gog|epic|xbox|none)[/](?<id>\d{1,20})`）。

## 6. ★★★ 休息处（篝火）选项

细节 → `notes/杀戮尖塔2-拆解-休息处扩展-20261009.md`。

- **官方口子**：`AbstractModel.TryModifyRestSiteOptions(Player, ICollection<RestSiteOption>)`；
  触发点是 `RestSiteOption.Generate(player)`。
  ⚠️ 必须写 `if (player != base.Owner) return false;`（照 `Shovel`），否则**多人时给所有人加选项**。
- **★ 隐形炸弹**：`RestSiteSynchronizer.ChooseLocalOption(int index)` 同步的是 **uint 下标**，
  每人选项表**各自本地生成**，接收端**只校验越界**
  → **两端差一个元素，同一下标指向不同选项，静默错。**
  → **给休息处加选项的 mod，选项顺序必须确定性**（固定排序表 + `RankOf`）。
  ★★ DouSpire 的做法：两个玩法选项**共用同一个单例**，在
  `DouSpireRestSiteSingleton.TryModifyRestSiteOptions` 里**按写死顺序 `Add`**
  —— **以后再加选项一律加进这个方法**。
- `ShouldDisableRemainingRestSiteOptions(Player)` 默认 **true**；连选多项返回 false。
  每人选过什么游戏自己记了（`CurrentMapPointHistoryEntry…RestSiteChoices`）—— **别自己存**。
  配置分歧用**房主权威**（RitsuLib `RunSavedData` + `SyncLobbyOnChange=true`）。
- **★ 图标坑**（DouSpire 踩过）：`RestSiteOption.Icon` 只读 `res://`；`has_pck:false` 的 mod 给假 `res://` 路径会
  **永久污染 AssetCache** → 图标错 + 标题回落「挖掘」+ 点击**卡死**。
  解法：自挂小 pck（`assets/DouSpire.icon.pck`，**唯一挂载点 = `DouSpireRestIcon`**）+ `ResourceLoader.Exists()`
  + 回落 `option_clone.png`。**manifest 绝不能写 `has_pck:true`**（`LoadResourcePack` 失败即抛异常 → **整个 mod Failed**）。
  ★ **打 pck 必须先 `--import`** 再 `--export-pack`。

- **弹幕尖塔 DanmakuSpire（`3779807977`，`deps: []`）= 「兼容性工程」标准答案**
  （**「弹幕」= B 站式滚动评论，不是弹幕射击**）→ `notes/杀戮尖塔2-拆解-弹幕尖塔-20261009.md`。
  **三条照抄**：① **逐补丁 try + 优雅降级**（连 `ReflectionTypeLoadException` 都兜）；

  + **镜像方法**（按**精确运行时类型**分发）+ **风险记账**。**绝不调真 virtual 方法。**

  ★ 风险 5 因 → `IHoverTip` 给玩家看。**推断结果强制打"不完整"标记。核心姿态 = 不确定就明说。**

## 8. ★★ 游戏本体 RNG 机制（斗地主 AI 的地基）

细节 → `notes/杀戮尖塔2-拆解-随机数预测-20261009.md` §2。

- **`Rng`**：内部 `MegaRandom`（**Xoshiro256**）+ `int _counter`。
  ★ **克隆两行** `new Rng(rng.ToSerializable())`（**游戏没给 `Clone()`**）。
  **`SerializableRng = { counter, state0..state3 }`（4×ulong）**，实现 **`IPacketSerializable`** → **能联网传**。
- ⚠️ **v0.109.0 破坏性变更**：「seed + counter 重建」→「序列化完整 Xoshiro 状态」。
  `Seed` / `Counter` / `FastForwardCounter` **已移除**。
- **`RunRngSet` 12 条流** + **`PlayerRngSet` 3 条**（`Rewards` / `Shops` / `Transformations`）；
  种子 = `run seed + 流名哈希` → **同 seed 同流必同结果**。12 条流名单 → 笔记 §2。
- ⚠️ run 内种子不许变；✅ `MockRng(type, seed)` 可按流换种（测试用）。

## 9. ★★★ 游戏网络层（netcode 的核心）

细节 → `notes/杀戮尖塔2-拆解-中国人能飞-20261009.md`；`projects/ref-combatflight/`。
**★ API 全清单 → `notes/杀戮尖塔2-游戏API速查-20261009.md` §一。**

1. **自定义消息 = 实现 `INetMessage : IPacketSerializable`，启动自动注册**
   （`MessageTypes.Initialize()` → `ReflectionHelper.GetSubtypesInMods<INetMessage>()`）。
   **★ 必须有 public 无参构造**。
2. **★ 收到不认识的类型 id**：`IsRunningModded()` 时**只警告一次然后静默丢弃**
   → **两端 mod 集合不同 = 消息静默丢失，不报错**。
3. **★★★ `ContentSorter` 是联机 id 分配的统一排序器**：id **不是注册顺序**，是排序后的下标；
   **第一排序键 = `affectsGameplay` 降序（`false` 排末尾）**
   → **`affects_gameplay` 是联机 id 稳定性的开关，必须诚实标注**。
   它被 `ModelIdSerializationCache` / `MessageTypes` / `ActionTypes` **三处共用**
   → `AssociateAssemblyWithMod` 不调时三套 id 一起错位。
   ★★ **官方口径**：「联机必要」= `affects_gameplay:true` ＋ `manifest.dependencies` 传递闭包
   （`ModPresetManager.FindMultiplayerDependencyClosure`）。
4. **`INetGameService.Update()` 必须定期调**，否则什么都不处理。
5. **★ RitsuLib Sidecar = mod 自己的频道**：`RitsuLibSidecarOpcodes.For(ModId, "table.in")`；
   **必须先 `RitsuLibSidecarProtocol.EnsureDefaultHandlers()`**（晚了赶不上大厅握手 → 静默丢消息）。
   `DouSpireNet`（1053 行）= 三频道 `table.in/open/act` + 座位映射 + `CastXxx` 广播。
   **P4 德州另起 `poker.*`，别动它**（`Seats=3` 写死且已上架）。

**初始化锚点**：`LocManager.Initialize` → `AssemblyInfo.Init` → `ModelDb.Init` →
`ModelIdSerializationCache.Init` → `ModelDb.InitIds` → `MessageTypes.Initialize` → `ActionTypes.Initialize`。
