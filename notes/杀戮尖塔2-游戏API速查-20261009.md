## 一、网络层（`MegaCrit.Sts2.Core.Multiplayer`）

> 来源：拆 `CombatFlight`（`notes/杀戮尖塔2-拆解-中国人能飞-20261009.md`）

### 1.1 自定义消息

```csharp
public class MyMessage : INetMessage          // INetMessage : IPacketSerializable
{
    public bool ShouldBroadcast => true;      // 发给 host 时会被转发给所有客户端
    public NetTransferMode Mode => NetTransferMode.Reliable;   // None=0 / Unreliable=1 / Reliable=2
    public LogLevel LogLevel => LogLevel.VeryDebug;            // 一般用 0
    public bool ShouldBuffer => true;

    public string Text { get; set; } = "";
    public int Value { get; set; }

    // ★ 必须有 public 无参构造（NetMessageBus 用 Activator.CreateInstance 造）
    public void Serialize(PacketWriter w) { w.WriteString(Text); w.WriteInt(Value); }
    public void Deserialize(PacketReader r) { Text = r.ReadString(); Value = r.ReadInt(); }
}
```

**自动注册**：`MessageTypes.Initialize()` →
`list.AddRange(INetMessageSubtypes.All)`（本体 52 个）+ `list.AddRange(ReflectionHelper.GetSubtypesInMods<INetMessage>())`
→ `_cache = new NetTypeCache<INetMessage>(list)`。**实现即注册，不用手动登记。**

### 1.2 收发

```csharp
var net = RunManager.Instance.NetService;
net.SendMessage(new MyMessage{...});                  // 广播
net.SendMessage(new MyMessage{...}, playerId);        // 定向（仅 host 可用）
net.RegisterMessageHandler<MyMessage>((msg, senderId) => { ... });
net.UnregisterMessageHandler<MyMessage>(handler);     // 记得在 _ExitTree / Unbind 里解
```

包格式：`[1 字节类型 id][8 字节 senderId][消息体]`。

**★ 收到不认识的类型 id**：`ModManager.IsRunningModded()` 为真时**只打一次警告然后静默丢弃**
（"we are assuming this is a message that does not affect gameplay"）；否则打 Error。
→ **两端 mod 集合不同 = 消息静默丢失、不报错。** 排查联机「没反应」先想这条。

### 1.4 `PacketWriter` / `PacketReader`

`WriteBool` / `WriteByte(byte, int bits = 8)` / `WriteBytes` / `WriteShort|WriteUShort(int bits = 16)` /
`WriteEnum<T>` / `WriteInt|WriteUInt(int bits = 32)` / `WriteFloat(float, QuantizeParams? = null)` /
`WriteLong|WriteULong(int bits = 64)` / `WriteDouble` / `WriteVector2(Vector2, QuantizeParams? x, QuantizeParams? y)` /
`WriteList<T>(IReadOnlyList<T>, int lengthBits = 32) where T : IPacketSerializable, new()` /
`WriteString` / `Write<T>(T) where T : IPacketSerializable`。

→ **支持位宽压缩 + 浮点量化**，位置同步这种高频包很值得用。

### 1.5 `ContentSorter`（联机 id 分配）

`NetTypeCache<T>` 的 id = **`ContentSorter.Sort` 排序后的下标**（不是注册顺序）。优先级：

1. **`affectsGameplay` 降序**（`false` 排末尾）
2. 类型 `Name`
3. 有无 mod
4. `manifest.id`
5. 类型 `FullName`
6. 程序集 `FullName`（全 `CompareOrdinal`）

游戏注释原话：`false` 排末尾是为了 *"players without those mods will still have a stable and
deterministic sorting of IDs that will be sent over the network"*。

→ 被 `ModelIdSerializationCache` / `MessageTypes` / `ActionTypes` **三处共用**。
不调 `ModManager.AssociateAssemblyWithMod` 时报的
`not associated with any mod ... errors in multiplayer`，
**坏的是「消息 id + 动作 id + 模型 id」三套一起错位**。

### 1.6 初始化锚点

`OneTimeInitialization.ExecuteEssential()`：
`LocManager.Initialize()` → `AssemblyInfo.Init()` → `ModelDb.Init()` →
`ModelIdSerializationCache.Init()` → `ModelDb.InitIds()` → **`MessageTypes.Initialize()`** →
**`ActionTypes.Initialize()`**。

### 1.7 位置同步配方

**相对偏移**（只发 `Position - Origin`）+ **序号去重**（环形比较
`IsNewerSequence(seq, prev) => seq != prev && (seq - prev) < 0x80000000u`）+
**按需限流**（移动 20/s、静止 1.3/s）+ **`IsFinite` 拒 NaN/Inf** + `ClampNetworkOffset(±10000)` +
`NormalizeRotation(-π..π)` + **`message.Location == _runLocation` 一致性校验**（不同战斗整包丢弃）+
忽略自己发的包 + `PruneDisconnectedFlyingPlayers()` + 绑定/解绑成对（解绑包 try/catch）。

## 三、pck / 脚本注册 / 本地化

> 来源：`ModPresetManager`（`notes/杀戮尖塔2-拆解-模组预设同步-20261009.md` §7）

### 3.1 pck 内 C# 脚本

- **路线 A（优先）**：`RitsuLibFramework.EnsureGodotScriptsRegistered(assembly, logger)`
- **路线 B**：自建 Godot 引导程序集
  ```csharp
  namespace GodotPlugins.Game;
  internal static class Main {
      [UnmanagedCallersOnly(EntryPoint = "godotsharp_game_main_init")]
      private static godot_bool InitializeFromGameProject(...) {
          ...
          ScriptManagerBridge.LookupScriptsInAssembly(typeof(Main).Assembly);
          return (godot_bool)1;
      }
  }
  ```
- 控件类打 `[ScriptPath("res://Scripts/Ui/Xxx.cs")]`，路径要和 pck 内路径一致。
- pck 内会带 `.godot/global_script_class_cache.cfg`（实测可只有 8 字节）、`.godot/uid_cache.bin`、`project.binary`。

### 3.2 ★★ mod 自带本地化

**路径约定**：`res://<ModName>/localization/<lang>/<表名>.json`，语言码 `eng` / `zhs`。
**格式**：扁平 `key → 文本`，键带 mod 前缀。

```json
{
  "MOD_PRESET_MANAGER.preset.title": "模组预设",
  "MOD_PRESET_MANAGER.preset.tooltip.export.action": "把配置复制到剪切板。\n{description}"
}
```

**读取**：

```csharp
private const string Table  = "main_menu_ui";         // 蹭游戏原有表名
private const string Prefix = "MOD_PRESET_MANAGER.";
public static string Text(string key, params (string Name, string Value)[] vars) {
    LocString s = new LocString("main_menu_ui", Prefix + key);
    foreach (var v in vars) s.Add(v.Name, v.Value);
    return s.GetFormattedText();
}
```

→ **给 mod 自己新增的 UI 加中英文案就用这个，别改本体本地化文件。**
`{占位符}` 机制和梗化尖塔处理的是同一套。

| API | 用途 |

回调里**校验 `m_unAppID.m_AppId == 2868840`**（防别的游戏事件污染）；
`DownloadItemResult_t.m_eResult == 1` 才算 OK；全程 try/catch 单 job 隔离；
`Environment.TickCount64` 计时。**STS2 的 Steam appid = 2868840。**
