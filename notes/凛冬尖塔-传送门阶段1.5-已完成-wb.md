## 一、缺口补齐：裂隙卡现在由凛冬契约遗物发

### 做法：`partial` 拆分，本体一行不动

新增 `FrostSpireCode/Relics/FrostPactRelic.Rift.cs`，把裂隙逻辑从本体拆出来：

```csharp
public sealed partial class FrostPactRelic   // ← 本体只加了个 partial 关键字
{
    [SavedProperty] public bool RiftCardGranted { get; set; }

    public override async Task AfterObtained()
    {
        await base.AfterObtained();
        await GrantRiftCardAsync();
    }

    private async Task GrantRiftCardAsync()
    {
        if (RiftCardGranted) return;                                  // 读档重入：不重发
        if (Owner?.RunState is not RunState state) return;
        var card = state.CreateCard<OpenFrostRiftCard>(Owner);        // RunState:641 泛型版
        await CardPileCmd.Add(card, PileType.Deck, CardPilePosition.Bottom);
        RiftCardGranted = true;
    }
}
```

**为什么这么拆**：本体的波次逻辑（锁1/锁2 + 16 波表）是 **M2 已实测**的代码，
`partial` 让裂隙出错时一眼看得出是哪边，**不敢碰已实测的东西**。

### 关键 API（都已核实）
| 用法 | 核实依据 |
|---|---|
| `AfterObtained()` 是 virtual | `MegaCrit.Sts2.Core.Models.RelicModel:559` —— `public virtual Task AfterObtained()` |
| `CreateCard<T>(Player)` 泛型版 | `RunState:641` —— `public T CreateCard<T>(Player owner) where T : CardModel` |
| `PileType.Deck` 存在 | 枚举末位，注释写「Where cards live between rooms」= 牌库 |
| `CardPileCmd.Add(card, PileType, CardPilePosition)` | `CardPileCmd:332` |

**为什么进牌库（Deck）而不是手牌**：拿遗物的时机在战斗外（开局发遗物），
手牌只在战斗中才存在。进牌库最稳 —— 下一场战斗抽到就能用。

## 二、★ 顺手修掉一个我上一轮埋的设计问题

**问题**：上一轮写的 `OpenFrostRiftCard.OnPlay` 里有个"不在地图房就拒绝"的判断。
这意味着 —— **玩家可以在战斗里打这张牌，然后什么都不会发生，白费一张牌**。体验很差。

**正解**：`CardModel.IsPlayable`。官方文档写得很明白：

> Override this property to add extra conditions to check before allowing play.
> For example, Grand Finale is only playable if your draw pile is empty, so it would override this.

`protected virtual bool IsPlayable => true;`（`CardModel:825`）—— 官方给的"这张牌现在能不能打"钩子。
所以改成：

```csharp
protected override bool IsPlayable
{
    get
    {
        try
        {
            if (CombatManager.Instance.IsInProgress) return false;      // 战斗中：灰掉
            return Owner?.RunState is RunState state && state.CurrentRoom is MapRoom;  // 只在地图上
        }
        catch { return false; }   // 拿不到状态就当不能用（安全侧）
    }
}
```

**结果**：不在能开门的场合，这张牌在手里是**灰的**，玩家不会误打。
`OnPlay` 里那道检查保留作双保险。

## 四、现在整条链路是通的（可以实测了）

```
开局（凛冬模式开启）
  └─ Entry 发凛冬契约遗物给所有玩家
       └─ AfterObtained → 往牌库塞一张「开启凛冬裂隙」（0 费）
            ↓
走到地图（MapRoom）
  └─ 抽到/打出「开启凛冬裂隙」（战斗中它是灰的，打不了）
       └─ FrostRiftSession.EnterRiftAsync
            ├─ 快照原地图（ActIndex / ActFloor / 当前坐标）
            ├─ state.Map = FrostRiftActMap（3 列 × 2 层遭遇的独立小地图）
            ├─ 存进 RitsuLib 的 RunSavedData 槽
            └─ 过场 → 进 MapRoom
                 ↓
        在裂隙里打 2 层遭遇
                 ↓
        走到终点（Treasure）→ 领奖励 → 点「继续」
          └─ FrostRiftExitPatch 主路径触发
               └─ FrostRiftSession.ExitRiftAsync
                    ├─ 换回原地图（Act.ToSave().SavedMap）
                    ├─ 落回进裂隙前那个坐标
                    └─ 清空存档槽
```

1. **先开 mod**（`settings.save` 里 FrostSpire 曾经是 `false`，这是上轮的教训）。
2. 走地图界面，牌库里找「开启凛冬裂隙」，打出。
3. 日志关键字 `[裂隙]` 覆盖全程。
4. 重点观察：**能不能回来、落点对不对**。
