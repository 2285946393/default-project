## 4. 原理速览（改东西先懂这个）
- **mod 文件夹**：`mods/MemeSpire/` 放 `MemeSpire.json`（清单）+ `MemeSpire.pck`。**纯文本 mod 没有 dll**（像工坊的 Kill The Tower）。
- **游戏怎么读**（反编译 `ModManager`/`LocManager` 确认过）：
  `res://<清单id>/localization/<语言>/<表名>.json` —— 只在这个路径**打了 pck 才存在**。
  游戏把 mod 的表 **`MergeWith` 进原版表**，`MergeWith` 是 `dict[key]=value` → **直接覆盖原版同名 key**。
- **另一条免打包的路**（调试用）：`user://localization_override/<语言>/<表名>.json`（= `%APPDATA%\SlayTheSpire2\localization_override\`），启动时也会合并。改文本想快速试可往这儿丢，不走游戏也能改。
- **表名**：cards / relics / monsters / powers / events / ancients / encounters / potions / enchantments / card_keywords / intents / acts / characters / orbs / game_modes / modifiers / bestiary …
- **key 规则**：`<ENTRY>.title` / `.description` / `.flavor`；怪物是 `<ENTRY>.name` 和 `<ENTRY>.moves.<招式>.title`；事件是 `<事件>.pages.<页>.options.<选项>.title`。

## 5. ⛔ 铁律（都是踩过的）
1. **value 里的 `{...}` 占位符一个都不能丢、不能加**，否则游戏启动时 `LocValidator` 判格式串非法 → 那条被跳过。已知含占位符的：`TEST_SUBJECT.name`(`#C{Count}`)、`VAKUU.talk.ANY.1-0r.ancient`(`{Visits}`)、遭遇的 `.loss`(`{character}`/`{encounter}`)、`NEOW.results.prefix`(`{blessing}`)、`THE_FUTURE_OF_POTIONS`(`{Rarity}`)、`RANWID_THE_ELDER`(`{Gold}`/`{Potion}`/`{Relic}`)。
2. **key 必须和原版逐字一致**（大小写、`.title` 后缀、事件的长链式 key）。写完 grep 对一遍原版表。
3. **`<ModId>.pck` 名字不能错**，且必须和 `MemeSpire.json` 同目录。
4. **`[]` 标签要配对**（`[sine]`/`[b]`/`[red]`/`[i][font_size=22]`/`[thinky_dots]`/`[lb]`），否则显示乱；`\n` 换行用 JSON 的 `\n`。
5. **说明文 ≤ 8000 字节**（不是字数！）。`prepare_workshop.py` 会打印字节数。
6. **不要动"说明类"文字**（玩家的硬性要求）：卡牌 `.description`、状态描述、关键词名（消耗/保留…）、UI 按钮——改了就看不懂牌了。**只动名字和风味**。
7. **改完必须重新打 pck + 重新部署**；只改 json 不重打 pck 游戏看不到。
8. **`export_presets.cfg` 的 exclude 要把 `workshop/*` 也排除**——不然封面大图会被打进 pck（曾把 pck 从 160KB 撑到 2.2MB）。打完 pck 顺手看下大小对不对。

## 6. 文案风格（玩家的硬要求）
- **每个名字都要是一个"梗"**，不能是"换个说法/换个近义词"。不常见的梗也行，"世界上趣事那么多"。
- 梗源要**全国大众**都懂：影视台词、广告词、动漫、游戏、网络热词、名人语录（张雪峰/李佳琦/罗永浩/董宇辉/罗翔）、小品相声、成语典故。**别只玩尖塔圈内梗。**
- 例子（已采用）：痛击→「一个大逼斗」、愤怒→「急了急了」、预借时间→「花呗」、双重释放→「双卡双待」、巨石→「巨石强森」、电击→「原神，启动！」、谋杀→「法外狂徒」、角色名用社区昵称（红裤衩/猎宝/机宝/骨妹/太子）。

## 11. 自动补梗（2026-10-04 加，用户要求"别一直问"）

### 一条龙脚本
`python tools/meme_autofill.py [--tables a,b] [--batch 25] [--max-batches 8] [--dry]`

自动做完：**导出待办 → 批量起草 → 自动筛 → 写回 json（先备份）→ 刷图鉴**。

- **后端**：优先 WorkBuddy 国际版 `deepseek-v4.1-flash`（免费、更聪明），失败退回 DSH 免费车道。
- **自动筛规则**：新名 == 原名 → 丢；**新名里含原名（"飞镖→夺命飞镖"这种加长版近义词）→ 丢**；
  同一个新名给了不同原名 → 只留第一个。
- **写之前自动备份**到 `tools/_backup_<表>.json`。
- **先做剩余最多的表**（免得额度被小表吃掉）。

### 定时任务
- 任务名 **`MemeSpireAutoFill`**，**每 6 小时**跑一次 → `tools/meme_autofill_loop.cmd`
  （cmd 里调 `meme_autofill.py --max-batches 6`，输出追加到 `tools/meme_autofill.log`）。
- 没活干时它几秒就退出，不会捣乱。
- 不想要了就：`schtasks /Delete /TN "MemeSpireAutoFill" /F`
- 立刻手动跑一次：`schtasks /Run /TN "MemeSpireAutoFill"`

## 12. ⛔ 又一批准"误改"（2026-10-04 体检发现，**别动**）

全表体检（3517 条 / 改动 3330 条 / 0 无效 key）时，发现 **9 处 `.description` 也被改了**，
一度想当成"违反规矩"还原 —— **其实都是有意改的**，因为它们和整包的沙雕语气一致：

| key | 现在写的 |
|---|---|
| `IRONCLAD.description` | 铁甲军团最后一个兵。不想打也得打，一刀一火把敌人全清了。 |
| `SILENT.description` | 尖塔外来的女猎手。谁拦路，就用刀用毒。 |
| `DEFECT.description` | 一台靠不停改造自己才活下来的机器。真要打架，就掏出充能球科技。 |
| `NECROBINDER.description` | 生在尖塔的巫妖，来复仇的。打架时就叫她那只可靠的左手[gold]小骨[/gold]。 |
| `REGENT.description` | 群星王座的继承人。宇宙级的力量，但活儿都让仆从干。 |
| `RANDOM_CHARACTER.description` | 随机一个角色，开爬。 |

### 结论（写给下一个接手的人）
**判断"是不是误改"不要只看 key 的名字，要看内容**：
- 只要**意思还对得上**、只是换了更口语化的说法（获得→白给、移除→删掉、选择→挑），那就是**有意的**，别还原。
- 真正"不能动"的只有：**卡牌 `.description`（写效果的那段）、状态描述、关键词名（消耗/保留…）、UI 按钮**。
- 角色 `.description`、遗物 `.eventDescription` **属于已授权改写范围**。
- 万一真误改了：**`MemeSpire.pck` 是上一版 json 的快照**，从里面解出来就能救回来（§10 用过这招）。
