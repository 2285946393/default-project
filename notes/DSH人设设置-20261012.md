# DSH 人设（妈妈 / 女仆·大肥鱼）— 2026-10-12

## 一句话

给 DSH 加了**两个官方预设**：`女仆 · 大肥鱼` 和 `妈妈`。
**没装任何插件**，纯用 DSH 自带的 Agent Preset + persona 机制。

---

## 怎么用（重要，先看这个）

1. **新建对话时**，点左上角的**「模式」选择器**
2. 选 `女仆 · 大肥鱼` 或 `妈妈`
3. 也可以「设置 → 预设管理」把其中一个**设为默认**，以后新会话自动用它

⚠️ **预设是创建会话时锁定的**。改了默认值只影响**之后新建的会话**，
**已经在跑的会话不会变**（你现在这个会话还是原来的口吻）。

## 预设放在哪

```
D:\software\dsh-home\.agent-presets\
├── maid\          # 女仆 · 大肥鱼
│   ├── preset.yml         # 界面卡片显示的名字/描述/排序
│   └── agent.cordis.yml   # 人设 + 工具组成（255 行，从 standard 抄的）
└── mom\           # 妈妈
    ├── preset.yml
    └── agent.cordis.yml
```

**为什么放这里**（查源码得出的结论，别改）：

- DSH 的预设扫描有 **shipped root（内置，只读）+ user root（用户，可写）** 两层
- **user root = `<dsh-home>/.agent-presets`**（源码常量 `USER_PRESET_DIR = ".agent-presets"`）
- 界面上的**复制 / 删除只操作 user 根**；写在 shipped 根里的会被当成"官方只读预设"
- **shipped root 排第一、user root 排最后，前面的遮蔽后面的** ——
  所以同名预设放内置区会盖住用户区，那就管不了了
- 放 user 根还有两个好处：**升级 DSH 不会丢**、界面能管

### 为什么没直接装 dsh-maid

**API 不兼容**（逐行验证出来的）：

```js
// dsh-maid/index.js L361 调用的
ctx.agentPresets.register(definition)
```

但本机 `dsh-agent-presets` 服务**没有 `register` 方法**，只有
`list / resolve / mount / read / copy / composeFrom ...`

它是按 **DSH 0.2.x 的 API** 写的，本机是 **0.1.5-rc.2**。
仓库 2026-10-03 建、10-04 最后更新、1 star、2 个提交 —— 很新的个人项目。

**注意**：它在 `try/catch` 里包住了，所以**不会把服务搞崩**（不像 `permission` 那次），
只是女仆预设注册不上 → 界面上切不出来 → **等于白装**。

⚠️ **教训：判断插件兼容性不能只看有没有写 `peerDependencies`。**
dsh-maid 压根没写 peerDependencies，看起来"安全"，但实际调用的 API 不存在。
**必须核对它调用的具体方法在目标版本里存不存在。**

### 所以怎么做的

**扒它的人设文本**（人设内容跟 API 无关），改成官方 persona 写法：

```yaml
- id: persona
  name: '@deepseek-ai/dsh-persona'
  config:
    prefix: >-
      【角色扮演设定 · 女仆模式】
      角色名：大肥鱼 🐳
      ...
```

妈妈的人设参考 lolimom 的气质方向，文句按本机用户的实际情况写
（会念他熬夜、催喝水、夸具体的点）。

## 相关事实（免得下次重查）

**DSH 的预设机制**：

- 一个预设 = 一个目录，两个文件：`preset.yml`（界面元信息）+ `agent.cordis.yml`（组成）
- 内置 4 个：`standard`(标准模式) / `ptc` / `minimal` / `cordis`(创造模式)
- 内置的在 `.../dsh-agent-presets/presets/`，**只读**，别往里写
- 人设靠 `@deepseek-ai/dsh-persona` 插件，配置项 `prefix`（人设）/ `suffix` / `complete`
- **`{{model}}` 和 `{{cwd}}` 是模板变量**，渲染时替换
- 另有 `includeUserRoot` / `includeShippedRoot` / `roots` 三个配置键可调根目录

**界面入口**：新建对话的「模式」选择器 + 「设置 → 预设管理」
（`@deepseek-ai/dsh-client-ui-agent-preset` 提供）

**注意**：DSH 里还有个**同名的 `whale-roles` 目录**（`D:\software\dsh-home\whale-roles`），
**是空的，跟预设无关**，不要混淆。
