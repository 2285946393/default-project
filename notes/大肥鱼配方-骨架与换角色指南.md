## 六点五、⚠️ 网页操作坑：填完词必须按 Tab 失焦

**2026-10-14 实测踩到**：用浏览器工具往提示词框填词后**直接点生成，用的还是上一次的旧词**。

**证据**：把第④段从 `{{white thighhighs,...}}` 改成 `{{black pantyhose,...}}` 后点生成，
出来的是**白丝**（图库记录 19:42:40 / 19:44:52 两条都是白丝）。

**原因**：填词动作没有触发页面的 React `onChange`，文本框内容变了但组件 state 没变。

**解法**（已验证有效）：

```
1. browser_type 填正/负向提示词
2. browser_press "Tab"      ← ★ 关键：让输入框失焦，触发状态同步
3. 再点「立即生成」
```

按这个流程后，黑丝版成功出图（图库记录 **20:02:04**，种子 `2109801795`）。

**⇒ 以后每次改词都要走这三步，否则白跑一次（还扣额度）。**
