# 磁力沙盒 · Ising Sandbox 玩法说明

双击 `磁力沙盒.html` 即可在浏览器中离线运行，无需联网、无需安装。

## 一句话

屏幕里每个格子只有一件事要做：看看四个邻居朝哪边，再决定自己要不要翻面。
**没有任何人在指挥，可它们会在某个温度突然全体站到同一边**——这就是相变。

## 核心玩法

- **调「温度 T」**：唯一必须玩的滑块。
  - T 很小 → 全体站成一边，只剩零星几个反骨（铁磁有序）
  - T ≈ **2.2692** → 临界点，最大最花的一片，界面前后蠕动
  - T 很大 → 热噪声把秩序打散，变成一片灰雾（顺磁无序）
- **按住拖动**：左键写「朝上」，右键 / Shift 拖动写「朝下」，可以直接在画面上画出一块反向的岛。
- **开「相变扫描」**（面板按钮或按 `A`）：温度自动从热降到冷，右边的图会**一边降温一边把曲线画出来**——粉点是实测，灰虚线是理论精确解，两者应当重合。

## 右边那张图是什么

横轴温度，纵轴是自发磁化 |M|。低于 Tc 时 |M| 明显大于 0，一到 Tc 就垂直掉到 0。
这条曲线有精确解（Onsager，1944），页面把理论值叠在一起做对照——两条线贴住，说明模拟是对的。

## 几个值得按的预设

| 预设 | 看什么 |
|---|---|
| **临界点** | 最漂亮的一个。大小不一的斑块不断长出来又缩回去，没有固定尺度 |
| **有序** | 全体一边倒，只剩几个小气泡慢慢消失 |
| **反铁磁** | 相邻格子偏要反着来。画面按「交错磁化」上色，所以有序处是纯色 |
| **外磁场** | 磁场把整体磁化推向一边，相变被"抹平"，曲线不再垂直 |
| **深冷** | 近乎完美的单畴 |

## 两个物理上的坎（页面已经处理）

- **团簇翻转（Wolff）**只在「零场 + 铁磁」下成立。有外磁场时整团翻面的能量代价和场有关，这个算法没算这一项，会得到错误结果——所以外场不为 0 时页面自动退回单点翻转。
- 反铁磁的有序是「相邻格子反向」，直接画原始自旋会和像素格打架出摩尔纹；页面改成按交错磁化上色，有序基态就变成纯色了。
- 网格边长恒取偶数，否则交错上色和周期性边界不自洽，左右边缘会出现一条错位缝。

## 快捷键

`空格` 暂停 · `A` 相变扫描 · `R` 随机重置 · `C` 全体朝上 · `P` 存图 · `G` 收起面板 · `[` `]` 或滚轮 调笔刷

## 实现备注

- 单文件、零依赖，Canvas 2D 直写 ImageData，自旋存在 `Int8Array` 里。
- 两套更新算法：棋盘格 Metropolis 单点翻转 + Wolff 单簇翻转，可切换。
- 接受概率用查表（ΔE 只有 5 个取值），内层循环里不调用 `exp`。
- 平衡态磁化与 Onsager 精确解逐点吻合（T=1.5 实测 0.986 / 理论 0.9865；T=2.0 实测 0.911 / 理论 0.9113）。
