### 1.2 三个入口（现在）

```
主菜单「斗地主尖塔」按钮  →  DouSpireEntry（单人/多人小页）
   ├─ 单人 → DouSpireTable.Toggle()        直接开桌（无赌注）

篝火「斗地主」选项         →  DouSpireNet.OpenAtRestSite() → 联机/单人 + 金币赌注
```

### 1.3 斗地主的阶段机（德州要**另起一套**，不能塞进去）

`DouSpireTable` 里跑的是：**明牌 → 抢地主(猜拳) → 加倍 → [2v2 扣牌] → 出牌 → 结算**。
这套是**斗地主专属**的，德州一步都对不上（德州是"发底牌→翻牌前→翻牌→转牌→河牌→摊牌"）。

> **结论：德州要写一个平行的 `DouSpirePokerTable : Control`，不往 `DouSpireTable` 里塞。**
> 理由：那个文件已经 5,531 行了；而且德州和斗地主的阶段、UI、联机语义都不一样。
> **可复用的东西早就被抽成独立的静态类了**（UI 工具箱 / 贴图 / 角色 / 活角色 / 音效 / 音乐 / 语音 / 摆位），
> 直接拿来用就行 —— 这也是当初"规则别写死在 DouSpireTable 里"那个口子（见四人玩法设计 §六）的价值。

## 三、设计方案

### 3.1 内核：`dou-spire-rules/Poker/`

```
Poker/
  PokerCard.cs     52 张牌（2..14，A=14），花色 SPADE/HEART/CLUB/DIAMOND
  HandEval.cs      7 张挑最好 5 张，返回可比较的 HandValue
  HoldemGame.cs    一手牌的状态机（盲注/四轮下注/边锅/摊牌）
  PokerAi.cs       电脑打牌（翻前查表 + 翻后牌力/赔率 + 诈唬）
  （控制台自检，不链接）PokerCrossCheck.cs
```

**⚠️ 关键：点数口径不能照抄斗地主。**
斗地主内核里 `Card.Rank` 是 **3=3 … K=13, A=14, 2=15, 王=16/17**（2 最大）。
德州里 **2=2 … K=13, A=14**（**A 最大**）。**两套点数，各用各的，别混。**
→ 所以 `PokerCard` 是**独立类型**，不复用 `DouSpireRules.Card`。（花色可以复用同一个 `Suit` 枚举，但为了自洽，`Poker/` 自己定义。）

**`HoldemGame` 要暴露的**（给桌面层和 AI 用）：
```csharp
enum Street { Preflop, Flop, Turn, River, Showdown, Done }
enum PokerAction { Fold, Check, Call, Bet, Raise, AllIn }

class HoldemPlayer { string Name; int Seat; int Stack; PokerCard[] Hole;
                     int CommittedThisStreet; bool Folded; bool AllIn; bool ActedThisRound; }

class HoldemGame {
    Street Street; int Button; int SmallBlind; int BigBlind;
    PokerCard[] Board; int BoardCount;         // 0 → 5
    int Pot; List<SidePot> Pots;
    int CurrentSeat; int CurrentBet; int MinRaise; int LastAggressor;
    IReadOnlyList<PokerAction> LegalActions();
    int MinAmountFor(PokerAction); int MaxAmountFor(PokerAction);
    bool Apply(PokerAction a, int amount, out string error);
    // 结算
    int[] Payouts; int[] Winners; string ResultText();
}
```

**钱必须平**（最重要的自检）：一手结束，**所有人筹码变化之和 = 0**。内核里直接写断言。

### 3.2 桌面层：`DouSpirePokerTable : Control`

形状**照抄 `DouSpireTable`**（静态单例 + `Open/Close/Toggle/OpenAtRestSite/OpenForNet`），
但阶段机换掉。**复用的现成件**：

- `DouSpireUi` —— `Root / Fill / Box / BoxGlow / StyleFont / Scaled / Px / Gap / ImageButton / ApplyGradButton / GameFont`（**必须借游戏字体，否则中文是豆腐块**）
- `DouSpireAssets` —— 三层回落（自己的图 → 游戏 `res://` → null）
- `DouSpireCharacters` + `DouSpireActor` —— 桌边活角色（出牌做动作、带配音）
- `DouSpireSfx` / `DouSpireMusic` / `DouSpireVoice` —— 音效 / BGM / 语音
- `DouSpireLayout` —— 座位摆位（`layout.txt`）

**新画的 UI**：
1. **中央公共牌区**（5 张牌位）—— 斗地主的中央是"出牌区"，德州放公共牌，位置天然合适。
2. **底池**数字（带筹码堆动画）。
3. **每席的下注筹码**（HUD 下面）。
4. **动作按钮排**：`弃牌 / 过牌 / 跟注 / 加注 / 全下`（按 `LegalActions()` 动态显隐）。
5. **加注面板**：预设按钮 `½池 / ¾池 / 满池 / 全下`（比滑条好点、也好做）。
6. **摊牌亮牌**：结算时把每人的底牌摊开 + 标出最佳 5 张。

⚠️ **摆位复用注意**：`DouSpireLayout.Seats` 是**静态单例**，斗地主桌和德州桌不能同时开（互斥的两种模式），
所以**共用一份 `layout.txt` 没问题**。德州只是额外在中间画公共牌区。
若实测中间区域被斗地主的布局占用了，再给德州单独加一份 `layout-poker.txt`（改动很小）。

### 3.3 联机：`DouSpirePokerNet`（平行频道）

**为什么不直接改 `DouSpireNet`**：它里面 `public const int Seats = 3;` 是**写死的**，
而且**已经在工坊上线、能跑** —— 动它等于拿正在卖的斗地主联机冒险。

**做法**：新开一套 opcode（同一套 RitsuLib Sidecar 总线）：
```csharp
PokerIn   = RitsuLibSidecarOpcodes.For(ModId, "poker.in");    // 客机 → 主机
PokerOpen = RitsuLibSidecarOpcodes.For(ModId, "poker.open");  // 主机 → 全员（座位表 + 种子）
PokerAct  = RitsuLibSidecarOpcodes.For(ModId, "poker.act");   // 主机 → 全员（动作/翻牌/摊牌）
```
主机权威：**主机洗牌、主机判定、主机广播动作**。座位旋转照抄 `ToGlobal/ToLocal` 那套。

#### ★★★ 德州特有的坑：**底牌是隐藏信息**

斗地主**没有秘密**（手牌数公开、明牌是主动行为）。德州**底牌只有本人能看**。

| 方案 | 怎么做 | 代价 |
|---|---|---|
| **A. 同种子各端本地发牌**（v1 推荐） | 沿用斗地主那套：主机广播 `Seed`，各端自己洗出同一副牌 | **技术上能看到别人的底牌**（改内存/打日志即可作弊）。好友局可接受 |
| **B. 主机只发"你该看的"** | 主机洗牌后，**只把公共牌 + 每席自己的底牌**发给对应的人 | 要做定向投递（或按座位切片）。**斗地主没有这个需求，得新做** |

> ⚠️ **这条必须让用户拍板**（见 §五 第 3 条）。默认我建议 **A**（简单、和斗地主一致），
> 但要把"理论上能作弊"这句话明明白白告诉用户。

**另外三条德州联机必须处理的**：
- **超时**：某人不表态 → 主机替他 **Check/Fold**（照斗地主那套 25 秒超时）。
- **重连**：中途掉线 → 座位标记 `Folded`（弃牌保筹码），不阻塞牌局。
- **摊牌同步**：摊牌时主机广播**所有人**的底牌（这一刻才公开），各端一起亮。

### 3.4 入口

#### (a) 主菜单第二个按钮

`DouSpireMenuButton` 现在是"装一个按钮"。改成**能装 N 个**：
```csharp
Install();        // 保持原样，装「斗地主尖塔」
InstallPoker();   // 新装「德州扑克尖塔」，同一个容器 MainMenuTextButtons
```
- 模板、克隆、`label.Text` 直接改、`Visible/Modulate` 掰回来 —— **照抄现有那套**（踩过的坑都在注释里）。
- ⚠️ **不要** `Signals` 标志（否则会抄来模板按钮的原动作）。
- 按钮文字：`德州扑克尖塔`（和"斗地主尖塔"成对）。

#### (b) 篝火第二个选项

**照抄 `DouSpireRestSite.cs`**，只换 `StableId`：
```csharp
public sealed class DouSpirePokerRestSiteOption : ModRestSiteOptionTemplate {
    public const string StableId = "DOU_SPIRE_POKER";
    public const string TitleKey = "OPTION_DOU_SPIRE_POKER.name";
    ...
    public override Task<bool> OnSelect() {
        var gold = DouSpireTable.MyGoldNow();
        if (gold is <= 0) { Entry.Toast("你身上一个金币都没有 —— 先去挣点钱。", "德州扑克"); return Task.FromResult(false); }
        DouSpirePokerNet.OpenAtRestSite(Owner, Entry.Logger);
        return Task.FromResult(false);   // ★ false = 不消耗选项，篝火可以反复玩
    }
}
```
注册：`Entry.RegisterContentPack()` 里**再加一行** `.Singleton<DouSpirePokerRestSiteSingleton>()`。

**⚠️ 两个必须记住的雷：**

1. **★★ 选项顺序必须确定性**。
   联机同步的是 **uint 下标**（`RestSiteSynchronizer.ChooseLocalOption(int index)`），
   每人选项表**各自本地生成**，接收端**只校验越界** → **两端差一个元素，同一下标指向不同选项，静默错。**
   → 两个选项（斗地主 / 德州）在表里的顺序**必须固定**（按 `StableId` 排序或写死 `RankOf`），
   **绝不能依赖字典/反射的枚举顺序**。

2. **★ 图标坑**（斗地主已经踩过一次，别踩第二次）。
   `RestSiteOption.Icon` **只读 `res://`**；`has_pck:false` 的 mod 给一个假 `res://` 路径会**永久污染 AssetCache**
   → 图标错 + 标题回落成「挖掘」+ **点击直接卡死游戏**。
   → 复用现有的 `assets/DouSpire.icon.pck` 机制（`ResourceLoader.Exists()` 先查，取不到就回落 `option_clone.png`）。
   **绝不能把 manifest 改成 `has_pck: true`**（`LoadResourcePack` 返回 false 时抛异常 → **整个 mod 变 Failed**）。

### 3.5 设置页（尽量少加）

| 项 | 建议 | 说明 |
|---|---|---|
| 大盲注 | **复用 `BaseStake`** | 小盲 = 大盲/2。默认 100 → 50/100 |
| 人数 | **复用 `TableSize`** | 3 人 / 4 人 |
| AI 风格 | **新加 1 项** `PokerAiStyle{保守, 正常, 激进}` | 影响诈唬频率和下注尺度 |
| 篝火赌注安全阀 | **复用** `BetUnitDivisor` / `BetMaxSwingPercent` | 用户：「不能让我赢太多。也不能让我输太多」 |

⚠️ **加设置项必须同时加 `InjectLabels()` 里的 key**（键 = `DOUSPIRE-<大写下划线属性名>.title`），
否则设置页显示成英文属性名 —— 这个坑 2026-10-08 踩过（用户「我根本看不懂」）。

### 3.6 ★★★ 新手友好 / 观众友好 —— 这是**硬需求**，不是锦上添花

**用户 2026-10-09 原话：「实话说我从来没玩过德州扑克，你自己看着办吧。主要是观众要加的。」**

推论很重要：**用户没玩过 → 大部分观众也没玩过。**
所以这东西**不能默认玩家懂德州** —— 要做成「**看别人玩也能看懂**」。

具体做法（按性价比排序）：

| # | 做什么 | 为什么 |
|---|---|---|
| 1 | **永远显示"你现在是什么牌"** | 底牌 + 公共牌能凑出啥，实时用中文写出来（"一对 A" / "两对 K 和 8" / "差一张成顺子"）。**新手不用背牌型表** —— 这一条最值钱 |
| 2 | **按钮写人话** | 不是 `Call/Raise/Fold`，而是 `跟注 100` / `加注到 300` / `弃牌`。**跟注按钮上直接写要掏多少钱** |
| 3 | **牌型速查表**（随时能开） | 10 档牌型 + 例子，一页看完。放一个 `?` 按钮 |
| 4 | **摊牌时高亮最佳 5 张** | 让观众一眼看懂"**为什么他赢**"（这是德州最容易让人懵的地方） |
| 5 | **赢的时候牌型名打大** | "三条 A！" / "同花顺！" —— 观众要有情绪点 |
| 6 | **"该不该跟"给个提示**（默认开，可关） | 算一下"你的胜率 vs 要花的钱"，给个"建议跟 / 建议弃"。**这是给新手最大的帮助** |
| 7 | **大场面特效** | 全下对决（all-in）给慢镜头 / 聚光；四条、同花顺给特效 —— 和斗地主的"炸弹特效"一个路子，**观众爱看** |
| 8 | **解说式日志** | 桌中央的历史用大白话（"电脑A 跟了 100"），不要用符号 |

> 内核里已经埋好了这些要用的东西：`HandEval.Name()`（中文牌型名）、
> `PokerAi.Equity()`（胜率，第 6 条直接用它）、`HoldemGame.LegalActions()` + `CallCost()`
> （按钮显隐和"要掏多少钱"）、`FinalPots`（分锅展示）。
> **内核里刻意没有"看别人底牌"的接口** —— UI 想做也做不到，联机不会因为界面 bug 而漏牌。

## 七、P4 联机施工图（已实现 · 2026-10-09 深夜）

**一句话**：德州桌的座位号在**内核里是全局的**（各端一致），画面上永远把"我"摆在 **0 号位** ——

### 7.1 新文件 `DouSpirePokerNet.cs`（~980 行，独立于 `DouSpireNet`）

⚠️ **绝不改 `DouSpireNet`** —— 它 `Seats=3` 写死、且**已上架**，动它就是给老玩家送回归。

| 频道 | 方向 | 用途 |
|---|---|---|
| `poker.in` | 客机 → 主机 | 我要开桌 / 我的动作 / 我要下一手 / 我走了 |
| `poker.open` | 主机 → 所有人 | 开桌（座位表：谁是人、netId、名字、角色下标） |
| `poker.act` | 主机 → 所有人 | 开一手 / 某人走子 / 某席改电脑 / 收桌 |

- opcode 走 `RitsuLibSidecarOpcodes.For("DouSpire", "poker.in")`；投递语义 `StableSync`（可靠 + 有序）。
- ★ **`Register()` 第一句必须 `RitsuLibSidecarProtocol.EnsureDefaultHandlers()`** ——
  晚了赶不上大厅握手，`CanSendToPeer` 恒 false，消息**静默丢弃**（斗地主踩过）。
- 自带 `W`/`R` 二进制编解码（小端 `BinaryPrimitives`），**不引任何序列化器**。

### 7.2 三条铁律

1. **视角旋转**：`G(view) = ToGlobal`、`V(global) = ToLocal`（单人恒等）。
   ★ `_hud/_chars/_actors/_hudHole` 一律按**视角位**存；`_game.*` 一律要**全局位**。
   P4 才发现 `RefreshSeats()` 一直把 `s` 当全局位用（单人时两者相同，看不出）。
2. **客机不自己走子**：点按钮 → 只发消息 → **等主机广播同一条动作回来才 `Apply`**（永不发叉，
   代价是一个来回的延迟）。主机 = 本地应用 + 广播一步到位。
3. **每手四要素主机算一次、广播**（`CastHand(seed, button, stack, sb, bb)`）：
   种子 / 庄家位 / 筹码 / 盲注。★ **赌注模式下筹码必须主机算** —— 每人本金 = 自己金币 ×
   `BetMaxSwingPercent%`，各端算出来不同；`HoldemGame` 要求开局筹码全同，否则第一手就分叉。

### 7.3 兜底（照"永远不能卡死"）

- **远端真人超时 45 秒**没动 → 主机用"能过牌就过牌、否则弃牌"替他走完（`SafeFallback`）。
- **主动离桌**（`InLeave`）→ 主机把他那席改成电脑接管并广播（`CastSeatAi`）。
- **开桌意愿收集 25 秒**：主机点了不立刻开，等大家（或超时）——没点的由电脑补位。
- 电脑席的 AI **只有主机跑**；客机跑 AI 会跟主机算出不同结果，直接把牌局带沟里。

### 7.4 赌注结算 = **主机权威**

- 联机时**只有主机结算金币**，且**给每一席都结**（用主机手上的各席 `Player` 写回各自金币，
  再靠游戏自己的玩家状态同步发到各端）。
- 客机一律不动 —— 否则主客两边都写同一份金币，或客机刚写完就被主机同步覆盖。
- 电脑补位的席没有真玩家，跳过。

### 7.5 顺带修掉的老假设

- `Refresh()` / `RefreshButtons()` 加了"`_game` 还没建"的空桌保护（联机桌等主机发第一手时）。
- 「换一批角色」在联机桌里**藏起来 + 直接不认**（那是本地换种子重开，会分叉）。
- 客机发出动作后 `_waitingHost` 期间**按钮收起 + 状态显示"已发出，等主机确认…"**（防重复点、让等待可见）。
- `HandleAct` 里主机广播的座位号**本来就是全局位** —— 早先 `ActSeatAi` 又过了一次 `ToGlobal`
  （对 `ActMove` 是恒等、看不出来；对 `SeatAi` 就错位），已修。

二次元牌桌是用户主动要的混搭：提示词有独立 anime style，**不能再追加全局暗黑奇幻 `<STYLE>`**。

### 10.2 代码落地

- `DouSpireAssets.cs`：增加 `DouSpireTableStyle`（编号 0~6）+ `DouSpireTableStyles.All` 固定顺序；
  `PokerTableOf(style)`、`TableKey(style)`、`TableShortName(style)`、`TableName(style)`；`AllSlots()` 逐档盘点。
- `DouSpireConfig.cs`：`PokerTableStyle` 默认 `经典绿绒`；设置页标题和 7 个选项全部在 `InjectLabels()` 注册。
- `DouSpirePokerTable.cs`：`ApplyTable()` 换贴图、`CycleTable()` 右上角按钮当场切换，按钮在牌型速查左侧，宽 200 / `ox=-829`；换图后必须 `MoveChild(_tableLayer, 2)` 钉在背景层之后、座位和 UI 之前。
- 缺图回落顺序：**目标风格 → 经典绿绒德州桌 → 斗地主圆桌**；不会因漏画一张出现空白，也不会直接跳成斗地主刻线。
- `tools/poker-assets.py`：为 6 张新图增加同名源文件映射，按品红底四边泛洪抠图，输出到 `assets/table/`。原图放项目根的 `assets/德州扑克/`，命名 `table_poker_<style>.png`，可用 `--only table_poker_` 只处理新桌面。
- 提示词：`assets/德州牌桌风格提示词-六款可复制.txt`（六条新桌面完整独立提示词）。经典绿绒已画；六条正文 **3553~3792 字符**，全部低于 QQ 5000 上限。出图时附经典绿绒桌作版式参考图，只参考功能刻线几何，不照抄颜色。

### 10.3 加新风格的规则

① 枚举值已经存盘，**只往末尾加，不能插队、不能改旧数字**；② 同步改 `DouSpireTableStyles.All`、`InjectLabels()`、`TableKey()` / `TableShortName()`；③ 同步加 `poker-assets.py` 任务、素材清单和提示词；④ 缺图时必须有经典桌回落；⑤ 游戏用户自己验收，**不要替用户启动游戏测试**。
