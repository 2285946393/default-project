# 斗地主尖塔 · 音乐系统（2026-10-08 建）

> 用户："你继续完善一下，比如音乐方面的。打斗地主放什么歌。然后高潮了放什么歌。
> 你看别人辉夜姬大型 mod。把超时空辉夜姬的歌全搬过去了。我很羡慕。"

---

## 一、一句话

**音乐不再是"两首本体曲切来切去"，而是按 5 个"时机槽位"分**：平时 / 紧张 / 高潮 / 赢 / 输。
往对应文件夹里丢歌就生效 —— 不用改代码、不用重编 dll、不用重启游戏。

---

## 二、五个槽位：什么时机放什么歌

| 槽位（文件夹） | 什么时候响 | 该放什么歌 | 空着时用什么 |
|---|---|---|---|
| `music\table\` | 平时打牌 | **舒缓、不抢戏、能循环听很久**。轻爵士 / 咖啡馆钢琴 / 悠闲国风小调 | 游戏第一层曲 `act1_a1_v1` |
| `music\tense\` | 有人只剩 1~2 张牌 | **节奏起来、有压迫感但不吵**（会反复切进切出）。紧张弦乐 / 鼓点加快 | 游戏第三层曲 `act3_a2_v1` |
| `music\climax\` | **炸弹 / 王炸 / 明牌 / 加倍 / 抢到地主** | **一上来就炸** —— 前奏别拖，最好 1 秒内进副歌。日系燃曲副歌 / 电子 drop | **无**（保持当前曲子） |
| `music\win\` | 这局我赢了 | 短，几秒到十几秒；上扬、得意 | **静音**（让"天降金币"那几声音效自己响） |
| `music\lose\` | 这局我输了 | 短；下坠、泄气但别太丧 | **静音** |

**高潮曲是"临时插播"**：放 11 秒后自动退回局势曲（`ClimaxSeconds` 可改）。
所以它要"副歌即开场"，不然还没爽到就退场了。

**一个槽位放多首会随机轮播，且不会连着放同一首。** 所以 `climax\` 里塞 5 首各取一段副歌，
每次炸弹放的都不一样 —— 这就是"把一套歌全搬进去"的正确姿势。

## 三、怎么放歌（两种方式）

### 方式一：用工具转（推荐）

`tools\import-music.py` 会把 mp3 / flac / m4a 批量转成 **.ogg**，并做 EBU R128 响度归一化
（免得几首歌一首吵一首轻），然后放进正确槽位：

```bash
cd "C:\Users\有花无实\Documents\Default Project\projects\dou-spire"

# 把一个文件夹的歌全部转进"高潮"槽位
python tools\import-music.py "D:\歌\我的燃曲" --cue climax

# 只转一首，裁掉开头 8 秒
python tools\import-music.py 主题曲.mp3 --cue table --skip 8

# 裁掉 AI 水印：只保留前 256 秒
python tools\import-music.py 歌.mp3 --cue win --keep 256

# 转完直接拷进游戏目录（连编译都省了）
python tools\import-music.py "D:\歌" --cue tense --to-mod

# 看看现在每个槽位有几首
python tools\import-music.py --list
```

### 方式二：手动拖

直接往下面这个目录里丢 **.ogg / .wav / .mp3**（放工程目录也行，编译一次就会同步）：

```
D:\software\steam\steamapps\common\Slay the Spire 2\mods\DouSpire\assets\music\<槽位>\
```

**生效方式**：游戏里 **F9 收桌 → F9 开桌**（开桌时会清缓存重读目录，不用重启游戏）。

只想放一首、不想建文件夹也行：直接放 `music\table.ogg`。

## 五、技术实现

### 新文件 `DouSpireCode\Table\DouSpireMusic.cs`

和 `DouSpireSfx`（音效走游戏 FMOD，只能按事件名播）分工不同：
**音乐走 Godot 自己的 `AudioStreamPlayer`，直接从磁盘读文件** —— 这样才能放自己的歌。
这条路和 `DouSpireVoice`（外部配音）是同一套做法。

要点：

1. **两个播放器轮换 + 交叉淡入淡出**（淡入 0.9s / 淡出 1.2s，用 `Tween` 拉 `volume_db`）。
   换曲不会"啪"地断掉。`Bus = "Master"`。
2. **槽位空着自动回退本体曲**（`VanillaEvent()`）：平时 → `act1_a1_v1`，紧张 → `act3_a2_v1`。
   **高潮 / 胜利 / 失败没有回退曲**（原因见下面「踩坑 ①」），高潮空着就保持当前曲子、胜负空着就静音。
3. **设成循环**：`AudioStreamOggVorbis.Loop` / `AudioStreamMP3.Loop` / `AudioStreamWav.LoopMode`。
4. **同一个槽位不连着重复**：`LastPick` 记住上次下标，最多试 6 次换一首。
5. **高潮曲会自己退场**：`Tick()` 每帧检查 `_climaxUntil`，到点回到 `_ambient` 槽位。
6. **两条铁律**（跟音效/语音那套一致）：任何异常都吞掉、连续失败 3 次永久闭嘴。
7. **诊断**：开桌时 `ReportOnce()` 打一条"每个槽位找到几首"，
   播放时 `[音乐]` 行写进 `mods\DouSpire\voice-log.txt`（跟语音共用一个诊断文件）。

### 改动的既有文件

| 文件 | 改动 |
|---|---|
| `DouSpireConfig.cs` | 新增 `MusicVolume`（滑块）、`MusicClimaxEnabled`（开关）+ 两个中英标签 |
| `DouSpireSfx.cs` | 原来的 `BgmCalm/BgmTense/Music()` 那一段**整块删掉**，三个方法改成**转发**给 `DouSpireMusic`（保留历史调用点，改动最小） |
| `DouSpireTable.cs` | 接 7 处钩子，见下 |

`DouSpireTable.cs` 的钩子（**都只加一行**）：

| 位置 | 加什么 |
|---|---|
| `Open()` | `DouSpireMusic.ClearCache()` + `ReportOnce()` |
| `UpdateMusic()` | 改成 `Tick()` → 高潮期放行 → 按局势 `Play(Table/Tense)` |
| 炸弹（watch 循环里 `PopMultiplier("炸弹")` 旁） | `Play(Climax)` |
| `ApplyDouble` 加倍 | `Play(Climax)` |
| 明牌 | `Play(Climax)` |
| 猜拳定地主「抢到地主！」 | `Play(Climax)` |
| 结算 `_endSfxDone` | `Play(Win / Lose)` |

> 炸弹那处**只需要接一次**：`IsBomb()` 已经同时覆盖 `Bomb` 和 `Rocket`，
> 而且 watch 循环对**任何一家**的新出牌都会触发，所以王炸和 AI 的炸弹都会走到。
> `Play(Climax)` 内部有幂等保护（已在放高潮就只续时长、不重新挑歌），重复调用无害。

### 素材自动部署

`DouSpire.csproj` 的 `CopyAssets` 目标本来就拷 `assets\**\*.*`（排除 .md），
所以 `assets\music\` 会自动同步到 `mods\DouSpire\assets\music\`，不用改 csproj。

### 一个容易漏的坑（已处理）

`DouSpireMusic.Tick()` 负责让高潮曲到点退场。一开始挂在 `UpdateMusic()` 里，
但 **`Refresh()` 只在状态变化时跑**（`_Process` 里并没有调它）——
玩家挂机不动时就没人推进时间，高潮曲会一直放着退不出来。

已改成挂在 `_Process` 的**最前面**（在所有 `return` 之前），每帧必跑。

## 十、实测踩到的两个坑（2026-10-08 02:20，都已修）

用户第一次进游戏试："我明牌了还是明牌，然后点不动。退出了。然后就是他俩 ai 在出牌。
然后我按钮都是暗的颜色"。

### 🔴 坑①（**严重，而且是老 bug，不是音乐引起的**）：单人模式明牌阶段死锁

**症状**：选完明牌，明牌提示不消失、按钮全暗、点不动；AI 照常出牌。

**根因**在 `DouSpireTable.BeginShowCards()` 的单人分支：

```csharp
if (!_netOn)
{
    for (var s = 1; s < 3; s++)
    {
        _showCardsSeat[s] = true;     // ← 只标了"明牌"
        _multiplier *= 2;
        Entry.Logger.Info($"斗地主：{s} 号（AI）明牌，倍数 ×2 → {_multiplier}");
    }                                 // ← 漏了 _showDone[s] = true;
}
```

而 `ApplyShow()` 的结尾是：

```csharp
if (!AllDone(_showDone)) return;      // ← AI 那两席永远 false → 永远在这里返回
_askingShow = false;
ShowShowCards(false);
BeginRps(_dealSeed);                  // ← 永远执行不到
```

→ **抢地主阶段永远不开始**。`ShowShowCards(false)` 也没执行，所以明牌提示还在；
出牌按钮虽然可见但没轮到人，所以是暗的。

**这是 2026-10-07 加"AI 自动明牌"那天引入的**，单人模式下明牌阶段从来没通过过
（联机走的是 `HostDecideAiShow()` → `ApplyShow()`，反而没这个问题）。

**修法**（一行）：循环里补上 `_showDone[s] = true;`。

**怎么定位的**（这个方法可复用）：
1. 日志里 `猜拳` 两个字**一次都没出现** → 说明卡在 `BeginRps` 之前；
2. 那段区间**没有任何 ERROR** → 不是异常，是**提前 return**；
3. 顺着 `ApplyShow` 往下读，只有 `AllDone(_showDone)` 一个 return 点；
4. 回头查谁负责设 `_showDone` → 找到单人分支漏了。

> 教训：**"标记"和"完成标记"是两个字段时，新加的捷径分支最容易只设一个。**
> 这个 bug 不报错、不抛异常，只是静默死锁 —— 只有读代码 + 数日志才能抓出来。

### 🟡 坑②（我的错）：高潮回退曲猜错了，本体放不出来

我按 `notes/杀戮尖塔2-音效事件全表.md`（从 dll 里扫字符串得到的）挑了
`event:/music/act1_boss_the_kin` 当高潮回退曲。实测：
