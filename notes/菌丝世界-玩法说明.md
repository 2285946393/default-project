# 菌丝世界 · Mycelia（中文单文件版）

一个在浏览器里活着的数字生物：**近百万只微小个体在你的显卡上协作，循着彼此留下的"化学气息"，几分钟内自组织成一张会呼吸、会发光的菌丝网络。**

- 改造自开源项目 **MattKulka/mycelia**（WebGL2 GPU 粒子 / 黏菌 Physarum 模拟），已全量中文化并打包成**单个 HTML**。
- **零依赖、零联网、零安装**：双击 `菌丝世界.html` 即可离线运行（推荐 Chrome / Edge）。

---

## 最有意思的玩法

1. **输入一个词，长出一只专属生物**
   左下角输入任意词（中文、英文、名字、日期都行），点"生长"或按回车。
   这个词会被算成一套"基因"，决定它的形态、颜色、性格——
   **同一个词，永远长出同一只生物**；把网址链接发给朋友，对方能一字不差地复刻出它。

2. **用鼠标"喂养"它**
   - 按住左键拖动：在光标处投放养分，菌丝会朝你的手生长、汇聚；
   - 按住 `Shift` 拖动（或右键 / Ctrl 拖动）：驱散，把它推开、撕出空隙。
   它会对你的每一次触碰做出反应，画面永远在变化，不会重复。

3. **养 1～3 只彩色菌落**
   右侧"菌落数量"切到 2 或 3，不同颜色的菌群会互相缠绕又彼此避让，交界处长出发光的"边界膜"。

4. **8 种配色氛围**：深渊 / 余烬 / 孢子 / 星云 / 象牙 / 青腐 / 岩浆 / 霜雪（按 `←` `→` 快速切换）。

## 右侧基因组面板（可实时拨动）

| 滑块 | 作用 |
|---|---|
| 感知角度 / 感知距离 | 个体"嗅觉"的视野宽窄与远近 |
| 转向速度 | 跟随气息转弯的灵活度 |
| 移动步长 | 爬行快慢 |
| 痕迹留存 | 化学气息消散得慢还是快（越久网络越密） |
| 扩散程度 | 气息向外晕开的范围 |
| 异种牵引 | 不同菌落之间是互相吸引还是互相排斥 |
| 辉光强度 | 荧光的明亮程度 |

**萌发形态**：散播 / 环形 / 聚核 / 轨道——决定生命最初从什么形状开始铺开。

## 快捷键

- `空格` 暂停 / 继续　·　`R` 重新生长　·　`S` 保存当前画面为 PNG
- `G` 显示 / 隐藏面板　·　`←` `→` 切换配色　·　`1` `2` `3` 切换菌落数量

> 卡顿的话：它默认按屏幕大小投放粒子数，窗口越小越流畅；手机/集显也能跑，只是个体更少。
