# 反应扩散 · Reaction-Diffusion Lab 玩法说明

双击 `反应扩散.html` 即可在浏览器中离线运行，无需联网、无需安装。

## 这是什么

两种化学物质（U 底物 / V 激活剂）在画布上反应、扩散，自发长出珊瑚、豹纹、条纹、迷宫、波浪般的有机纹理。这是图灵形态发生（Turing pattern）的数学模型——豹子的斑点、珊瑚的分支、手指的分化，背后都是同一套方程。

## 核心玩法

**按下拖动就是播种**——在画布空白处画一笔，反应扩散会沿着你的笔画生长出发光的有机纹理，然后不断演化、蔓延、变形。

- 左键拖动：绘画播种（在 V 激活剂中画一笔）
- 滚轮：调整笔刷大小
- 画完后盯着看：纹理会自己生长、蔓延、变化，没有两笔长得一样

## 七种预设形态

点击预设按钮，整片世界瞬间换一种活法：

| 预设 | 效果 |
|---|---|
| 斑点 | 经典豹纹，圆点在深色背景上 |
| 条纹 | 斑马纹，波浪状条纹 |
| 迷宫 | 迷宫般的连通脉络 |
| 珊瑚 | 环形/孔洞结构，像珊瑚或细胞 |
| 波浪 | 行进的波浪纹 |
| 分裂 | 细胞分裂般的图案 |
| 孔洞 | 深色孔洞在亮色背景上 |

## 两个关键参数

- **喂养率 f**：控制 U 底物的补充速度，越大图案越稀疏
- **死亡率 k**：控制 V 激活剂的衰减，越大图案越破碎
- 微调这两个滑块，整片纹理会连锁突变——这是最上瘾的部分
- 点「随机参数」让系统随机选一组，经常有惊喜

## 六套配色

霓虹（蓝紫青）、熔岩（橙红）、极光（绿青）、赛博（粉青紫）、珊瑚（橙粉）、金墨（金色）。点击色块即时切换。

## 操作

- **左键拖动**：绘画播种
- **滚轮**：笔刷大小
- **空格**：暂停 / 继续
- **G**：隐藏 / 显示面板
- **P**：保存当前画面为 PNG
- **C**：清空并重新播种
- **R**：随机参数
- **[ / ]**：笔刷减小 / 增大

## 好玩技巧

1. **画一个心形或写字**：笔画会变成发光的有机轮廓，然后慢慢变形。
2. **画几笔交叉**：不同笔画的纹理会互相干扰、融合，产生复杂的图案。
3. **边画边调参数**：画一笔，然后微调 f/k，看纹理在你眼前突变。
4. **随机参数 + 随机绘画**：每次都是独一无二的生成艺术。
5. **暂停后精细绘画**：按空格暂停，画好构图，再继续看它演化。
6. **保存作品**：调到好看的瞬间按 P 保存 PNG。

## 技术说明

基于 Gray-Scott 反应扩散模型，9 点离散拉普拉斯，子步迭代（dt=0.6，每帧 18 次），Canvas2D 离屏渲染 + 发光后处理。参考 Karl Sims / jasonwebb / piellardj 的成熟参数组与交互设计，零依赖单文件。
