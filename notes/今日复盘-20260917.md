## 三、AI 剪辑流水线

**先搞清楚概念**：现在说的"AI 剪辑"不是 AI 生成视频，是**让 AI agent 通过 MCP 操作剪辑软件**。生成视频（Seedance 那类）产出的是素材，AI 剪辑产出的是成片。两回事。

**选了 `ai-jian-koubo`**（482 星，中文项目，作者是 B站 UP 栗氪聊AI）：口播视频粗剪，转录 → AI 标口误 → 网页波形审核 → 导出工程文件。转录走火山引擎，40 小时免费额度。

**在 Windows 上修了三个兼容问题**（这项目只在 mac/linux 能跑）：

1. `run_transcribe.sh` 里的 `ffmpeg -i "file:$VIDEO_PATH"`——`file:` 前缀会让 Git Bash 跳过 MSYS 路径转换，原生 ffmpeg 读不懂 `/c/Users/...`。解法是路径参数一律传 Windows 格式 `C:/...`。
2. `python3` 命中 `WindowsApps` 下的微软商店占位符（执行无输出）。在 `~/bin/python3` 放了个垫片转发到真实 Python。
3. curl 报 `CRYPT_E_REVOCATION_OFFLINE`——Windows 的 Schannel 查不到证书吊销列表就拒绝连接。改成按 curl 版本探测，自动补 `--ssl-no-revoke`。

**然后发现我没有口播素材**。转录跑通了，识别出 31 个字，才反应过来手上没有能剪的东西。

## 四、作品演示片

**换个思路**：既然工具都装好了，拿它给 28 个作品剪一条演示片。

**素材**：一条 9 分 50 秒的录屏，内容是操作作品展馆、点进各作品、再退回来。830MB，2546×1344。

**问题**：展馆页、页面跳转、加载等待全混在里面，而且有的作品我自己觉得"太拉"不想放。运动量检测帮不上忙（展馆首页的极光流体封面比谁都活跃），只能场景切分 + 人工挑选。

**为这个写了三个脚本**（都在 `.opencode/skills/ai-jian-koubo/scripts/`）：

- `scene_split.js` — ffmpeg 场景检测找切换点 → 合并过短段 → 抽缩略图 → 生成勾选审核页。9.8 分钟切出 81 个切换点，合并成 53 段
- `cut_segments.js` — 读勾选结果，自动合并首尾相接的段，生成时间线
- `label_segments.js` — 生成带缩略图的命名页

**自动认作品失败了**。想用 `assets/作品截图` 里 31 张按 slug 命名的截图做图像比对，自动识别每段是哪个作品。HSV 直方图 + 网格平均色，跑出来每个片段都匹配上了还带置信度——**拿手填的结果一对，21 段只蒙对 3 个**。连 0.886 最高分的那段都是错的。

原因：参考截图 1440×810，录屏 2546×1344，视口尺寸不同导致响应式版面不同。颜色分布又不够有区分度。

结论：作品名还是让人来填。

**烧字幕又踩两个坑**：

1. `drawtext` 挂在 `trim` 后面时，滤镜作用在源片分辨率上，缩到 1920 后字号被等比缩掉且位置偏移。正确做法是 `concat → scale → 再叠字幕`，用 `enable='between(t,t0,t1)'` 按累计时间控制
2. ffmpeg 的 `fontfile` **不认带盘符冒号的绝对路径**，绕法是启动时把工作目录切到 `C:\Windows\Fonts`，只按文件名引用

**成品**：片头 4s + 正片 7:08（21 段，每段左下角标作品名）+ 片尾 4s = **7 分 28 秒 / 209MB / 1920×1014**

文件：`Videos\作品演示片_完整版.mp4`

## 今天的坑，汇总一下

| 坑 | 症状 | 解法 |
|---|---|---|
| Iconify 走 CDN | 图标全消失 | 离线图标集 + 按用量裁剪 |
