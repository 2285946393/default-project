# 我的游戏统计（页面 + 取数脚本）

2026-10-04 做的。把本机 Steam 的游玩记录变成一张能看的网页。

## 成品

`pages/我的游戏统计.html` —— 双击就能打开，单文件、零依赖。

- 顶部四个数字：游戏数量 / 总时长 / 折合天数 / 10 小时以上的款数
- 「玩得最久的 20 款」横向条形图
- 全部记录：能搜名字、能按时长/最近游玩/名字排序、每条带档位标签和 appid
- 底部单列「不在 Steam 里的（桌面启动）」，来自 Steam 的非 Steam 游戏列表

## 数据从哪来

| 文件 | 内容 |
|---|---|
| `userdata/<id>/config/localconfig.vdf` | 每个 appid 的 `Playtime`（分钟）和 `LastPlayed` |
| `steamapps/appmanifest_*.acf` | 已安装游戏的名字 |
| `appcache/appinfo.vdf` | 全部 app 的名字（二进制 v29，key 走字符串表下标） |
| `shortcuts.vdf` | 非 Steam 游戏（走 `tools/steam_shortcuts.py`） |

`appinfo.vdf` 的 v29 结构：`magic(4) universe(4) string_pool_offset(8)`，
然后一堆 `appid(4) size(4) kv(size) sha1(20)`。kv 里顶层第一个字段通常是
`name`（字符串表下标 4），扫 `\x00\x01\x04\x00\x00\x00` 就能批量拿名字；
少数（比如 CS2）name 不在第一位，要按 appid 单独在记录范围内再搜一次。
查不到的 appid 写在 `tools/_steam_name_fix.json` 里手动补。

## 以后怎么更新

```powershell
python tools\steam_playtime.py --json tools\_steam_playtime.json   # 重新读 Steam 记录
python tools\gen_game_stats.py                                     # 重新生成页面
```

想改页面样式/文案，改 `tools/gen_game_stats.py` 里的 `HTML` 模板再跑第二条。

## 注意

- 页面脚本**必须包在 IIFE 里**，原因见 `notes/踩坑笔记.md` 第六节（会静默不执行）。
- 时长是 Steam 本地记录，卸载过的游戏也在；`Playtime` 单位是分钟。
