# 图集总览 — 一墙看完全部出图

## 这是什么

把 `pages/` 里**每一个出图页面**（第 18 轮 ~ 第 70 轮、Z 系列、各种对照实验）里的
`<figure>` 图集全部拆出来，摊平成一面墙。

以前想看"我之前出过哪些脚图 / 鸣潮出过几轮"，得一个个打开 50 多个页面翻。
现在一个页面搞定。

**双击打开：`pages/图集总览.html`**

---

## 里面有什么

| 数字 | 含义 |
|---|---|
| **52** | 有图集的轮次 / 页面 |
| **283** | 汇总的图（全部引用原图，不复制不占空间） |

顶部四个按钮：

- **全部** — 283 张
- **标了「正常」的** — 只留有 `<span class="ok">正常</span>` 标记的（28 张，无崩坏）
- **带脚的** — 描述/标题里出现 脚 / 足 / 脚趾 / 赤足 / 袜 / feet 的（133 张）
- **最近 10 轮** — 第 61 轮往后（58 张）

搜索框支持**多词空格分隔**，比如 `misaka 脚`、`鸣潮 咬唇`。

点任意一张卡片 → 大图 + 完整描述 + 标签 + 「打开这一轮」跳回原页。

## 重新生成

以后又出了新的一轮，重跑一次就同步：

```bash
cd "C:\Users\有花无实\Documents\Default Project"
python projects/gallery-builder/build.py
```

它会自动扫 `pages/*.html`，把所有 `<figure>` 抓出来重新生成总览。
**零联网，纯本地解析，不花流量。**

---

## 文件在哪

| 文件 | 作用 |
|---|---|
| `pages/图集总览.html` | 生成出来的成品（单文件，双击就能开） |
| `projects/gallery-builder/build.py` | 扫描 + 生成脚本 |
| `projects/gallery-builder/template.html` | 页面模板（改样式改这个） |

---

## 已知情况

- 汇总的是**已经写进 HTML 的图**。`assets/` 里有些图没被任何页面引用（比如还没入库的），这里不会出现。
- 全部是相对路径引用，**页面不能单独拷走**，得跟 `assets/` 一起。
