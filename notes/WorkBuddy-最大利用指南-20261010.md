## 八、给你的 10 条具体做法（照抄即可）

1. **以后建任务先选工作空间** → `Documents\Default Project`（或更细到 `projects\dou-spire`）。
2. **给三个 mod 各开一个空间**：dou-spire / frost-spire / meme-spire，名字改成中文，历史任务自动归类。
3. **mod 崩了别自己翻日志** —— 直接说，我会走 `sts2-mod-debug`：godot.log 定位 → 反编译核对 API → 改 → 编译部署。
4. **要调研**（比如「工坊又上了什么新 mod」）用 `deep-research`，它会先出大纲再并行搜，比一问一答快得多。
5. **出图 / 抠图 / 配音**优先走朋友的魔搭创空间（已在你的 AGENTS.md 第六点九节，最高优先级）。
6. **改动前用 Plan 模式**，尤其「改一堆笔记」「重构代码」这种，先看清它打算动哪些文件。
7. **交付前看右侧「变更」**，确认改的是你想改的文件。
8. **不变量写进 `AGENTS.md`**（工作区根目录，每次开任务自动带上）—— 你已经这么干了，继续保持。
9. **要给别人看结果** 用「分享任务」或「产物分享」，自动生成公开链接。
10. **打游戏时只开一套 wb** —— 昨天卡是因为国内版 + 国际版两个 Electron 同时跑，18 个进程 4.9 GB，且 GPU 进程是 `ABOVE_NORMAL` 优先级跟游戏抢 CPU。codex / CC 是纯命令行没窗口，所以不卡。
11. **⚠️ 有些事必须你自己点一下，别让 wb 跑** —— 今天实测：wb 的终端是**提权**的，而 Steam 是普通权限，两边 IPC 不通 ⇒ 工坊上传器死活卡在 `Initializing Steam`。这类「要和本机 GUI 程序握手」的活（Steam、某些需要同权限级别的程序），你自己在普通终端里敲一下反而更快。wb 的价值在于**先帮你把原因查清楚**，而不是硬跑。
