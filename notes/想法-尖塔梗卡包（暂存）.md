# 想法存档 —— 尖塔梗卡包（已暂停，2026-10-04）

> 玩家结论：**「算了，感觉你不是很适合做卡牌」** → 卡包暂停，成果全部存这里，别再翻散落的文件。
> 本文合并了原来 5 份（调研 / 卡表 / v4 / 卡图提示词 / 撞车检查）。

## 一、为什么做、为什么停
- **做的理由**：工坊已经很饱和（沙盒 / 种子分享 / 回放 / 卡牌交易 / PVP / 自走棋 / 放置 / 卡牌编辑器 /
  骰子 / 融合 / 战绩图表 / 汉化 …… 全都有人做了），但**中文梗是老外做不了的**，
  而 QuestSpire 已经证明这类内容在中文区有受众。
- **停的理由**：卡牌需要**逐张调数值**、还要跟本体 596 张卡错开机制 —— 这是细活，
  做起来不像做 mod 功能那样"有成品感"。玩家觉得性价比低。

## 二、技术路线（已核实，能直接开工）

加一张卡 = 写一个 `ModCardTemplate` 子类，**和我们加遗物是同一套写法**：

```csharp
[RegisterSharedCardPool]                                  // ≈ 遗物的 [RegisterSharedRelicPool]
public sealed class MemeCardPool : TypeListCardPoolModel { ... }

[RegisterCard(typeof(MemeCardPool))]                      // ≈ 遗物的 [RegisterRelic(typeof(...))]
public sealed class JiMiSpirit : ModCardTemplate
{
    public JiMiSpirit() : base(0, CardType.Skill, CardRarity.Rare, TargetType.Self, false) { }
    protected override async Task OnPlay(PlayerChoiceContext ctx, CardPlay play) { ... }
    protected override void OnUpgrade() { ... }           // 敲
}
```
- 卡图：`ModCardTemplate.CustomPortraitPath` 等一堆可覆盖路径；放 `QuestSpire/images/cards/`，走 pck。
- 文案：走我们现成的本地化注入（`LocInjector`）+ `QuestTextEn` 生成器 + pck。
- **撞车检查工具已做好**：`tools/dump_base_cards.py` → `tools/base_cards_zh.txt`（本体 **596 张卡**的中文名 + 效果）。
  设计新卡先搜这个文件的效果列。

## 六、「噶人焖」用的减益池（已按代码筛过）

本体共 **50 个减益**，筛掉一半后剩 **19 个可用**（各 3 层）：

中毒 · 易伤 · 虚弱 · 脆弱 · 缩小 · 柔嫩 · 缓慢 · 紧缠 · 摧残 · 污染 · 消亡 · 瓦解 ·
精神过载 · 衰朽 · 预借时间 · 心灵腐化 · 懒惰 · 恶咒 · 不可格挡

**排除原因分类**：其实是增益（人工制品/幽魂形态）、怪物专属（征服者/吊杀/横冲直撞/尖叫/紧追不放）、
多人专属（多人组队/遭到包围）、对敌人没意义（不可抽牌/无法获得能量/混乱/缠结/昏眩）、
特殊易出错（孤注一掷/幻象/魔法炸弹/魂缚锁链/灾厄）。

⚠️ 这 19 个**没在游戏里实测过**，真做的话要先用【测试】按钮逐张点一遍。
