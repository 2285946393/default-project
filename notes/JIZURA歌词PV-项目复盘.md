## 二、工具是什么

- **JIZURA（字面）** —— `https://github.com/852wa/JIZURA`，MIT，800+ 星，日语项目。
- 线上版：`https://852wa.github.io/JIZURA/`（切中文后地址是 `/zh-hans/`）。
- **纯前端**：歌词、音乐、渲染、编码全在浏览器里，不上传服务器；导出用 mp4-muxer。
- 界面支持 7 种语言（菜单 → Language）。**不是 AI 生成**，是算法排版。

## 三、四条能力边界（重点，别再踩）

1. **界面语言要手动切**。菜单里的 `Language` → 简体中文，切完地址带 `/zh-hans/`。
2. **它不找歌**。伴奏和歌词都得自己给。歌词取网易云，伴奏要么本地有、要么去下载。
3. **⚠️ 手填的「开始（秒）」不驱动时间轴**。输入框能改、数字会留着，但渲染时会被按节拍
   重新分配。而且只要点一次「一键随机」，填进去的数字全部被打回原形。
   **唯一有效的方式是「轻点同步」**——播歌、在每行开头敲一下（空格或 TAP 按钮）。
4. **视频保存按钮在 Codex 内置浏览器里全是哑的**。「分享并保存」（系统分享）和
   「大型视频用（直接保存为文件）」（系统另存为）都点不动。但**普通下载是正常的**
   （工程 json 能存下来）。所以：**先存工程 json，再换到自己的 Chrome 导出视频**。

## 四、可复用的流程

```text
1. 网易云搜歌 → 拿 songId
2. 取歌词：https://music.163.com/api/song/lyric?id=<ID>&lv=1&kv=1&tv=-1
   → LRC 格式，每行形如 [00:28.06]她是位姑娘 我叫她秋呀
   过滤掉 作词/作曲/制作/编曲/混音/母带/封面/出品/营销 这些署名行
3. 取伴奏：https://music.163.com/song/media/outer/url?id=<ID>.mp3
   ⚠️ 只有免费曲拿得到（头部是 ID3 说明成功；返回 HTML 就是被拦/要会员）
4. 开 JIZURA → 切中文 → 歌词语言选「简体中文」→ 贴歌词
5. 载入音乐 → 它自动测 BPM、把镜头贴到节拍上
6. 点「一键随机」（或按 R）摇风格，摇到满意为止
7. 【关键】点「轻点同步」→ 播歌 → 每行开头敲一下
8. 导出范围选「全曲」→ 导出 MP4
9. 先存工程 json（备用）→ 视频换到自己的 Chrome 里导
```

## 五、67 下打拍子的自动化做法

JIZURA 的「轻点同步」是唯一能写入真实时间的入口。做法：用 LRC 的真实时间当目标，
拿页面报的播放时间校正墙上时钟，到点按空格。

```js
const targets = [28.06, 30.04, /* … */ 200.10];

// 每 15 下重新对一次表，避免累漂
const cur = await readPlaybackTime();   // 读页面上的 00:28.06
baseWall = Date.now() - cur * 1000;

const wait = baseWall + targets[i] * 1000 - 20 - Date.now();  // -20ms 抵消按键延迟
if (wait > 0) await sleep(wait);
await press("Space");
```

**实测效果**：205 秒的歌、67 行，敲完误差 0.1～0.3 秒。

**验证方法**（很土但很硬）：跳到 1 分 46 秒，看画面显示哪一行。同步前显示随机分到的第 38 行，
同步后显示第 31 行「待我化作尘土之后」——而这一行真实时间就是 1:42–1:46。
另一个量化验证：把导出范围设成第 1→10 行，看它算出来的时长对不对。

## 七、投稿提醒

- 歌是别人的，工具条款写明「所用歌词和音乐的权利归各自的权利人所有」。
- 公开投稿有被音频指纹命中的风险（限流 / 下架），投稿前自己权衡。
- 简介里写清楚版权归属比较稳妥。
- **B 站标题输入框是它自己组件接管的**：程序一次性写入的值会被覆盖，一刷新就退回旧标题。
  要用逐字敲键盘（`pressSequentially`）才生效。分区、标签、创作声明用真实点击选，不受影响。

## 八、如果再做一次

1. 先确认这首歌**本地有伴奏**，没有就先解决伴奏，再动别的。
2. 歌词在记事本里先过滤干净（去掉署名行），一行一句，别带空行以外的格式。
3. 风格随便摇，**但敲拍子一定放在最后**（摇风格会重置时间）。
4. 视频导出**直接在自己的 Chrome 里做**，别在内置浏览器里耗。
