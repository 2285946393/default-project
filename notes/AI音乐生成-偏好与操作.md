# AI 音乐生成 · 偏好与操作（2026-09-28 定）

> 用网页版 AI 音乐工具（目前是**海绵音乐** haimian.com）把诗做成歌时的规矩。

---

## 一、固定偏好（用户明确要求）

1. **一律用女声版本。** 生成时在提示词里写明「温柔女声演唱」；工具默认常给男声，要主动改。
2. 曲风往**梦幻、治愈**方向走，不要暗黑。
3. 歌词**不许擅自删改**。诗原文多长就贴多长——是否裁剪由用户决定，
   之前擅自把《月下散步闲赋记》砍掉一半，用户当场发现并要求改回全文。

## 二、海绵音乐的正确用法（踩过的坑）

1. **提交要按回车，点按钮没用。**
   在「输入你的灵感或歌词」框里填完，**直接按 Enter** 才会提交。
   「生成音乐」和「免费创作」两个按钮点下去都没反应（2026-09-28 实测）。
2. 页面有两个输入框：
   - `textarea[placeholder*="灵感或歌词"]` —— 贴歌词 / 灵感
   - `textarea[placeholder*="风格"]` —— 风格、情绪、乐器（**默认隐藏**，要展开「个性化」）
   所以风格要求可以直接写在歌词框末尾，例如「（要求：温柔女声演唱，梦幻古风，钢琴与弦乐）」。
3. 进创作页时如果带 `auto_create=1`，Agent 会先问「做成歌词还是生成歌曲」，点「生成歌曲」。
4. 生成一次会出两版（会自己起名字，比如《夏日来信》《夏风与你》）。
5. 工具会自动给歌词分「(前奏)(主歌)(副歌)(间奏)(尾奏)」，**长散文诗它也能自动找副歌**
   ——《月下散步闲赋记》那串「月照耀于…月平荡于…月高悬于…」就是它自己挑出来当副歌的。

## 三、长诗怎么处理

散文诗（比如《月下散步闲赋记》638 字）**不用先删短**。直接全文贴进去，工具会：

- 论述型长句放主歌，做半唱 / 念白
- 从排比句里自动挑出重复性最强的一段当副歌

比起自己先砍一半，让工具先跑一版、再决定删哪句，更不容易误伤。

## 四、自己生成的歌，怎么自动拿到时间轴（2026-09-28 打通）

JIZURA 对轴只能「轻点同步」，一首歌要敲几十下。《滥俗的歌》能自动化是因为网易云有 LRC；
自己生成的歌没有 LRC，就卡住了。**解法：用语音识别自己造一份 LRC。**

```sh
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple faster-whisper   # 约 300MB，装一次
```

```python
import os
os.environ.setdefault("HF_ENDPOINT", "https://hf-mirror.com")   # 别用 HuggingFace 直连
from faster_whisper import WhisperModel
m = WhisperModel("small", device="cpu", compute_type="int8")
segs, info = m.transcribe("歌.mp3", language="zh", vad_filter=False)
```

- 262 秒的歌，CPU 跑约 3 分钟，出 57 段带秒数的文本
- **识别文字会有错字（繁体、同音字），但时间点很准——我们只要时间**
- 把秒数按顺序映射到歌词行，写进工程 json 的 `timing.lineTimes = {"0": 0.5, ...}`
- 在 JIZURA「打开」这个 json → 载入音乐 → **时间轴直接生效，一下都不敲**

**注意**：改时间轴一律走"改 json → 重新打开"。在同一个会话里手填输入框没用
（《滥俗的歌》那次就白填了），旧状态会盖回来。

## 五、裁掉 AI 水印

海绵音乐下载的 mp3 结尾带一段"音频由海绵音乐 AI 生成"的人声。先定位再裁：

```sh
# 在「人声频段」找静音段，最后一段长静音之后就是水印
ffmpeg -v info -i in.mp3 -af "highpass=f=200,lowpass=f=3500,silencedetect=n=-30dB:d=0.25" -f null -
# 直接裁
ffmpeg -i in.mp3 -t 256 -c copy out.mp3
```

⚠️ 只在**伴奏会停**的歌上有用；伴奏从头到尾不停就查不到（《月下散步闲赋记》
查到了，静音在 253.06 秒，水印在 259.5 秒之后）。
