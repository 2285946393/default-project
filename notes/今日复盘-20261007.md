## 二、踩坑（都是今天现踩的）

1. **动作文件挑错，整批白渲。**
   模型根目录的 `aidale.motion3.json` 看着像待机，渲出来 57 帧**每一帧都举着大锤**。
   真正的待机是 `motions/idle.motion3.json`（**89 条曲线**，是前者的 2.5 倍）。
   → **判断办法：待机动作的曲线条数最多。**
2. **JS 用了没定义的变量 → 出来全是 2KB 空图。**
   加了 `expFrame` 分支却忘了 `const expFrame = params.get('frame')`。
   页面抛异常、截图照样"成功"，只是内容是空白。
   → **渲染结果体积异常小 = 页面 JS 报错**，先怀疑变量。
3. **`applyIdleParam` 和 `applyExp` 的顺序。**
   必须先 idle 后 exp，否则眨眼参数会把"爱心眼"这类表情的眼睛盖掉。
4. **Chrome 截图的 `--screenshot` 用相对路径 → 一个文件都不出。** 必须绝对路径。
5. **bash 读 Windows 生成的清单，行尾带 `\r` → 文件名非法。**
   用 python 写 `faces.txt` 是 CRLF，`label` 末尾挂了 `\r`，截图全失败。
6. **`xargs` 遇到带空格的路径会拆错参数**（`Slay the Spire 2` → 名字显示成
   "Slay the Spire love.png"）。不是文件名坏了，是显示方式坏了 —— 用 python 列目录才准。
7. **解压中文 zip：文件名修了编码，顶层目录名漏修** → 目录名变成 `┤╗`
   （实际是"椿"）。补救：`name.encode('cp437').decode('gbk')` 反解回来。
8. **`dotnet build` 平时不用网（用缓存），但只要触发还原就要连 nuget** ——
   卡在 `NU1301 SSL`。**加 `HTTP_PROXY/HTTPS_PROXY` 指向 127.0.0.1:7892 就好了。**
9. **Codex 的模型显示名。**
   复制 `deepseek-flash` 的条目造新模型时**忘了改 `display_name`** →
   界面上 `gpt-6` / `claude-opus-5` 全显示成「DeepSeek-Flash」，
   用户看到"一堆重复的 DeepSeek-Flash"，根本找不到。
10. **`--window-size` + 相对路径 + profile 复用**这三个凑一起会让 headless Chrome 静默不写文件。
