## 5. 高频坑速查（今天全踩过，细节见进度账）

| 坑 | 一句话解 |
|---|---|
| `PowerModel`/`CardModel` 在 `MegaCrit.Sts2.Core.Models` | 不在 Entities.* |
| `PowerModel.Owner` 是生物不是玩家 | 抽牌传 `Owner.Player` |
| Godot 控件子类必须 `partial` | GD0001/GD0002，连带外围类也要 |
| `BeforeCombatStart` 读档不重跑 | 战斗内状态别在它里面初始化（用持久化推导） |
| `[SavedProperty]` 只支持 int/bool/string/枚举/数组等 | 加新状态先想存档 |
| 卡池抽象成员 ≠ 遗物池 | Title/IsColorless/DeckEntryCardColor/CardFrameMaterialPath |
| 先反编译再写代码 | `~/.dotnet/tools/ilspycmd.exe -t <全名> "<游戏>\data_sts2_windows_x86_64\sts2.dll" -o <目录>` |
| PowerShell 含中文 .ps1 必须 UTF-8 带 BOM | 否则 PS 5.1 按 ANSI 读会炸 |
| Write/Edit 偶发弄乱文件 | 写完必 build + 回读 |
| **改 dll 不重启游戏不生效** | 且 mod 可能被禁用——两件事都要查 |
