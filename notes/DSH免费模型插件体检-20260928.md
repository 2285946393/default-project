# DSH 免费模型插件（dsh-our-free-model）体检

## 一、装的是什么

- 插件包：`dsh-our-free-model` v1.3.1
- 位置：`D:\software\dsh-home\profiles\web\node_modules\dsh-our-free-model`
- 数据：`D:\software\dsh-home\our-free-model\`（settings / catalog / availability / stats）
- **上游**：OpenCode Zen 网关 `https://opencode.ai`，路径 `/zen/v1/chat/completions`（少数走 `/responses`、`/messages`）
- **认证**：`Authorization: Bearer public` —— 公开免密车道，**不需要登录、不需要填 key**
- 选择器里的分组名：`Our Free Model`（可用）+ `Our Free Model · region-limited`（地区受限）

## 四、踩到的坑

1. **免费车道有工具指纹闸门**：请求体里没有 `bash / glob / grep / read` 这四个工具名时，
   上游直接 `403 FreeTierError: OpenCode's free tier can only be used from within OpenCode`。
   自己手搓脚本调这个接口必须补齐四个名字；**插件已经自动补齐**（用会话里的真实 pwsh 顶 `bash` 槽），
   所以在 DSH 里正常用不受影响。
2. **额度按"会话"记**：短时间猛打会回 `429`，等一会儿自动恢复（插件会标成"已达限额"而不是藏起来）。
3. **本机没有 `pwsh`**（只有 Windows PowerShell 5.1）。模型如果自作主张把命令写成
   `pwsh -Command "..."` 就会失败——这是模型的问题，不是插件的问题；用 space-bunny 基本不犯。
4. 免费模型集合随上游变，`availability.json` 里 `region-blocked / unavailable` 的条目
   过一阵可能自己回来，插件每 15 分钟自动重探。

## 五、怎么用

在 DSH 输入框的模型选择器里选 `Our Free Model` 分组下的任意一个即可，
设置页里还有 `设置 → Our Free Model`：模型清单、公告、用量看板、本地转发端口、探测设置。

**推荐日常挂 `space-bunny-free`**，要快就 `ling-3.0-flash-fin-free`，要深想就 `nemotron-3-ultra-free`。
