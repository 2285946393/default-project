# 凛冬尖塔 · 传送门方案——「树洞」机制拆解（ZCode 侦察，2026-10-06 深夜）

> 用户提议：「地图上有个点，走传送门去另一张我们的地图，直接我们的玩法，生成怪，打完直接结算。」
> 指名参考 mod：**集成战略事件 IntegratedStrategyEvents**（工坊 3747637213，作者 Natsuki——海克斯符文同作者）。
> 本机拆了它的版本化 dll（lib/0.111.0/IntegratedStrategyEvents.dll，1.1MB）。
> 结论：**能做，有已上线的实盘样板，整个机制它都趟平了。**

## 一、它的"传送门"是怎么实现的（五个部件）

1. **自定义 ActMap 子类 = 另一张地图**。`IntegratedStrategyTreeHoleActMap : ActMap`：
   自己的 `Grid`（MapPoint[7,6]）、`StartingMapPoint`（MapPointType.Ancient）、`BossMapPoint`（Boss），
   中间用 `CreatePathPoint` / `CreateBranchRow` + `AddChildPoint` 连路。
   **"一张迷你地图"就是一个 ActMap 网格**——它还提供了 `CreateSpecialPoint/CreatePathPoint/RollPointType`
   这类现成的摆点方法（照抄即可）。
2. **入口 = 事件选项**。自定义事件里选「踏入裂隙」→ `EnterProphetHornFragmentFromEvent(owner, …)`；
   联机走 `EnterSpecialFinaleFromSyncedAction(owner, kind)`（同步动作，各端一致）。
3. **地图交换 + 快照存取**（这是最难也最值钱的部分）：`TreeHoleSaveSnapshot` / `TreeHoleRestoreSnapshot`——
   进门时把**原地图/坐标/访问历史/ActFloor 全部快照**（OriginalMap/OriginalVisitedMapCoords/OriginalActSave），
   把当前 `state.Map` 换成临时地图；打完**原样还回来**。存读档安全靠这套快照（还有 `SerializableActMap.FromActMap`）。
4. **出口协调**：`[HarmonyPatch(typeof(RunManager), "EnterNextAct")]` → `HandleEnterNextAct`——
   临时地图打完后，"进入下一幕"被接管：要么回原地图，要么走它的终局。
5. **共存接口**：`IntegratedStrategyEventsInterop`（public）+ `IsTemporaryMap` +
   `RegisterSecretNodeSkipPredicate`——**它留了公开口子让别的 mod 注册自己的临时地图**，
   我们做传送门时应该用它登记，避免两边的地图补丁打架。

## 二、凛冬尖塔的传送门版怎么做（方案）

```
地图上出现事件「凛冬裂隙」（普通事件房/事件池注入，或固定节点）
  → 选「踏入裂隙」→ 快照原地图 → 换入 FrostRiftActMap（我们的迷你地图）：
      16 波表 = 地图节点：普通波=战斗节点、精英波=精英图标、事件波=事件节点、第16波=BOSS 顶点
  → 每个节点 = 一场普通战斗（复用波次表的编排；波次引擎的"一场超长战斗+双锁"退役）
  → 节点间奖励走本体流程（打完节点弹奖励，比间隙补给更正统）
  → 打完 BOSS 节点 → EnterNextAct 协调器把原地图还回来 → 结算 → 继续正常爬塔
```

- **现有资产 100% 复用**：16 波编排、精英力量强化、事件双选、 CONTRACT 的怪池全不动；
  变的只是"波次的载体"从一场超长战斗变成一张小地图。
- **额外好处**：存档天然分场（每节点一场，不用做战斗内快照）；拥挤问题彻底消失；
  波次预告面板的活让地图 UI 自己干了。

## 三、工程量与风险

| 项 | 评估 |
|---|---|
| ActMap 网格 + 摆点 | 小（它的摆点方法照抄，16 节点比它的 7×6 还简单） |
| 入口事件 | 小（事件注入 API 待核——RitsuLib RegisterEvent 或事件池 hook） |
| **快照存取（进/出/读档）** | **大，全案命门**——要逐行读它的 TreeHoleSaveSnapshot/RestoreSnapshot 并自己实现一份 |
| EnterNextAct 协调器 | 中（Harmony 补丁，quest-spire 有 Harmony 经验） |
| 联机 | 用 FromSyncedAction 模式；v1 仍建议单机 |
| 与集成战略 mod 共存 | 用它的 Interop 注册；没装它也要独立可跑 |

**建议排期：M3.5（工事牌 M3 之后）**。理由：工事牌是"房间里玩的东西"，传送门是"门面"；
先厚玩法再换门面，且传送门需要专门一轮伺候快照系统。
若用户更想先看门面，可对调——工事牌侦察已完毕，两条路随时能切换。
