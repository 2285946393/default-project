[h1]🀄 斗地主尖塔 · 在杀戮尖塔 2 里开一桌斗地主[/h1]

[b]三条命变三副牌。[/b]铁甲战士、荒疫猎人坐你对面，还有四个会说日语说中文的二次元角色陪打——抢地主（猜拳定！）、明牌、加倍、炸弹翻倍、筹码结算，一个不少。
[b]还可以把牌面换成杀戮尖塔的卡[/b] —— 打击、防御、背刺、大爆炸，一整套尖塔牌桌。

[h2]🎮 玩法[/h2]
[list]
[*][b]完整斗地主牌型[/b]：单张 / 对子 / 三张 / 三带一 / 三带二 / 顺子 / 连对 / 飞机 / 飞机带单 / 飞机带对 / 四带二 / 四带两对 / 炸弹 / 王炸
[*][b]抢地主 · 猜拳[/b]：要抢的人一起在桌上出拳（石头剪刀布），赢的当地主 —— 用的是游戏本体的联机手势图
[*][b]明牌[/b]（底注翻倍）/ [b]加倍[/b]（地主农民各选）/ [b]炸弹翻倍[/b] —— 倍数在顶部实时显示，翻倍时牌桌中央弹大字
[*][b]筹码系统[/b]：开局每人 1000，地主一人对两个农民，按倍数结算
[*][b]出牌时限[/b]：默认 20 秒（可在设置里调，能关）
[*][b]单人[/b]：一个人打两个电脑
[*][b]多人[/b]：篝火处点「斗地主」，和队友同坐一桌打（主机开局、客机入座，中途离桌自动转 AI）
[/list]

[h2]🃏 尖塔牌面（可选）[/h2]
设置里可以把牌面从「经典斗地主」切成[b]「尖塔牌面」[/b] —— 牌会直接渲染成[b]杀戮尖塔的卡[/b]（打击、防御、背刺、大爆炸、神化……），
用的是游戏自己的卡牌节点，所以[b]你装了改卡名的 mod（比如梗化尖塔），桌上的牌会跟着变[/b]。
[b]牌力完全不变[/b]：打击还是当 3、防御当 4，顺子连对王炸照旧。

[h2]🌸 四个二次元角色[/h2]
每个角色都有自己的一整套配音（14 类牌局事件 + 抢地主，全中文/日语），出牌会换表情、平时一直在呼吸摆动。

[list]
[*][b]DS鲸鱼娘[/b]——吃白饭的蓝色大肥鱼，出炸弹会喊"我就是吃白饭的蓝色大肥鱼"
[*][b]椿[/b]——《鸣潮》花女，危险又暧昧，"再来一局吧？"
[*][b]八千代辉夜姬[/b]——软糯妹系，全程日语
[*][b]橘雪莉[/b]——《魔法少女的魔女审判》名侦探，笑眯眯地说"犯人确定了"
[/list]

[h2]🔊 原版音效[/h2]
不只是配音——出炸弹会响[b]故障机器人的超能光束[/b]，当上地主响[b]摄政王的主权之刃[/b]，赢了是[b]三档天降金币[/b]。全是从游戏本体的音效库里挖出来的原音。

[h2]📥 安装[/h2]
[list]
[*]Steam 创意工坊订阅即可，不依赖其它模组
[*]需要游戏本体 [b]v0.107.1+[/b]
[*]角色素材体积较大（约 100MB），订阅时请耐心等下载
[/list]

[h2]👆 怎么玩[/h2]
主菜单点[b]「斗地主尖塔」[/b]。进桌后：翻箭头选人 → 决定明不明牌 → 抢地主（猜拳）→ 加倍 → 开打。
快捷键 [b]F9[/b] 收桌 / 开桌。牌面风格、音量、出牌时限都在[b]设置 → 模组配置[/b]里。

[h2]🔧 推荐搭配[/h2]
[b]想让桌上的游戏角色也变好看？[/b]推荐两个搭配着用：
[list]
[*][b]Voice Framework (Regent Mesugaki Voice)[/b]（[url=https://www.nexusmods.com/slaythespire2/mods/880]N 网 880[/url]，作者 Yatima2215）——把摄政王娘化成傲娇小皇帝，自带一整套语音（配上娘化卡图更搭）
[*][b]摄政王娘化卡图 / 皮肤 mod[/b]（N 网 / 创意工坊）——替换约 50 张储君的卡面立绘，配上娘化语音更搭
[/list]
这两个都是可选搭配，不装也能正常玩。
