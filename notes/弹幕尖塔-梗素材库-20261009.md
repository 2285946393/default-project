## 0. ⚠️ 2026-10-09 玩家放宽了限制（先看这条，再看下面的 §1）

写这份库的时候，梗化尖塔的铁律是「梗源要**全国大众**都懂，别只玩尖塔圈内梗」，
所以我在 §1 里写了"这份素材不能直接当卡名用"。

**当天玩家把那条铁律放宽了，原话：**

> **「不一定是全国。我们这个mod只有尖塔玩家」**

→ **下面 §1 的警告作废。圈内梗现在是合法素材，可以直接用（包括名字）。**
→ **§2 / §3 / §6 的用法照旧，只是不用再"只挑大众梗"了。**
→ 唯一没变的：**必须是"梗"，不能是"换个说法/近义词"**；
  以及**说明类文字（卡牌 `.description`、状态描述、关键词名、UI 按钮）仍然不能动**。

## 1. ~~⚠️ 先说清楚：这份素材**不能直接当卡名用**~~（已被 §0 推翻，保留作历史记录）

梗化尖塔的铁律是「**梗源要全国大众都懂，别只玩尖塔圈内梗**」。
而这 336 条里，**超过一半是纯尖塔圈内梗**：

| 圈内梗 | 意思 |
|---|---|
| 铁斩波 / 打打防防 | 一代「铁波」卡（攻防一体），社区用来调侃任何"又攻又防"的东西 |
| 咔咔美声 | 雕塑家 Boss 吟唱时的音效 |
| 误弑灯 / 无视灯 | 女王 / 火炬头 Boss 战里的「灯」 |
| 红色格挡条 | 把**血条**当格挡条（掉血 = "用脸接"） |
| 蓟县 | 「极限」的谐音（天津蓟县） |
| 尽孝 | 拿到强力卡/遗物 = "给牌尽孝" |
| 算你赢了 | 社区口头禅「X 算你赢了」 |
| 敲牌大于一切 / 删牌大于一切 / 好牌多抓 | 尖塔打法口诀 |
| 观者打过来了 | 「观者」= 一代角色（The Watcher） |
| 东尼意思 | 制作人安东尼（**已在梗清单里**） |
| 战个未来 | **已在梗清单里** |

**所以这份素材的正确用法是下面三种，不是第四种。**

### ✅ 用法一：一份「社区怎么叫这些东西」的权威对照表（最值钱）

这是**唯一一份"社区原生叫法"的实机数据**。
做名字时能蹭上共识 —— 玩家一看就知道你在说什么，而且会觉得"你懂"。

### ✅ 用法二：句式模板（可无限套用）

这些句式**本身是大众梗**，只是被社区拿来用了。
**换个词就能套到任何卡/遗物/怪物上**，是真正的产能工具：

| 句式 | 例句（原库） | 怎么套 |
|---|---|---|
| **我说 X 有没有懂的** | 我说{card}伤害特别高 | 尖塔圈句式（梗清单已有），可继续扩 |
| **我说 X 算你赢了** | 我说 sl 算你输了 | 「算你赢了/输了」是社区口头禅 |
| **X 大于一切** | 删牌大于一切 / 敲牌大于一切 / 动画大于一切 | 万能口号句 |
| **X 了家人们** | 动画卡我启动了家人们 | 直播带货腔 |
| **！？X？！** | ！？观观？！ / ？！banana！？ / ！？不拿拿？！ | 弹幕震惊体 |
| **XX，XX 了** | 抉择，抉择了 / 好好睡，好好睡 | 重复强调体 |
| **依旧 X** | 依旧尽孝 / 依旧假装思考 / 依旧冲精英 | "又来了"的疲惫感 |
| **X 这一块** | 折磨观众这一块 | "XX 这一块"是大众热词 |
| **X 享受者 / X 爱好者** | 大数字享受者 | 大众句式 |
| **有一个角色 X，你知道他是谁** | 有一个角色{hp}血冲精英，你知道是谁 | 悬念体 |
| **记笔记，X** | 记笔记，{char}不抓{card} | 学习型弹幕 |
| **细节 X** | 细节不防骗弹幕 / 细节保护血上限 | "细节"反讽 |
| **X 算你赢了** | 神化算你赢了 / 无伤算你赢了 | 同上 |
| **X：下把不来了** | {card}：下把不来了 | 拟人化句式 |

### ✅ 用法三：挑几条圈内梗当**彩蛋**

一条圈内梗都不放，老玩家会觉得"这 mod 不像懂尖塔的人做的"。
建议挑 **5–10 条最经典的**（铁斩波 / 咔咔美声 / 红色格挡条 / 尽孝 / 算你赢了 / 东尼意思）
撒在**不影响理解**的位置（风味文案、成就名、徽章名、历史节点），**不要放在卡牌名上**。

### ❌ 用法四（别做）：拿圈内梗当卡牌名

玩家看不懂，违背「不改说明类文字、名字必须大众都懂」的原则。

## 5. 用法提醒（别踩）

1. **`{card}` `{item}` `{hp}` `{char}` `{x}` `{count}` 是占位符**，
   借用句式时**要么替换成具体词，要么原样保留**（梗化尖塔铁律：占位符一个都不能丢/加）。
2. **弹幕是"旁白"和"角色"两种口吻**（原库 `style: narration / character`）。
   做**风味文案**用旁白体（259 条），做**角色台词/语音**用角色体（77 条）。
3. 带 `variant` 的 17 条是**同规则不同分支**（如桥梁事件 `weak`/`strong`、
   收集品 `waiting`/`completed`/`timeout`），借的时候注意分支语义。
4. 作者声明「模组不自行创作弹幕文本，全部来自社区抓取或玩家投稿（经人工审核）」——
   所以这份库**可以当"社区共识"证据**用，但**文本版权归社区/投稿者**，
   直接照搬成商品 mod 的文案前，建议**改写**而不是原样抄。
