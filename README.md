## 我在做什么

我的作品有一个共同点：**把抽象的规则变成别人一打开就能玩、能看懂的东西**——调一个参数、拖一下鼠标，屏幕里的世界就会真的改变。

技术上，我关注三件事：**浏览器里的实时模拟与渲染**、**AI 能力如何变成可靠的产品功能**、以及**把成熟的开源技术改造成有完成度的作品**。

## 关于开源

这个仓库里有多个作品是**基于成熟开源项目改造**的。我的做法是：

1. 找合适的技术底座，**读源码理解它的入口、依赖与核心机制**
2. 判断它值不值得做成一件作品
3. 然后**自己负责玩法设计、交互、视觉与工程适配**

我倾向于**不重复造轮子**——把时间花在有差异化的部分。所有改造都保留了原项目的来源标注与许可信息：

| 作品 | 原项目 | 许可 |
|---|---|---|
| 粒子生命 | [hunar4321/particle-life](https://github.com/hunar4321/particle-life) | MIT |
| 元素秘境 | [MaxBittker/sandspiel](https://github.com/MaxBittker/sandspiel) | MIT |
| 流体花园 | WebGL Fluid Simulation | MIT |
| 菌丝世界 | [MattKulka/mycelia](https://github.com/MattKulka/mycelia) | 原作未声明许可证，故仅标注来源 |
