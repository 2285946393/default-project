3要补的四件事 按性价比排序，不是按难度

1
工具调用（Function Calling） 半天
Agent 的地基，也是最短的一块板。用 Vercel AI SDK 的 tools 参数给面试间加一个工具——比如「查我的知识库」「按岗位调题库」，让模型自己决定调哪个。
补完你就能说：「我实现了 function calling，模型自主选择工具」——这一句在 Agent 岗里含金量很高。
2
一个真正的 Agent 项目 1–2 周
这是简历上最缺的一行。最省力的做法是把面试间升级成 Agent：加工具调用 + 多轮记忆 + 任务规划（先出题 → 追问 → 复盘，让模型自己决定下一步）。
不要新开一个从零的大坑——升级已有项目比新做便宜十倍，而且面试时能讲的东西更多。
3
Python 基础 3–5 天
JD 里的硬门槛，绕不过去。不用精通：能读懂、能写脚本、能用 FastAPI 起一个服务、知道怎么调 openai 官方库就够了。
你的 JS 底子很好，Python 对你是换语法不换思维。
4
LLM 原理 + MCP 概念 各半天
原理：Transformer 大意、上下文窗口、幻觉怎么来的、Prompt 注入怎么防——够用来回答问题就行，不用啃论文。
MCP：知道它是什么、解决什么问题、能说出你日常在哪些工具里用过它。
