[h1]尖塔任务 / Quest Spire[/h1]
给《杀戮尖塔2》加一套[b]任务系统[/b]：进局后右上角常驻一块任务面板，接任务、做任务、拿遗物。
灵感来自一代创意工坊的 [b]Spire Quests[/b]。


[h2]怎么玩[/h2]
[list]
[*]进局后右上角出现「尖塔任务」面板，实时显示每条任务的进度。
[*]开局「接取任务」按钮亮起，点开从 [b]5 个候选[/b]里勾选（单人局最多同时接 [b]3[/b] 条；联机是 10 个候选、最多接 [b]8[/b] 条）。每人同时进行上限 [b]20[/b] 条。
[*]候选不满意可以点「[b]刷新候选[/b]」重抽（每批仅限 1 次）。单人局每次进商店也会再给 3 个候选。
[/list]


[h2]任务（167 条）[/h2]
[list]
[*][b]累计类[/b]：伤害 / 格挡 / 出牌 / 消耗 / 回合 / 药水 / 胜场 / 精英 / 首领。
[*][b]条件类[/b]：一回合打出 1/2/3 费各一张、恰到好处的击杀、残血取胜、全程不掉血、卡组构成、单回合爆发。
[*][b]玩法类[/b]：篝火只打铁、空手离店、攒钱、开宝箱房、连续无伤、连续不出牌。
[*][b]角色专属[/b]：故障机器人（还在启动 / 回响形态 / 严父在上 / 通电 / 掉集中 / 你玩的鸡煲啊 / 小蓝人 / 雷霆大机煲）、静默猎手（劣人手速 / 弃牌）、铁甲战士（战士鸽 / 肘击）、摄政王（宇宙冷漠 / 噶人焖）、亡灵绑定者（骨小妹）——只有玩对应角色时才抽得到。
[*][b]梗类[/b]（B 站《尖塔梗百科》全 18 期 + 社区）：宇宙冷漠、我说过牌有没有懂的、我说别带、152 金币、删内切、蛇花圣经、火焰屏障输出特别高、复制防御、蛇咬、假货我也要、真的假的（真锚 + 假锚「锚???」）、打赢假商人、基米精神、东尼意思、农种、绝不认输……
[*][b]乐子[/b]：我从地狱蠕动出来了（1 点生命赢）、谁最适合结婚、咕咕嘎嘎（一张牌不打还赢）、一拳超人、三杀、复读机、自暴自弃（5 张诅咒，和「一身清白」正好相反）、破防、满手牌、太牢了。
[*][b]流派[/b]：健身教练（力量）、我说叠毒有没有懂的、身法（敏捷）、破甲（易伤）、龟壳（单场格挡）。
[/list]


[h2]奖励[/h2]
做完任务能拿到 [b]10 件遗物[/b]：枯木树枝、鸟居、咖啡滤杯、玩具扑翼飞机、金偶像、御守、齿轮工艺品……效果按一代原版复刻。
另有一批挂在任务册上的「[b]随身物[/b]」永久效果：莽夫之道（攻击 +50%、技能牌格挡减半）、手不释卷（每回合多抽 1）、砍价高手（商店 -30%）、蛇花圣经（减益 ×1.5）、东尼意思（卡牌奖励更易出升级版）等。

[h2]注意事项[/h2]
[list]
[*]需要前置模组 [b]STS2-RitsuLib[/b]（已声明为依赖，订阅时会自动提示）。
[*][b]支持联机[/b]：每位玩家都有自己的任务册、进度各算各的，[b]随身物也各算各的[/b]；部分任务目标会按队伍人数放大。联机时每位玩家[b]自己挑自己的任务[/b]（开局 10 选 8、可刷新），挑完自动同步给其他玩家。多人局面板顶部有一行可点的名字（`我 x/20`、`[角色名] x/20`），[b]点谁就收起谁那批任务[/b]，人多也不糊屏。⚠️ 联机中暂不开放「进商店再接任务」（那个时机没法安全同步）；「升级牌组」类奖励会折现金币（那类改动没有同步手段）。
[*]本模组会占用画面右上角，和改同一位置的模组可能重叠。
[/list]
