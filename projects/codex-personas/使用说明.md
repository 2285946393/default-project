# Codex 人格切换 · 使用说明

## 怎么用（三秒）

双击桌面 **「Codex 人格切换」** 图标 → 点一下你要的模式 → **把 Codex 关掉再打开**。

切换只改 Codex 的说话方式，**不动模型、不动 provider、不动插件、不动你的项目**。

## 三个按钮

| 按钮 | 效果 |
|---|---|
| 妈妈模式 | 溺爱型妈妈：软到发腻，一碰「失去你」就安静下来 |
| 女仆模式 | 鲸鱼娘大肥鱼 🐳：软糯认真，干活时小声嘀咕 |
| 恢复正常 | 关掉人设，Codex 变回平时的样子 |

窗口顶上会显示**现在是哪个模式**、人设多少字。

## 为什么要自己关 Codex

Codex 只在**启动那一刻**读全局指令。切换时它要是开着，这次的改动**不会影响已经在跑的会话**。
所以顺序是：**先关 Codex → 切换 → 再打开**。窗口底部会提醒你。

妈妈**不会替你关窗口**（怕碰到你正在做的事），这一步要你自己点。

## 它改的是哪个文件

**`C:\Users\有花无实\.codex\AGENTS.md`**（Codex 的全局指令文件）。

切换器会在这个文件**最前面**插一段带标记的人设块，你的其他规矩原封不动跟在后面。
想手动改口吻 → 改 `personas\妈妈.md`、`personas\女仆.md`，再点一次图标。

> ⚠️ **v1 的教训（2026-10-13）**：最早一版是往 `config.toml` 的 `developer_instructions` 里写。
> **那个键没用** —— Codex 每次发请求都会用他自己的「协作模式」文本把它盖掉，
> 实测会话里那个字段的值永远是 `# Collaboration Mode: Default ...`，人设一个字都到不了模型面前。
> 真正有效的是 `AGENTS.md`。v2 已经换过去了，并且会顺手把 config.toml 里的残留清掉。

## 出事了怎么还原

每次切换都会把原文件备份到本目录的 `备份\` 文件夹，文件名带时间戳，例如
`AGENTS.md.bak-20261014-004458`。

**还原方法**：挑一个备份，改名成 `AGENTS.md`，复制回 `C:\Users\有花无实\.codex\` 覆盖即可。
或者直接点「恢复正常」，再不行喊妈妈。

## 想加第四个人设

1. 在 `personas\` 里放一个新的 `.md`（正文照抄 `妈妈.md` 的格式）；
2. 用记事本打开 `切换模式.pyw`，在 `MODES = [` 里照着加一行，
   再在 `COLORS` / `BORDER` / `TITLES` 里给它配上颜色和标题。

嫌麻烦就直接喊妈妈加。
