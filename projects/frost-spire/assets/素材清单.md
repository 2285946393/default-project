# 凛冬尖塔 · 素材清单（等图的清单）

> 规矩（quest-spire 定的）：**不自己造美术，等用户给图**。
> 图放进本目录（`assets/`）后 —— **不用重编译、不用重启游戏**，重开面板/重进局即生效。
>
> 加载顺序是「**自己的图 → 游戏自带的图 → 纯色兜底**」（见 `FrostSpireCode/UI/FrostAssets.cs`）。
> 画一张覆盖一张，没画的自动用游戏本体的，界面永远不会开天窗。
> 开局时日志会打一条盘点，写明每个槽位最终用了哪张图：
> ```
> 凛冬素材：用自己的 N 个，用游戏自带 N 个，没有素材 N 个。assets 目录：...
> ```
> ⚠️ 参考图库：`projects/sts2-asset-library/`（1846 张，从 pck 导出，按游戏原 res:// 路径存放）。
> 打开它的 `index.html` 可搜索、按目录筛选。

**按钮分状态命名**（可选，画了更好看；只对自己的图生效）：
```
buttons/btn_primary.png            ← 常态（必须有这张）
buttons/btn_primary_hover.png      ← 鼠标悬停
buttons/btn_primary_pressed.png    ← 按下

```

**九宫格切法**：标了「九宫格」的是**拉伸用**的，出图时把**四角画成固定大小、中间可拉伸**。
代码里按边距 **12px（1920 基准）** 切，四角别小于 40px（2 倍图上）以免拉糊。

## 三、画风（沿用斗地主那套工艺标准，但色板换冰雪）

参考 `projects/sts2-asset-library/风格基准/README.md` —— 那套「描边 / 上光 / 饱和 / 质感」四条
是**共用的对稿标准**，保证两个 mod 摆一起不像两个游戏：

| 检查项 | 标准 |
|---|---|
| **描边** | 每块形状外圈一圈**近黑 `#1A1512`**，粗细**均匀** |
| **上光** | 光**只从左上**来，右下一律压暗；一块面上只有**一条**明暗交界线 |
| **饱和度** | 低饱和。**没有荧光色、没有高亮纯色** |
| **质感** | 平涂为主，**看不到笔触**；磨损裂纹用**硬边小色块**画 |

⚠️ **凛冬的色板不照抄牌桌**：主色走**冷蓝 / 霜白 / 暗铁**，强调色用**霜金**（`FrostUi.Gold`），
而不是斗地主的赌坊暗红。
