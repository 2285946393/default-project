# 尖塔决斗 · Spire PvP

《杀戮尖塔 2》双人构筑 PvP，当前测试版 0.2.5。

## 使用

双方订阅并启用本 Mod 和 BaseLib 3.4.7 或更新版本，使用相同游戏和 Mod 版本。在「多人模式 → 创建」选择「PvP · 构筑决斗」，邀请另一名玩家加入。

房主可选 10 / 15 / 20 次三选一，或现开套牌（30 张选 10 张）。双方构筑完成后，点击地图唯一决斗入口。每回合同步抽牌和恢复能量，双方就绪后自由抢速出牌，两人都结束回合后进入下一回合。双方视角中自己在左、对手在右。

在「设置 → 模组配置（BaseLib）→ 尖塔决斗」调整生命、格挡、召唤、受到灾厄与中毒的倍率，或切换壁垒。默认分别为 2 / 1.5 / 1.5 / 0.5 / 1 倍，壁垒默认开启。新建房间生效，以房主设置为准；灾厄和中毒调整新增层数，减少或清除层数不缩放。

## 当前范围

- 针对游戏 v0.111.0 / 41cef1ea 编译。
- 244 项自动检查通过，已验证启动；双机实战、全卡池及其他玩法 Mod 组合仍需继续测试。
- 仅支持双人独立 PvP；普通爬塔 Boss 后 PvP 暂时停用。
- 独立 PvP 不保存为正常爬塔存档，不支持退出后读档续战。
- 网络延迟仍影响联机体验，额外回合由双方共同进入。
