# dou-spire-rules — 斗地主玩法内核

「斗地主版杀戮尖塔」项目的规则底座：**一套能真打完一局的斗地主内核**（纯规则，不是游戏）。

> 不依赖游戏、不依赖引擎、不依赖任何第三方包。
> `Cards.cs` / `Combo.cs` / `ComboJudge.cs` 以及 `Game/` 下的引擎可以**原样搬进 mod 工程**
> （同样 net9.0 环境，跟 `projects/quest-spire`、`projects/frost-spire` 一致）。

配套文档：
- `notes/斗地主尖塔-可行性与方案.md`（可行性 + 技术路线 + 工作量分级）
- `notes/斗地主拆解笔记-20261006.md`（拆开源实现的结论，含被逮出来的边界规则）
- `notes/斗地主尖塔-牌面与界面方案.md`（两版牌面换皮 + UI 摆位）

## 跑起来

```bash
bash run.sh                    # 全套自测（30613 条断言）
bash run.sh -- --play          # 跟两个电脑打一局（终端版）
bash run.sh -- --play 777      # 指定种子
bash run.sh -- --demo          # 三家全电脑，把整局流程打出来
bash run.sh -- --sim 2000      # 电脑自战 2000 局
```

在普通 CMD / PowerShell 里也可以直接 `dotnet run -- --play`。

## ⚠️ 本机环境坑（重要，别的 AI 接手前必读）

**在 WorkBuddy 的 bash 里直接 `dotnet build` 会失败**，报：

```
error : Value cannot be null. (Parameter 'path1')
```

**原因**：WorkBuddy 的 bash 沙箱启动子进程时不带 Windows 系统环境变量
（`SystemRoot` / `ProgramData` / `APPDATA` 等全缺）。.NET 的
`Environment.GetFolderPath(CommonApplicationData)` 因此返回空，
NuGet 拼不出机器级配置路径（`%ProgramData%\NuGet`），`Path.Combine(null, "NuGet")` 直接抛异常。
连已经能跑的 `projects/frost-spire` 在这个 shell 里也构建不了——**不是工程的问题，是 shell 的问题**。

**两个绕过办法**（`run.sh` 里都做了）：

1. 补齐系统变量：`SystemRoot` / `windir` / `ComSpec` / `ProgramData` / `ALLUSERSPROFILE` /
   `APPDATA` / `LOCALAPPDATA` / `TEMP` / `TMP` / `ProgramFiles` / `CommonProgramFiles`。
2. 加参数跳过 NuGet 配置加载：
   `-p:MSBuildEnableWorkloadResolver=false -p:RestoreProjectStyle=`

本项目零第三方依赖，所以绕过 NuGet 是安全的。
**带 NuGet 依赖的工程**（quest-spire / frost-spire 要 RitsuLib / Godot.NET.Sdk）
在沙箱里仍然构建不了——那两个**用你普通终端里的 `dotnet build`**，或者在 WorkBuddy 之外跑。

### 最有说服力的两组：跟开源实现正面对答案

对的是 **rlcard**（`datamllab/rlcard`，斗地主规则引擎写得干净，自带穷举生成的全量表）。
它是"标准答案"，我们是"考生"：

| 组 | 怎么验 | 结果 |
|---|---|---|
| 七 | 27471 条合法出牌逐条认牌型 + 3076 对逐对比大小 | ✅ 0 失败 |
| 八 | 74 副手牌，把**每个子集都穷举一遍**（9,699,254 种），跟 rlcard 真实判牌器双边比 | ✅ 完全一致 |

**第七组是单向的**（"表里的我认不认"），**第八组是双向的**（"我多认的它认不认"）。
正是第八组逮出了 16 条我原来判错/判漏的边界，归成 3 类：

```
我原来会把  QQQQKKK   判成"飞机带单"   ← 拆炸弹去凑飞机，应该拒
我原来会把  QQQQKKKK  判成"飞机带单"   ← 两个炸弹冒充飞机，应该拒
我原来会把  AAAABR    判成"四带二"     ← 带牌是双王，应该拒
```

修完复跑，4263 = 4263，一条不差。

## 自战结果（200 局）

```
地主胜 135 ／ 农民胜 65（地主胜率 67.5%）
平均 47.2 回合，最长 82 回合，卡死 0 局
```

- **0 卡死** → 轮次指针 / 要不起 / 自由出牌这套流程自洽，不会"两个人互相要不起然后死循环"。
- 地主胜率 67.5% 偏高（真实高手局约 55~60%），原因是农民 AI 不会配合（只有"不抢队友"这一条）。
  **属于 AI 强度问题，不是流程问题**，以后换 DouZero 或加配合逻辑即可。

## 结算方式（按用户要求）

赢家手牌一空 → 直接判另外两家失败，赢家显示胜利。**不需要对玩家造成伤害**，
直接用原版的血量/失败/胜利流程：

```
── 电脑A（地主）赢了；我、电脑B 判负。
```

## 已知的规则取舍（先这样做，要改再说）

- **一对王**：一副牌里两张王 = 王炸（不是对子）；两副牌里两张王**不算**王炸（王炸要四张王）。
- **带牌不许是炸弹**：飞机的链上点数必须正好 3 张，多出来的那张不能当带牌（不许拆炸弹凑飞机）。
- **四带二 / 飞机带单的带牌不能同时是两张王**（rlcard 同款）。
- **贴边带牌上限 2 张**：跟飞机相邻的点数最多拿 2 张当带牌（第 3 张会产生歧义）；`2` 例外。
- **四带二**：允许四张 + 任意两张单（或两对）。
- **顺子/连对/飞机**：只到 A，不含 2 和王。
- **炸弹**：四张及以上同点数；两副牌下**张数多的大**，张数相同比点数。
- **定地主**：目前按手牌评分自动定（炸弹 +6、王炸 +8、A/2/王加分）。
  **还没做"叫地主/抢地主"**——如果要真人互动，这是下一步。
