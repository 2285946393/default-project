# 弹幕尖塔 DanmakuSpire

一个《杀戮尖塔 2》（Slay the Spire 2）的纯事件监听型模组：不添加角色与卡牌，只监听你的爬塔行为（打牌、购买、受伤、SL 等），在对应时机以横向滚动弹幕显示来自社区的弹幕。多人模式下，队友的行为弹幕也能互通显示。

A pure event-listening mod for *Slay the Spire 2*: it adds no characters or cards. It watches your run actions (card plays, purchases, damage taken, save-loads, etc.) and shows community danmaku as horizontally scrolling messages. In multiplayer, teammates' behavior danmaku is shared as well.

## 功能特性 / Features

- 58 条行为规则（A1–H1 + I1–I3 多人专用 + E14 卡组过小 + F3 领主阳伞）覆盖战斗、奖励、商店、事件、火堆与 Run 生命周期 / 58 behavior rules covering combat, rewards, shops, events, rest sites and run lifecycle
- 横向滚动弹幕：原版静态烟雾九宫格、官方字体与角色头像、4–12 条可调轨道 / scrolling danmaku with vanilla smoke panels, official fonts, character avatars and 4–12 adjustable lanes
- 玩家可调配置：弹幕开关（关闭/仅单人/仅多人/所有）、字号、透明度、背景样式、速度、显示区域、词条密度、顶部弹幕 / configurable switch (off / single-player only / multiplayer only / all), font size, opacity, background style, speed, display area, density and top-pinned mode
- 多人模式：只传信号不传文本（防注入），队友弹幕本地渲染；握手确认模组版本 / multiplayer: only signals are sent (no raw text, injection-safe); peer danmaku is rendered locally; handshake verifies mod version
- 共创弹幕：玩家在游戏内投稿（昵称/文本/触发时机/前置条件），作者人工审核后以版本化快照下发，本地离线播放 / co-created danmaku: players submit in-game; after author review a versioned snapshot is distributed for offline playback

## 安装 / Installation

弹幕尖塔没有任何外部模组前置。手动安装时请完整复制发布包中的 `DanmakuSpire/` 目录（包括 DLL、清单和 `content/` 内置内容快照）到游戏目录的 `mods/` 下；也可直接通过创意工坊安装并在游戏的模组管理中启用。不要只复制 DLL/PDB/JSON，否则 1.2.1 的外置内容基线不会随包安装。

DanmakuSpire has no external mod dependencies. For a manual install, copy the complete released `DanmakuSpire/` directory—including the DLL, manifest and built-in `content/` snapshot—into the game's `mods/` directory. Alternatively, install it through the Workshop and enable it in the mod manager. Copying only the DLL/PDB/JSON omits the externalized 1.2.1 content baseline.

## 配置 / Configuration

游戏设置 → 弹幕尖塔设置。入口标题为「弹幕尖塔设置」、按钮为「弹幕配置与投稿」，位于游戏设置页「发送反馈」正上方，直接复用原生设置行与按钮，因此与其他条目共用完全相同的字体、悬停/失焦颜色、缩放动画、音效与控制器交互，与下方条目之间以分割线分隔。

Settings → Danmaku Settings (`弹幕尖塔设置`). Titled "弹幕尖塔设置" with the button "弹幕配置与投稿", the entry sits directly above "Send Feedback" in the in-game settings screen, reuses the native settings row and button, and is separated from the items below by a divider, sharing the same font, hover/unfocus colors, scale animation, audio and controller behavior.

设置面板、配置校验和配置保存均由弹幕尖塔自行管理，原有 12 个配置项、默认值和即时生效行为保持不变。设置窗是居中的大尺寸非全屏面板，主菜单背景仍然可见；中文界面使用游戏官方本地化字体管理器和随包 CJK 字体，避免移动端字形图集异常。旧版配置会在首次启动时自动迁移到 `user://DanmakuSpire/settings.json`，旧文件会保留以便回退。若某个游戏版本的设置页结构发生变化，还可在游戏控制台输入 `danmaku_settings open` 打开同一面板。

The mod now owns its settings UI, validation and persistence while preserving all twelve existing options, defaults and live-update behavior. Its large centered panel is modal without covering the entire screen, and localized CJK fonts prevent mobile glyph-atlas artifacts. Legacy settings are migrated automatically to `user://DanmakuSpire/settings.json` and the old file is retained for rollback. If a game update changes the settings layout, `danmaku_settings open` opens the same panel from the in-game console.

## 版本兼容 / Version Compatibility

清单不再设置最低游戏版本。补丁和设置入口会在启动时按当前游戏提供的类型、方法与界面节点逐项检测；单项不兼容时只停用受影响功能并记录日志，尽量避免整个模组阻断游戏启动。游戏未来若删除或根本性修改必要接口，仍可能需要更新模组，届时请附上游戏版本、平台和日志反馈。

The manifest no longer enforces a minimum game version. Runtime capabilities are detected independently so one incompatible hook can be disabled without taking down the whole mod. A future game build that removes or fundamentally changes required APIs may still need a mod update; please include the game version, platform and logs in reports.

## 词条来源 / Danmaku Source

模组内所有正式词条均来自可追溯的社区弹幕抓取、真人玩家投稿（经作者人工审核）或由作者明确提供；模组不自行创作弹幕文本。

All danmaku texts come from traceable community captures, real player submissions (after author review) or are explicitly provided by the author; no texts are generated by the mod itself.
