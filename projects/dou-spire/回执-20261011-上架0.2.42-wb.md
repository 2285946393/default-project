## 零、第一次上传为什么失败（已修）

**现象**（`upload-0.2.42-fail1.out`，14:28）：

```
Status: k_EItemUpdateStatusCommittingChanges

Error occurred while uploading to the workshop! Result: k_EResultInvalidParam
```

注意：内容其实是**传完了的**（`PreparingContent` 走到 `UploadingContent` 再到 `CommittingChanges`），
挂在最后一步「提交参数」。⇒ 说明问题在**元数据**，不在文件。

**定位过程（靠对比，不靠猜）**

1. 用 Steam 的公开接口把**线上 0.2.41 的 description 原样拉下来**量了一遍：
   `ISteamRemoteStorage/GetPublishedFileDetails` → **3725 字 / 7999 字节**。

3. 其它字段都没变：`title` 125 字节（上限 128）、`changeNote` 2079 字节、`tags` 12 个、`deps` 2 个、
   `image.png` 521KB —— 全部和 0.2.41 一致。

⇒ **Steam 工坊说明文的上限是 8000「字节」，不是字符。** 超了就在提交那步报 `k_EResultInvalidParam`（错误码 8）。
（网上也有同款案例：错误 8 的原因是「描述太长导致了提交参数（非法）」。）

**⚠️ 我犯的错，记一笔**

我一开始看到 4433 个**字符** < 8000，就断定 `prepare_workshop.py` 里那个按**字节**判的检查是「误报」，
**把它改成了按字符判** —— 方向完全反了。上一版说明文是 7999 字节这件事本身就是最硬的证据，我当时没看。

**修法（两处）**

1. **`workshop/description.md` 砍到 7888 字节**（3790 字，余 112 字节）。
   砍的都是**重复和修饰**，没删事实：
   - 21 点那节从 5 条压成 4 条（「入口」并进开头、「分牌提示」并入规则条）
   - 「关键词」那节按行压掉一批同义堆砌（21点/blackjack/黑杰克 这一行留着）
   - 德州 / 斗地主 / 语音系统 / 署名 / 怎么玩 各压掉一批「——」从句
   - **署名、CC BY-NC-SA、角色版权归属、FishAudio/Live2D 出处全部保留**（这些是法律要的）
2. **`tools/prepare_workshop.py` 改成硬拦**：

## 一、这次 0.2.41 → 0.2.42 改了什么

### 1. 新玩法：21 点（Blackjack）

| 项 | 内容 |
|---|---|
| 入口 | 篝火第三个选项「21 点」+ 主菜单第三个按钮「21 点尖塔」 |

### 2. 21 点 · 血量模式

设置里把赌注从「金币」切成「血量」，就是**拿命赌**：爆牌掉血、黑杰克回血。

三条保命线（写死在 `ApplyHpAsync` 里）：

1. 单次最多掉**当前血量的 1/4**（`BlackjackHpCapPercent = 25`）
2. **永远留 1 血** —— 掉血上限 = `当前血量 - 1`
3. 回血不超过血量上限

血只剩 1 点 → 篝火拒绝开桌（会弹提示）。
掉血走 `CreatureCmd.Damage(..., ValueProp.Unblockable, ...)` = **生命流失**（像中毒），不被格挡、不触发「被攻击」类反应。

> ⚠️ **血量模式只能从篝火开桌** —— 血量只在 run 里存在，主菜单那版没有 run 也就没有血（所以主菜单那版是纯筹码局）。

## 二、上架前临时加的一道闸（重要）

**21 点这版是纯本地桌**，没有像德州那样的联机分流层（`DouSpirePokerNet`）。
而篝火选项的**选择是按 uint 下标全队广播**的 —— 联机时一个人点了「21 点」，
每个客户端都会各自开一张**自己的**本地桌、各发各的牌、各结算各的金币，**直接跑岔**。

所以上架前在 `DouSpireBlackjackRestSite.cs` 的 `OnSelect()` 开头加了一句：

```csharp
if (DouSpireNet.InMultiplayerRun())
{
    Entry.Toast("21 点暂时只支持单人 —— 联机请玩斗地主或德州扑克。", "21 点");
    return Task.FromResult(false);   // 篝火留着，谁也不动
}
```

所有人都会走到这一句、都返回 false ⇒ **篝火原样留着，不会不同步**。
等哪天 21 点接上联机分流层，把这一段删掉即可。
