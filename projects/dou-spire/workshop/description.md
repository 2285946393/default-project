[h1]🀄 斗地主尖塔 · 在杀戮尖塔 2 里开一桌斗地主 / 德州扑克 / 21 点[/h1]

[b]三条命变三副牌。[/b]铁甲战士、荒疫猎人坐你对面，四个会说中日双语的二次元角色陪打——抢地主（猜拳定）、明牌、加倍、炸弹翻倍、筹码结算一个不少。
[b]牌面还能换成杀戮尖塔的卡[/b]（打击、防御、背刺、大爆炸）；另有[b]德州扑克[/b]与[b]21 点[/b]两张完整牌桌（21 点本轮新增，能拿血下注）。

[h2]♠️ 21 点 / Blackjack（本轮新增）[/h2]
[list]
[*][b]四个按钮[/b]：要牌 / 停牌 / 加倍 / 分牌，旁边实时给「[b]基本策略[/b]」提示，不会玩也能上手
[*][b]赌场标准规则[/b]：6 副牌靴、庄家软 17 停、黑杰克赔 3:2、庄家明牌 A 或 10 时偷看、加倍只发一张、分牌最多 4 手、分出的 A 锁死
[*][b]血量模式[/b]：设置里把赌注从「金币」切成「血量」= 拿命赌。爆牌掉血、黑杰克回血；单次最多掉当前血量 1/4，永远留 1 血
[*][b]⚠️ 仅单人[/b]：联机时点它会提示「暂时只支持单人」
[/list]

[h2]🂡 德州扑克[/h2]
[list]
[*][b]四轮下注[/b]：大小盲 → 两张底牌 → 翻牌 → 转牌 → 河牌 → 摊牌
[*][b]弃牌 / 过牌 / 跟注 / 加注 / 全下[/b] 齐全，按钮上直接写要掏多少钱；2~4 人，单人打电脑，也能和队友联机同桌
[*][b]新手友好[/b]：桌面正中实时告诉你「你现在是：一对 A」，并高亮凑成牌型的那 5 张；牌型 10 档
[*][b]台面 / 牌室随手换[/b]：左右两个小圆钮 —— 左换牌室（4 款）、右换台面（5 款），每个台面的公共牌凹槽单独校过，牌会正好卧进槽里
[/list]

[h2]🎮 斗地主玩法[/h2]
[list]
[*][b]完整牌型[/b]：单张 / 对子 / 三张 / 三带一 / 三带二 / 顺子 / 连对 / 飞机 / 四带二 / 炸弹 / 王炸（14 种全有）
[*][b]抢地主 · 猜拳[/b]：要抢的人一起出拳，赢的当地主 —— 用的是游戏本体的联机手势图
[*][b]明牌[/b]（底注翻倍）/ [b]加倍[/b] / [b]炸弹翻倍[/b] —— 倍数顶部实时显示
[*][b]筹码系统[/b]：开局每人 1000，地主一人对两个农民，按倍数结算
[*][b]出牌时限[/b]：默认 20 秒（设置里可调，能关）
[*][b]单人[/b]打两个电脑；[b]联机[/b]时篝火各自点「斗地主」，人齐自动开局（缺的位 AI 补），金币输赢主机统一结算进各自钱包
[/list]

[h2]🎵 背景音乐[/h2]
牌桌自带四档背景音乐：[b]主界面 / 开局 / 只剩一两张的警告 / 炸弹王炸高潮[/b]，炸弹王炸自动插播高潮曲。四档都能在设置里换成[b]你自己的歌[/b]。

[h2]🗣️ 语音系统[/h2]
[list]
[*][b]音量可调[/b]：一条滑条管所有对手角色的说话音量
[*][b]触发分级[/b]：发牌 / 抢地主 / 炸弹 / 输赢这类关键台词[b]必说[/b]；闲聊台词有限流
[*][b]多版本随机[/b]：同一件事有多条录音时随机轮播，不重样
[/list]

[h2]🃏 尖塔牌面（可选）[/h2]
设置里可把牌面切成[b]「尖塔牌面」[/b]：牌直接渲染成[b]杀戮尖塔的卡[/b]（打击、防御、背刺、大爆炸、神化……），用的是游戏自己的卡牌节点 —— 装了改卡名的 mod 会跟着变。[b]牌力完全不变[/b]：打击还是当 3、防御当 4。

[h2]👆 怎么玩[/h2]
主菜单点[b]「斗地主尖塔」[/b]（另有[b]「德州扑克尖塔」[/b][b]「21 点尖塔」[/b]两个独立入口）。进桌后：翻箭头选人 → 决定明不明牌 → 抢地主（猜拳）→ 加倍 → 开打。
爬塔途中在[b]篝火（休息处）[/b]也能点[b]「斗地主」[/b][b]「德州扑克」[/b][b]「21 点」[/b]开一桌。快捷键 [b]F9[/b] 收桌 / 开桌。牌面风格、音量、出牌时限、21 点赌注都在[b]设置 → 模组配置[/b]里。

[h2]👥 四人 2v2 组队[/h2]
选人界面点「四人桌（2v2）」：两副牌 84 张，[b]对家是队友[/b]（坐你右手边）。猜拳定先手队，后手队各扣一张底牌再开打，按队结算。信息框左上角[b]队色小条[/b]标队友。

[h2]🤖 鸡煲代打[/h2]
点「鸡煲代打」：AI 用最高难度替你打完[b]一整局[/b]——明牌/抢地主/猜拳/加倍/扣牌/出牌全包，再点一下收回自己打。
