## 二、确定的问题：主机的兜底形同虚设（已修）

`StepDiscard` 本来有个「远程真人太久不扣牌 → 主机替他扣」的兜底，
但**计时写错了位置**：

```csharp
_aiTimer -= delta;
if (_aiTimer > 0) return;          // ← 绝大多数帧在这里就 return 了
_aiTimer = DouSpireConfig.AiDelay;

var s = _game.PendingDiscards[0];
...
if (_netOn && s != MeSeat && IsHumanLocal(s))
{
    _discardWait += delta;         // ← 每 AiDelay 秒才执行一次，每次只加一帧的 delta
```

**后果**：`_discardWait` 每秒只涨 `delta / AiDelay`（≈ 0.014 秒）。
`DiscardWaitLimit` 是 30 秒 ⇒ 实际要等 **30 / 0.014 ≈ 2150 秒 ≈ 36 分钟**。
**等于没有兜底** —— 队友一不响应，主机就永远停在扣牌阶段。

**修法**（`DouSpireTable.StepDiscard`）：

- 把远程真人的等待计时**提到 `_aiTimer` 门控之前**，**每帧累加**；
- 超时后**立刻替他扣**（不再等 `_aiTimer` 节奏）；
- `DiscardWaitLimit` **30 → 15 秒**（出牌限时是 20 秒，扣一张牌不该等更久）；
- 每 5 秒往日志报一次「还在等 N 号位（名字）扣牌 —— 已等 X 秒」，
  下次再卡住，看一眼日志就知道**卡在谁身上**。

## 三、更可能的根因：客机认不出自己的座位（已修，待队友日志确认）

### 3.1 链路

客机收到主机的开桌广播后，要自己算「我坐几号位」：

```csharp
// HandleOpen
var mine = -1;
var myId = LocalNetId();                       // ← 旧代码
for (var s = 0; s < Seats; s++)
    if (SeatHuman[s] && SeatNet[s] == myId) { mine = s; break; }
if (mine < 0) { Warn("开桌消息里没有我"); mine = 0; }   // ← 认不出就按 0 处理
```

**而主机填座位表用的是**：`SeatNet[s] = p.NetId`（`p` 来自 `RunPlayers()`）——
**联机层**的 id（SteamID）。

**客机却用 `LocalNetId()`**，它的**第一优先是 `LocalContext.NetId`** —— 那是**另一套口径**，
未必等于联机的 SteamID。

### 3.2 为什么这会导致「出不来牌」

一旦 `LocalContext.NetId` 给出一个「非 0 但不是 SteamID」的值，客机就**一个座位都匹配不上**：

```
客机 myId ≠ SeatNet[任意]  →  mine = 0（错！应该是 1）
  →  MySeat = 0
  →  BuildView 里 ViewFrom(MySeat=0) —— 座位 0 的人**不旋转**（GameState.cs:211）
  →  客机的 PendingDiscards 还是**全球口径** {1,3}（该是 {0,2}）
  →  BeginDiscard 里 ShowDiscardBtn(Contains(MeSeat=0)) = **false**
  →  **扣牌按钮根本不亮，队友想扣也扣不了**
  →  主机永远等不到 1 号位扣牌 → 整桌卡死
```

**主机不受影响**（`MySeat` 恒 0，见 `HostOpenTable` 的 `MySeat = 0;`），
所以现象正好是「**主机正常、客机动不了**」—— 和用户描述完全一致。

### 3.3 旁证

- 同一个文件里 `IsMyPlayer` 早就踩过这个坑，注释写着：
  > 「`LocalContext.IsMe()` **一会儿 true 一会儿 false** …… 这里改成**先按 NetId 比**（稳定）」
  —— 说明 `LocalContext` 在联机下本来就不可靠。
- `LogPeerState` 的客机分支注释也写明：
  > 「⚠️ 客机这里 `NetService.NetId` 是**我自己**的 id」
  —— 联机层的 id 才是对的。

### 3.4 修法（`DouSpireNet`）

1. **新增 `MyNetIdForSeat()`**，按「**联机层优先**」取 id：
   `NetService.NetId` → 我自己的 `Player.NetId` → `LocalNetId()` 兜底。
2. `HandleOpen` 改用它，并把失败日志写全（带 `LocalNetId`、整张座位表）。
3. **再加一层便宜的兜底**：万一还是认不出，就用「**排除主机**」推断 ——
   座位表里去掉 `HostNetId`，剩下的真人席如果**只有一个**，那必定是我
   （2 真人 + 2 电脑正是这种局面）。3 个真人以上不猜，宁可按 0 也不乱认。
