## 二、今天干了什么（按模块）

### 1. 特效可见化（根因修复）
- **真凶**：`VfxCmd.PlayNonCombatVfx` 把特效节点挂到牌桌场景**外面**，而牌桌根节点 `ZIndex=200` 整层盖住 → 日志"特效已播"但看不见。
- **修复**：重写 `DouSpireTable.SpawnGameVfx()`——自己 `PreloadManager.Cache.GetScene("res://scenes/"+innerPath+".tscn")`（兜底 `Godot.ResourceLoader.Load`，⚠️ 必须**全限定**，MegaCreat 命名空间会遮蔽）→ `Instantiate<Node2D>` → 挂 `_scene`，`Position=at`（_scene scale=1 本地=视口像素），**相对 ZIndex=40**（有效 240 压过所有牌），6s 兜底清理。
- 新增 `SeatVfx(seat, path, scale)`：座位**立绘胸口**（ArtY-0.08）当落点。
- 挂点：炸弹→胸口 `vfx_common_hit_flare`(1.7)+`outward_streaks`(1.4)；王炸→胸口+中央各一道 `vfx_attack_lightning`；定地主/先手→胸口 `vfx_common_ray`(1.4)；cast 蓄力 4 处（明牌/抢地主/加倍/报单）→胸口 `vfx_common_clean_flare_1`(1.2)。
- 本体特效安全清单见 `notes/杀戮尖塔2-本体特效资源清单.md`（312 个 .tscn；**bounce_spark / heavy_blunt 会抢坐标，弃用**；slime/sandy/starry 挂共用粒子脚本安全）。

### 2. 三个终局 bug（玩家反馈）
- **超时托管死循环**：超时代码直接 `OnPassPressed()`，但**领出时要不起是非法动作** → 永远失败；且 `_myTurnSince=0` 导致下一帧 waited=天文数字 → **每帧重触发**，报错弹窗刷屏，人一张没出、AI 把牌打完。修：领出时照 `StepAi` 兜底**甩最小一张**（客机走 `DouSpireNet.SendPlay`）；超时后 `_myTurnSince = now`（不清 0）。
- **终局按钮不出现**：补亮按钮靠 `PayOut` **之后**才创建的 2.5s 定时器，PayOut 一抛异常定时器永不创建 → "必须点鸡煲代打才显示再来一把"。修：改成 `_Process` **每帧时间驱动**（`Winner!=null && !_nextBtn.Visible && now-_roundOverAt>=2.5 → RefreshButtons()`）。
- **打完的局重开卡死**：收桌存档不区分终局 → 恢复出一张死桌子。修：`_ExitTree` 存档条件加 `Winner is null`；`RestoreOrPick` 恢复前防御检查（旧终局存档直接扔）→ 打完退出再进 = **直接弹选人**。

### 3. AI 明牌看手牌
- 原来：单人 AI 无脑全明（每家 ×2，起手 ×4）、联机 `HostDecideAiShow` 全明、鸡煲代打盲目跟明。
- 新增 `AiWantsShow(seat)`：`GameState.LandlordScore(手牌)`（炸弹+6、王炸+8、2/A/王加分）**≥5 → 明**；否则 **12% 概率诈明**。地主手要**扣掉底牌**再算。三条路统一走它。

- 调参点：`AiWantsShow` 里的 5 分门槛和 12% 骰子。
