## 一、斗地主：标题水印换渲染版 + 上移

### 现象
桌面正中的 "Slay the Spire II" 是**纯白描边**的，压在「场上最后一手」那一行上，
一出牌就和牌面糊在一起。

### 根因（两件事）
1. **素材是白描版**：`assets/table/watermark.png` 是 960×484、平均色 `(255,255,255)` 的
   纯白 + alpha 图 —— 实测**逐字节等于**游戏本体的 `res://images/ui/sts2_logo_static.png`
   （都是 27151 字节）。彩色渲染版在别处。
2. **坐标和出牌区共用**：水印用的是 `TrickAx/TrickAy = (0.502, 0.518)`，
   而 `_trickRow`（场上最后一手）也是这一组 —— 两个东西必然叠在一起。

### 修法
| 改哪 | 从 | 到 |
|---|---|---|
| `DouSpireAssets.Watermark` 候选链 | 只有 `table/watermark.png` | **首选** `res://animations/backgrounds/mainmenu/logo/main_menu_logo.png`，旧图留作兜底 |
| 水印坐标 | 复用 `TrickAx/TrickAy (0.502, 0.518)` | 新常量 `MarkAx/MarkAy = (0.50, **0.335**)` |
| 水印尺寸 | 520×262（比例 1.98） | 600×266（**按素材真实比例 1192/528 = 2.26**） |
| `Modulate` | `(1, 0.95, 0.80, 0.92)` 淡金染色 | `(1, 1, 1, 0.88)` —— **彩色版不能再染色**，否则金/青两色一起被洗黄 |

`0.335` 的取法：夹在**底牌（0.269）**和**最后一手（0.518）**中间的空档里；
横向只占 0.5±0.156，碰不到两侧 x≈0.1 / 0.9 的底牌位。

### ⚠️ 为什么用 `res://` 而不是把图拷进 assets/
`参考图/README.md` 明确写着：**「这里的图版权归 Mega Crit，不要拷进 `assets/` 打进 mod 发布。
代码里用 `res://` 引用才是安全的。」** 那张白描版就是当年被拷进来的，属于历史遗留。

### 已核实：这个 `res://` 路径真的能加载
pck 里搜 `main_menu_logo` 只看到 `.import` + `.ctex`（**所有贴图都长这样**，不是异常），
抽出 `.import` 确认 remap 指向 `CompressedTexture2D`：

```
[remap]
importer="texture"
type="CompressedTexture2D"
uid="uid://yfjv1uq5f0vb"
path.s3tc="res://.godot/imported/main_menu_logo.png-2445f60b90a865a17ff4d6c2a25be4ce.s3tc.ctex"
```

和 mod 里**已在用的** `res://images/packed/combat_ui/end_turn_button.png` 是同一种形态
⇒ `ResourceLoader.Exists` 会命中。取不到时 `DouSpireAssets.LoadGame` 返回 null，
候选链自动回落到旧白描版 —— **不会白块，也不会崩**。

## 二、德州：底池不好看

### 现象
底池那块牌匾糊成一坨深红色小方块，旁边一根细筹码。

### 根因（真凶在 `PlateBox`）
`PlateBox` 的九宫格保护边距是按**图片宽度**的 1/5 取的，**不是按实际绘制宽度**：

| | 值 |
|---|---|
| `pot_plate.png` | 971×256 |
| 保护边距 | 971/5 = **194**，左右各 194 ⇒ **388** |
| 实际绘制宽 | **150 ~ 176 px** |

**保护边距(388) 比控件本身(176) 还宽** ⇒ 整张牌匾被硬塞进一个小方块。
另外 150×56（比例 2.68）对 971×256（比例 3.79）来说也是**竖着拉长的**，看着发胖。

### 修法
1. `PlateBox(string[] chain, float targetW = 0f)` —— 传了 `targetW` 就按 `targetW/5` 取边距，
   并夹在 `[2, 图宽/2]` 之间；高度按图片宽高比折算。底池传 `targetW = 240f`。
2. 牌匾尺寸按素材真实比例重定：经典绿绒 **150×56 → 210×55**；其余四档 **176×64 → 240×63**。
3. 筹码堆 **44×80 → 56×104**，与牌匾间距 36 → 40 px。
4. 数字字号 22 → 24。

## 三、德州：各角色面前放筹码（新增）

用户："筹码应该是各个角色面前都放两三个。"

- 新字段 `Control?[] _hudChips`，在 `BuildSeats` 里每席建一个 `VBoxContainer`，
  用**负间距**（`Gap(-20)`）把 **3 枚** `poker/chip_single.png`（38×38）叠成一摞。
- 位置 = **从该席立绘朝桌心方向走 38%**：
  `chipX = ArtX + (0.5 - ArtX) * 0.38`，`chipY` 同理 —— 落在"面前"而不是"脚下"。
- 显隐在 `RefreshSeats`：`chipPile.Visible = p.CommittedStreet > 0`
  （= 信息框里「这一轮已下 N」那行字的实物版）。

## 四、德州：摆位对齐斗地主

用户："摆位也奇怪。布局其实按斗地主的就行了。"

- `DouSpireLayout.PokerDefaults()` 改成 **`=> Defaults(playerCount)`** —— 直接沿用斗地主那套。
- 旧版是「左右贴桌子中腰(y 0.47) + 对家坐顶上正中(0.500, 0.225)」，
  四人局时**顶上那一席正好压在底池和 5 张公共牌的中轴线上**，桌心被挤没地方。
- 斗地主那套是**四个角**（我 左下 / 右 右上 / 左 左上 / 对家 右下），
  整条中轴 x 0.35~0.65 是空的 —— 正好把桌心完整让给底池和公共牌。
- `WritePokerDefault()` 生成的注释文本同步重写。

### ⚠️ 已存在的 `layout-poker.txt` 会覆盖代码默认值
`mods\DouSpireDev\assets\layout-poker.txt` 里的旧数字**优先级高于**代码里的 `PokerDefaults`。
已直接改写为新的四行，**原文件备份在**
`mods\DouSpireDev\assets\layout-poker.txt.bak-20261010-2203`。

0 = 0.115 0.855 240 300   0.115 0.645
1 = 0.885 0.450 240 300   0.885 0.140
