## 一、根因：德州桌**一处语音都没调**

`DouSpirePokerTable.cs` 里对 `DouSpireVoice` 的引用只有一行 —— 收桌时清缓存：

```csharp
DouSpireVoice.ClearCache();   // 424 行，仅此一处
```

角色系统（`_chars` / `_actors`）**是齐的**，走位动作（`ReactActor`）也有，
就是没人让它开口。所以德州全程只有 SFX（发牌 / 点牌 / 输赢音效），没有一句人声。

---

## 二、改法：抽一条**桌子无关的公共分发**，德州直接复用

### 为什么不是"再抄一份 switch"

斗地主那边这段"按角色选语音包"的 switch 原本只写在 `DouSpireTable.WhaleReact` 里：

```csharp
switch (c.GuestId) {
    case "whale": DouSpireVoice.ReactTo(...); break;
    case "yuki":  ...  case "sherry": ...  case "chun": ...
    default: if (IsRegent(c)) ReactRegent(...); else ReactBase(...);
}
```

德州若抄一份，以后**加一个语音包就得改两处**，早晚漂掉。所以抽到
`DouSpireVoice.ReactAs(SeatPick c, Mood mood, int seat)`（连带 `IsRegent` 一起搬过去），
斗地主和德州**共用同一条**。

| 文件 | 改了什么 |
|---|---|
| `DouSpireVoice.cs` | **新增** `ReactAs(...)` + `IsRegent(...)`（从 DouSpireTable 搬来） |
| `DouSpireTable.cs` | `WhaleReact` 里那段 switch → 一行 `DouSpireVoice.ReactAs(c, mood, seat)`；删掉本地 `IsRegent` |
| `DouSpirePokerTable.cs` | **新增** `MoodFor` / `Speak` / `ReactActor` 里先播语音；接 4 个时机 |

### 事件 → 槽位映射（德州**借**斗地主编好号的素材，不另造一套）

| 德州事件 | 借的槽位 | 为什么 |
|---|---|---|
| 发牌（`StartHand`） | `1_deal` | 直接对应 |
| 轮到我（`_Process` 换人时） | `3_myturn` | 与已有 `DouSpireSfx.MyTurn()` 同一时机 |
| 弃牌 `Fold` | `10_pass` | ≈"要不起，我不跟了" |
| 过牌 `Check` | `5_small` | 最小动作 |
| 跟注 `Call` | `5_small` | 小动作 |
| 下注 `Bet` | `11_beat` | 主动压一手 |
| 加注 `Raise` | `11_beat` | 压得更狠 |
| 全下 `AllIn` | `9_bomb` | 大招（"全体起立"） |
| 赢 `Win` | `13_win` | 直接对应 |
| 输 `Lose` | `14_lose` | 直接对应 |

> **好处**：六个语音包（编外四套 + 本体四角色 + 储君）**一行都不用改**。
> 以后想给德州加"专属台词"，那是**素材**的事 —— 往 `assets/voice/<角色>/` 丢新 ogg 即可，
> 代码不用动（`DouSpireVoice.Pick` 会按前缀自动扫、随机轮播）。

### 触发点（4 处）

1. **`StartHand`**（发牌）→ `Speak(MeView, Mood.Deal)`
   —— **只让我这一席开口**。三家同时说会糊成一团（斗地主 `Mood.Deal` 也只给 MeSeat）。
2. **`_Process` 轮到我**（和 `DouSpireSfx.MyTurn()` 同一时机）→ `Speak(MeView, Mood.MyTurn)`
3. **`ReactActor`** —— 一步动作的声音放这里，**4 个调用点（AiStep / MyMove / NetMove / OnHandOver）自动全覆盖**：
   - 语音**放在"有没有活角色"的判断之前** —— 编外角色 / 关掉活角色的桌没有骨骼模型，
     但照样该开口（斗地主 `WhaleReact` 踩过同一个坑，注释里有）。
4. **`OnHandOver`**（输赢）→ **每一席都开口**：赢家走 `ReactActor(..., win:true)`（动作 + 赢语音），
   其余席单独 `Speak(s, Mood.Lose)`。
   —— 为什么要分开：输家的"输"若也走 `ReactActor`，它会跟着播 `PlayWin` 的**动作**，那就错了。

## 三、安全性（都不新增失败面）

- `DouSpireVoice.Say` 内部每一步异常都吞掉 + 封顶 3 条日志；`Speak` 外面再兜一层。
- 认不出角色 / 空座 / 玩家没装语音包 → 只是**安静**，不报错不崩。
- `DouSpireConfig.VoiceEnabled` 关掉时整条静默（`Say` 第一行就 return）。
- 每席一个 `AudioStreamPlayer`（`DouSpireVoice.Players[4]`）→ 三家同时开口不互相掐。
  自己那席满音量，对手按 `OpponentVoiceScale` 压低。
- 视角位 / 全局位**没混**：`_chars[s]` / `_actors[s]` / `Speak(seat)` 全走**视角位**，
  `_game.Players[g]` 走全局位（`G(s)` / `V(g)` 换算）。输赢那圈用 `G(s)` 比 `Winners`。
