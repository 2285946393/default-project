## 二、四个 bug（都在日志/代码里坐实了）

### Bug 1（P0，崩溃）`NetSeatAi` 在选人阶段读 `_game` → 空引用

`DouSpireTable.cs`：

```csharp
internal void NetSeatAi(int localSeat)
{
    if (!_netOn) return;
    Entry.Logger.Info($"斗地主：{localSeat} 号位现在由电脑接管。");
    if (localSeat != MeSeat)
        Entry.Toast($"{_game.Players[localSeat].Name} 离桌了，电脑替他打。", "斗地主");   // ← 炸在这
```

**根因**：选人阶段 `_game` **还是 null** —— 牌要等大家都点「开始打牌」才发
（`ReturnToPickerForNet` 只建选人界面，不建牌局）。队友在选人界面离桌就当场 NRE。

**后果比崩溃本身更糟**：异常被 `HandleIn` 的 `catch` 吞掉，
**那一席的后续处理整条断掉**，主机停在"还差 1 个真人"上 —— 看起来就是"卡死"。

**修**：分两段。`_game is null` 时只管选人界面（清掉他那张准备票 + 刷界面）然后 return；
牌局建好了才走原来那套。顺带加了 `localSeat` 越界保护。

### Bug 2（P0，永久卡住）真人全齐了，但没人去开局

`DouSpireTable.TickPickWait`：

```csharp
var need = PickUnreadyHumans();
if (need == 0) { _pickWait = 0; UpdatePickCountdown(); return; }   // ← 就只是"清零再走"
```

队友离桌 → 他那一席变电脑 → `need` 从 1 掉到 0 → **进这个分支只把计时器清零，
没有任何人去调 `NetHostStartNewRound()`** ⇒ 主机永久停在选人界面。
（日志里从 5121 到 5823 一直"还差 1 个真人"，之后 800 行里**再没有** `超时…主机直接开局`。）

**修**：`need == 0` 且我自己已经点过「开始打牌」→ 直接开局。

不会误开，因为：进选人界面时 `_pickReady` 全是 false，只要我是真人就 `need ≥ 1`；
开局后 `BeginShowCards` 会把 `_picking` 置 false，本函数不再被调。

### Bug 3（回不来）离桌的人**永远**回不来

`DouSpireNet.HostOnOpenReq`：

```csharp
if (Active) return;      // 已经开着了   ← 离桌队友重进再点「斗地主」，请求被静默丢掉
```

日志 5868 行 `收到一个不认识的人（netId …）的消息，忽略。` 就是这条的下游：
座位已经变 AI，`SeatOfNet` 找不到他，他所有消息全被拒。

**修**：新增 `HostAdmitLatecomer(netId, theirRoom)`，`Active` 时不再直接 return，分三种：

| 情况 | 处理 |
|---|---|
| 他本来就在桌上（重发请求） | `CastOpen()` 重发座位表，让他的客户端清掉"等主机开桌" |
| 不在桌上，**且还在选人界面** | 找一席电脑坐下 → `Gen++` → `CastOpen()` → 全桌回选人界面重新点「开始打牌」 |
| 不在桌上，**但牌已经发了** | 不硬塞（半路换座位会把这一局搅烂），记日志让他等这一局 |

配套：`DouSpireTable` 新增 `internal bool IsPicking => _picking;`；
`NetPickOpen` 加了个可选日志参数（补位和"重新选人"都走它，但原因不同）。

### Bug 4（各端不同步）客机的座位表没跟着更新

`HandleAct` 的 `ActSeatAi` 分支原来只调 `t.NetSeatAi(...)`，
**没有更新客机自己的 `SeatHuman[]`** ⇒ 客机的选人界面把已经走掉的人还当真人显示
（名字还在、`PickUnreadyHumans()` 也一直把他算进"还差几个真人"，倒计时永远不消失）。

**修**：抽出 `NoteSeatBecameAi(globalSeat)`，主机（`HostGotLeave`）和客机（`HandleAct`）共用。

### 顺手（体验）把"在等谁"点出来

`UpdatePickCountdown` 原来只写「还差 1 个人没点「开始打牌」· X 秒后自动开始」——
屏幕上另外两行都写着「电脑」的时候，这行看着像在等一个不存在的人。
现在把名字带上：**「还差 1 个人没点「开始打牌」（鲸鱼娘）· 12 秒后自动开始」**。

## 五、待实测核对（要重启游戏，两台机器）

1. **选人界面队友离桌** → 主机**立刻开局**（电脑补位），不再卡住；日志**不再有** `NullReferenceException`。
2. **队友离桌后重进、再点「斗地主」** → 应看到 `斗地主：<netId> 补进来了，坐 N 号位（第 X 代）`
   + 全桌弹回选人界面 + 双方都能再点「开始打牌」开局。
3. **牌局进行中有人重进** → 应看到 `想补进来，但这一局已经在打了`，**不会**把牌局搅烂。
4. **正常两人对局** → 不受影响（两个人都在时走的还是"都点了才发牌"那条路）。
5. **倒计时那行字** → 应该能看到队友的名字，不再只是"还差 1 个人"。
