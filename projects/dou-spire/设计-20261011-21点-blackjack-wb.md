# 设计：21 点（Blackjack）—— DouSpire 第三种玩法

> 用户 2026-10-11：「**想做个新模式。black杰克21点**」
>
> 已拍板的三个方向：
> 1. **两条赌注都要**（金币 + 血量，设置里切）
> 2. **庄家 = 电脑荷官**（用户：「其实我自己都找不到一起玩的人」→ 单机是主场景，联机优先级低）
> 3. **四种动作**：要牌 / 停牌 / 加倍 / 分牌（**不做**保险、投降）

---

## 一、规则（已实现 + 已验证）

内核在 `dou-spire-rules/Blackjack/BlackjackGame.cs`，**纯逻辑、不碰 Godot**，
自检 `BlackjackSelfTest.cs`，跑法 `dotnet run -- --bj` → **57 条全过**。

| 项 | 取值 | 说明 |
| --- | --- | --- |
| 牌靴 | **6 副 312 张**，剩 25% 重洗 | 赌场标准，算不了牌也不用一直洗 |
| 庄家 | **软 17 停牌（S17）** | 对玩家最有利的那一版，也最好解释 |
| 黑杰克 | **赔 3:2** | 起手两张凑 21；**分出来的 21 只赔 1:1** |
| 平分 | 退注 | |
| 偷看 | 庄家明牌是 **A 或 10** 时查底牌 | 是黑杰克就**当场结算**，玩家不用白动作一轮 |
| 加倍 | 只许前两张，注翻倍，**只再发一张**就强制停 | |
| 分牌 | 两张**点数相同**即可（K/Q 能互分），最多 **4 手** | 分出来的 A **只补一张就锁死**（赌场规矩） |
| 爆牌 | 直接输（哪怕庄家后来也爆） | |

**最硬的一条验证**：电脑按基本策略自战 **2 万局** → 返还率 **RTP = 99.91%**
（理论 99.4%~99.7%，差 0.3% 在 1 个标准误内）。
这个数比任何单条断言都管用 —— 只要算点 / 加倍 / 分牌 / 结算里**任何一处写错**，它就会明显跑偏
（比如黑杰克赔成 1:1 会掉到 97% 以下）。

## 二、赌注：两套，设置里切

### A. 金币模式（默认）

和斗地主、德州**完全一致**的路子：

- 篝火点「21 点」开桌，押金币；
- 下注档位照抄斗地主（`BaseStake` 100，`BetUnitDivisor` 20 → 按身家自动给档）；
- 赢了拿回注码 + 等额（黑杰克 1.5 倍），平局退注，输了赔掉。

### B. 血量模式（尖塔味的核心）

**把赌注换成血** —— 这是 21 点比德州更适合尖塔化的地方：一局就 20 秒，爆牌立刻见血，节奏刚好。

| 结果 | 金币模式 | 血量模式 |
| --- | --- | --- |
| 黑杰克 | +1.5×注 | **回血** 1.5×注（不超上限） |
| 赢 | +1×注 | **回血** 1×注 |
| 平 | 0 | 不掉不回 |
| 输 / 爆牌 | −1×注 | **掉血** 1×注 |

**三条保命线（必须做，不然能把自己玩死）**：

1. **单次掉血不超过当前血量的 25%** —— 再大的注也只掉这么多；
2. **掉血不会掉到 1 以下** —— 最低留 1 血（斗地主也有同款底线，用户 2026-10-08 定的「不能让我白手起家」精神一致）；
3. **回血不超过最大血量**。

> ⚠️ 血量改动必须走 `CreatureCmd`（`Damage` / `Heal`），**不能直改 `CurrentHp`** ——
> 直改会绕过护盾、遗物、各种「受到伤害时」钩子，别的 mod 也感知不到。

### 设置项

```
DouSpireConfig.BlackjackStakeMode   : 金币 / 血量      （默认金币）
DouSpireConfig.BlackjackBaseStake   : 基础注 100
DouSpireConfig.BlackjackHpCapPercent: 单次最多掉当前血量的 25%
```

- **我坐正中**（座位 0），另外两家分列左右 —— 21 点是"玩家一字排开对着荷官"，

### 实现细节（2026-10-11 13:5x 落地）

- 血量结算走 **`CreatureCmd`**，不直改 `CurrentHp` —— 直改会绕过护盾、遗物、各种
  「受到伤害时」钩子，别的 mod 也感知不到。
- 掉血用 **`ValueProp.Unblockable`**（= 生命流失，像中毒）—— 不该被护盾挡掉，
  也不该触发"被攻击"那一类反应。`ValueProp` 在 `MegaCrit.Sts2.Core.ValueProps`（注意复数）。
- ★ `CreatureCmd.Damage` 的 **5 参版 dealer 是非空 `Creature`**，要传 null 得用 **7 参版**
  （`Damage(ctx, target, amount, props, dealer, cardSource, cardPlay)`）—— 用错会有 CS8625 警告。
- 异步命令用 fire-and-forget（`_ = ApplyHpAsync(net)`），内部 try/catch ——
  不阻塞 UI，也不让异常炸到牌桌。
- **血量模式只能从篝火开桌**：血量只在 run 里存在，主菜单那版没有 run 也就没有血
  （所以主菜单是筹码局，篝火才是金币/血量局）。
