- `NCard.DisplayingPile` 换成别的值（`Play` / `Deck`）—— 现在给的是 `Hand`，
  游戏可能因为"在手牌里但没能量"才判成打不出。
- 或者 `SetForceUnpoweredPreview(false)`（成员表里有这个方法，看名字是"强制按缺能量预览"）。

### 问题 2：手牌位置偏高，被操作按钮压住

**现象**：手牌那一排的**顶边压在「出牌/要不起/提示」或「加倍/不加倍」下面**，
牌的上面一截被按钮盖住。

**已经做的**：把 `HandAy` 从 0.900 一路挪到 0.945、`ActionAy` 从 0.795 挪到 0.770。
**结果**：不够，还差一截。

**根因判断（待验证）**：这张卡的画面是**从原点往上画的**（原点在下边）。
日志实测卡的原始尺寸 `300×422`、缩放 `k≈0.387`、可见高度 `163px`；
而从截图反推，卡的顶边正好比格子顶**高出一个卡高（约 160px）**——数字对得上。

**最新一版已经按这个改了**（还没部署）：

```csharp
self.Position = new Vector2(0f, natural.Y * k);   // 按可见高度往下推一格，落进格子里
```

**注意**：自动纠偏那条路**走不通** —— 用 `GetGlobalRect()` 量到的是 `(0,0)`，
这个时机拿不到有效坐标（日志里 `纠偏后卡顶 y=0，格子顶 y=0`）。别再往那个方向试。

## 五、踩过的坑（这一节最值钱）

### 5.1 绝对不能按"显示名"找游戏里的东西

**第一次做的是**：按**中文卡名**去 `ModelDb.AllCards` 里找卡模型。
一开**梗化尖塔**就全乱 —— 那张 json 把卡名全换掉了，于是有的卡找不到、
有的匹配到别的卡（症状：卡面显示 `Broken Card` / `If you can read this, there is a bug.`，
或者显示成完全不相关的卡）。

**正确做法**：**按游戏内部类名**找（`Models.Cards.StrikeIronclad`），
比较前先归一化（去下划线、转小写），并且**撞名时优先用游戏本体程序集里那张**
（`card.GetType().Assembly == typeof(ModelDb).Assembly`），因为 mod 也可能加同名的类。

> 顺带：梗化尖塔就是用户自己做的（`MemeSpire.json` 里 `author: 有花无实`），
> 它是**纯文案覆盖**（`has_dll: false`，只覆盖 `localization/zhs/*.json`）。

### 5.2 设置项的值是**存盘**的，改默认值没用

`SpireCardScale` 默认从 `0.22` 改成 `1.0`，日志里还是 `0.22` —— 玩家盘里存的那份说了算。
**改默认值不会覆盖已存的值**。要重置只能**改设置项的名字**（旧键自然作废）。

### 5.3 `SetAnchorsPreset` 只改锚点，**不改偏移**

用它"铺满父级"是错的：偏移还是老的，节点位置就漂了。
要么用 **`SetAnchorsAndOffsetsPreset`**，要么显式设 `Position` + `Size`。

### 5.4 初始化必须等节点**进了场景树**之后

在树外调 `OnInstantiated()` / `UpdateVisuals()`：**卡图能出来，但文字控件是空的** →
游戏画成坏卡占位。必须 `AddChild` 之后、`_Ready` 跑过之后再初始化（用 `Callable.From(...).CallDeferred()` 推迟一帧）。

### 5.5 光设 `NCard.Model` 不够

还得调 **`OnInstantiated()`**（场景实例化后的初始化入口）和设 **`DisplayingPile`**。

### 5.6 那张卡是**固定像素**排的，必须整体缩放

`NCard` 的 `Size` 进来时是 **`0x0`**，内容是照它自己的 **`300×422`** 排的。
只给格子尺寸它不会缩，会撑满屏幕。
做法：`GetCurrentSize()` 量原始宽度 → `Scale = 目标宽 / 原始宽`，`PivotOffset` 设 0。

### 5.7 别拿 Spine 的**散图集**当图片用

`animations/backgrounds/treasure_room/chest_room_act_1.png` 是宝物房那种**骨骼动画的散图集**
（手、石块、箱子零件全打在一张图上），直接铺出来是满屏碎片。
要用就找**单张整图**（`.godot/imported/` 里的是编译后的，源 png 未必在 pck 里）。

## 六、关键 API 速查（都是从运行日志里现查出来的）

### `MegaCrit.Sts2.Core.Nodes.Cards.NCard`（是个 `Control`）

```
属性  CardModel Model | PileType DisplayingPile | Control Body | NCardHighlight CardHighlight
      Node OverlayContainer | Node CardVfxContainer | ModelVisibility Visibility | Tween PlayPileTween

方法  OnInstantiated() | GetCurrentSize() | UpdateVisuals(PileType, CardPreviewMode)
      SetPretendCardCanBePlayed(bool) | SetForceUnpoweredPreview(bool) | ShowUpgradePreview()
      SetPreviewTarget(Creature) | add_ModelChanged(Action<CardModel>) | AnimMultiCardPlay() ...
```

- `PileType` 取值：`None / Draw / Hand / Discard / Exhaust / Play / Deck`
- `CardPreviewMode` 取值：`None / Normal / Upgrade / MultiCreatureTargeting`
- 场景路径：`res://scenes/cards/card.tscn`

### `MegaCrit.Sts2.Core.Models.CardModel`

- `ModelDb.AllCards` → 全部卡（含 mod 的）
- `card.Title`（**string**，不是 LocString）、`card.Type`、`card.EnergyCost`（不是 int）

### 卡面素材（自己拼卡面时的备用，现在用不上）

- 卡框：`res://images/atlases/ui_atlas.sprites/card/card_frame_{attack|skill|power|quest|ancient}_s.tres`
- 画框：`card_portrait_border_{attack|skill|power}_s.tres`
- 卡图：`card_atlas.sprites/<职业>/<卡>.tres`
- 联机手势：`res://images/ui/hands/multiplayer_hand_<角色>_<手势>.png`（手势：rock/scissors/paper/point）
