# 斗地主尖塔 · 素材清单

> 这张表回答一个问题：**要做出参考图那种整屏牌桌，需要哪些 UI 素材？**
>
> 规则很简单：**能借游戏本体的就借**，借不到的才要画。
> 下面每个槽位都写清楚了「放哪个文件」「替换的是什么」「不画的时候现在长什么样」。

> 📁 **参考图在通用素材库：`projects/sts2-asset-library/`**
> —— 1846 张，从游戏 pck 里导出的真实素材，按游戏原 `res://` 路径存放。
> 打开它的 `index.html` 可以搜索、按目录筛选；`manifest.json` 可以反查路径和尺寸。
> **每个槽位具体该看哪张 → 见同目录的 `参考图对照.md`。**
> 两句话用法：**画之前先对着参考图定描边粗细和饱和度；不确定的槽位就先看它在借哪张游戏图，照着那张找手感。**

> 📝 **要自己画的 8 项，提示词见 `生成提示词.md`**（按 GPT 图片 / ChatGPT 4o 的写法写的，可直接粘贴）。

## 一、怎么用（改图不用重编 dll）

1. 把图画好，**按表里的文件名**丢进本目录（`assets/`）。
2. 编译一次 mod（`bash ../dou-spire-rules/tools/build-mod.sh .`）——
   `assets/` 会被自动拷到 `mods\DouSpire\assets\`。
   （也可以直接往 `mods\DouSpire\assets\` 里丢，免编译。）
3. 游戏里 **F9 收桌再开桌**，图就换了。**不用重启游戏。**

加载顺序是「**自己的图 → 游戏自带的图 → 纯色兜底**」。
所以我们画一张就覆盖一张，没画的那张自动用游戏本体的，界面永远不会开天窗。
开桌时日志里会打一条清单，写明每个槽位最终用了哪张图：

```
斗地主素材：用自己的 3 个，用游戏自带 25 个，没有素材 8 个。assets 目录：...
  自己的：背景=bg/hall.png、圆桌=table/table_round.png、...
  借游戏的：牌背=res://images/packed/run_history/card_back.png、...
  走纯色兜底的：星盘、空位框、选中框、红桃、...
```

## 四、座位立绘的命名（3 家都要）

> ## ⛔ 这一节已于 2026-10-11 作废 —— 图已全部删除
>
> 用户原话：「**为什么预览是这些静态图。把这些静态图给我删了。我用的是本家和那四个二次元人物。**」
>
> **删掉的 13 张**：`seats/char_*.png` ×9（ironclad / silent / defect / necrobinder / regent /
> whale / chun / yuki / sherry）+ `seats/icon_*.png` ×4（whale / chun / yuki / sherry）。
>
> **为什么可以删** —— 池子里这 9 位每一位都有比静态图更好的东西：
>
> | 谁 | 现在用什么 | 说明 |
> |---|---|---|
> | 本体 5 位（铁甲战士 / 沉默猎手 / 故障机器人 / 亡灵缚师 / 帝王） | **游戏自己的活模型** | 会待机、会受击、会亮牌。原来那 5 张是早先 AI 仿的，跟游戏里真正的角色不像 |
> | 四位客人（DS鲸鱼娘 / 椿 / 八千代辉夜姬 / 雪莉） | **待机动画** `<id>/idle/fNN.png`（96 帧 @12fps） | 和斗地主用的一模一样 |
>
> **顺带查出来的两个坑**：
> 1. `seats/char_<客人>.png` 和 `assets/<客人>/base.png` **是同一张图**（md5 完全相同）——
>    等于每张图存了两份，`base.png` 已经够用。
> 2. `seats/icon_chun/sherry/yuki.png` 又和 `char_*` 是同一张（md5 相同），
>    只有 `icon_whale.png`（268×268）是真头像。所以那 4 张"小像"本来就没起到小像的作用。
> 3. **德州和 21 点原来根本不播待机动画**（只有斗地主播）—— 同样四位客人在斗地主里会动、
>    到德州/21 点就变成一张死图。**这才是用户看到"静态图"的直接原因**，代码已一并修好。
>
> 想恢复：全在 `_work/seats-static-回收-20261011/`。代码侧的候选链（`DouSpireAssets.SeatOf`）
> 还留着，外部素材包自己补图仍然生效。

文件名是 `seats/char_<entry>.png`，`<entry>` 用**游戏角色的内部 id**。
现在游戏里能选的 5 位：

| entry | 角色 |
|-------|------|
| `ironclad` | 铁甲战士 |
| `silent` | 静默猎手 |
| `defect` | 故障机器人 |
| `necrobinder` | 缚灵师 |
| `regent` | 执政官 |

所以最少要画这 5 张：

```
assets/seats/char_ironclad.png
assets/seats/char_silent.png
assets/seats/char_defect.png
assets/seats/char_necrobinder.png
assets/seats/char_regent.png
```

**画法建议**：坐在桌边的半身像，背景透明，脚下对齐画面底部。
没画的那位自动退回「头像框 + 游戏小头像」，不会空。

## 五、按钮分状态命名（可选，画了更好看）

按钮槽位里，除了主文件，还可以多画三个状态图（在**同一目录**、**同名**加后缀）：

```
buttons/btn_primary.png            ← 常态（必须有这张）
buttons/btn_primary_hover.png      ← 鼠标悬停
buttons/btn_primary_pressed.png    ← 按下
buttons/btn_primary_disabled.png   ← 不可用
```

只画常态也行 —— 游戏自带的那套会自动用**明暗**来区分悬停 / 按下 / 禁用。
这套分状态只对**自己的图**生效（借游戏图的槽位只有一个状态）。

## 七、九宫格怎么切

标了「九宫格」的那几个（按钮、面板、标题条、剩牌条）是**拉伸用**的，
出图时把**四角画成固定大小、中间可拉伸**。代码里现在按边距 **12px（1920 基准）** 切，
四角别小于 40px（2 倍图上）以免拉糊。

