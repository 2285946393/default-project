# 烫金牌面 · 生成提示词

> **这一套是「第三档牌风」**，不是替换现有的。  
> 现在桌上有两档可以切：`经典斗地主`（手绘马克笔风）/ `尖塔牌面`（借游戏本体的卡）。  
> 这一套叫 **`烫金赌桌`**，专为德州扑克配的 —— 和那张圆桌、筹码、牌匾是**同一套味道**。
>
> 三档在**设置页的「牌面」下拉**里选，桌上也有个按钮**点一下换一档**。

---

## 0. 用法（先说这个）

**下面每一个 ` ``` ` 代码块都是完整的一整段 —— 复制整块、粘贴、出图。**  
**不用再拼任何东西**，风格、底色、禁止项全都写在里面了。

每段后面跟一个「**出图后必须确认**」清单，那是给你**验图**用的（不是提示词的一部分）。

### 0.1 要画多少

| 组 | 张数     | 内容                 | 落到哪                                              |
| - | ------ | ------------------ | ------------------------------------------------ |
| 一 | **1**  | 四个花色（一张横图，代码切 4 份） | `cards/gilded/suit_spade.png` 等 4 张              |
| 二 | **13** | 点数 2~10、J、Q、K、A    | `cards/gilded/pip_2.png` … `pip_A.png`           |
| 三 | **2**  | 牌面底（普通 / 高亮）       | `cards/gilded/card_face.png`、`card_face_sel.png` |
| 四 | **1**  | 牌背（**德州必需**，见下）    | `cards/gilded/card_back.png`                     |

**合计 17 张。**

**为什么牌背这次要单独画**：斗地主看不到别人的牌，牌背基本不露脸。  
**德州不一样 —— 对手的两张底牌从头到尾都盖着**，一桌最多 8 张牌背同时摆在屏幕上，  
它比牌面还显眼。所以这套必须有自己的牌背。

### 0.2 五条铁律

1. **同一条对话串里连着出** —— 这一套尤其重要，17 张必须像**同一个人画的一副牌**。  
   中途换了对话串，粗细、金色、笔锋就全跑了。
2. **先定比例，再描述内容。** 每段开头都写清了是方的还是 5:7 竖的，别让模型自己决定。
3. **颜色只写十六进制**（都写在提示词里了），不要自己改成「金色」「红色」这种词。
4. **不要透明背景，要平铺洋红 `#FF00FF`**，我这边本地脚本抠。**别写 transparent。**
5. **不要描述场景、分辨率、镜头** —— 这是素材图，不是插画。

### 0.3 和现有素材的关系

- **不动的**：`cards/pip_*.png` / `cards/suit_*.png` / `cards/card_face_std.png`（经典那套）、  
  `card_face_sel.png` / `card_frame_selected.png` / `card_slot_empty.png`。
- **新画的全在新目录** `assets/cards/gilded/` 下，一个文件都不覆盖。
- **尺寸**：牌面底 **512×716**，花色/点数各 **256×256 见方**（点数「10」可宽到 256×243）。  
  这些是**游戏里贴图用的框**，画满即可，代码会等比缩放。

# 第一梯队：花色（1 张合图，代码切 4 份）

## 1.1 四个花色　`cards/gilded/suit_sheet.png`

> 出**一张横图**，四个花色排成一行 —— 合着出**粗细和金色才是同一套**，  
> 分开出四张一定会有一个偏粗一个偏细。代码按列切开存成 4 个文件。

```
A wide landscape 4:1 game asset for a dark-fantasy card game: four playing-card suit symbols in a single evenly spaced horizontal row, all four exactly the same visual weight and the same height, with generous empty space between them.

From left to right:
1. SPADE — a bold solid near-black ink spade (#1A1418) with a fine antique-gold rim highlight tracing its silhouette and a few delicate engraved hatch lines inside suggesting old metalwork.
2. HEART — the same weight and construction, filled in oxblood red (#8E1F22) with the identical gold rim and engraving.
3. CLUB — the same weight and construction, filled in near-black ink with the identical gold rim and engraving.
4. DIAMOND — the same weight and construction, filled in oxblood red with the identical gold rim and engraving.

Each symbol is a clean, instantly recognisable, geometrically correct silhouette with sharp outlines, bold enough to stay perfectly readable when shrunk to 60 pixels tall. The gold rim catches the light along the upper-left of each shape. Nothing else in the image — no card, no numbers, no decoration.

STYLE. Gilded gaming-table fantasy art. Antique gold (#C9A227, highlights #E8C766, shadow #8A6A18), oxblood red (#8E1F22, shade #6E1418), near-black warm ink (#1A1418). Clean, crisp, sharp-edged, flat orthographic front view, no perspective, lit evenly from the front by a soft warm key light. Refined and slightly worn, like the equipment of a very old, very expensive gambling house.

BACKGROUND. The entire background is one perfectly flat, uniform, saturated magenta #FF00FF — no gradient, no noise, no texture, no shadow, no reflection. The four symbols never touch the image edge; leave at least 6% clear magenta margin on all sides.

DO NOT INCLUDE. No text, no letters, no numbers, no logos, no watermark, no signature. No frame, vignette or border around the outside of the image. No drop shadow, no glow bleeding outside the shapes, no background scene, no table, no hands, no perspective, no 3D rotation, no tilt. No extra objects, no fifth symbol.
```

**出图后必须确认**

- **四个都在一条水平线上**，没有谁高谁低（它爱把第二个抬高一点）。
- **粗细一致** —— 四个花色的笔画重量要像同一个模具压出来的。
- **只有四个**（它有时候会多画一个重复的）。
- 金色只是**一圈细边**，不是整个填成金色 —— 填金就变成「金色花色」，和牌面对不上。

> 拿到图先看中心：**中心必须是干净的米白，什么都没有。**

# 5. 出图顺序建议

**同一条对话串里连着出，顺序按"先定调子"来：**

1. **先出 1.1 花色合图** —— 它定这一套的**金色和笔画重量**，后面 13 个点数都跟它走。
2. 然后 **2.1~~2.9（2~~9）连着出**，一口气出完，别插别的。
3. 再出 **2.10~2.12（J/Q/K）** —— 这三张有纹章，一起出好统一纹章的粗细。
4. **2.13（A）** 单独出（它最干净，别跟带纹章的混着出）。
5. **3.1 牌面底 → 3.2 高亮牌面底**，**紧挨着出**，这样两张的金线位置最容易对上。
6. **4.1 牌背最后出** —— 它是唯一一张满铺图案的，放最后不会影响前面的判断。

# 6. 做完之后（怎么进游戏）

1. **出图丢到** `Default Project\assets\烫金牌面\`（目录已经建好了，里面有个 `放这里.txt`）。  
   **建议直接按目标文件名存**（`suit_sheet.png` / `pip_A.png` / `card_back.png` …）——  
   生成器默认给的是哈希名，认起来费劲。懒得起名也行，丢进来跟我说一声，我认一遍。
2. **抠图**：在这个工程根目录跑
   ```bash
   python tools/poker-assets.py --set gilded
   ```
   脚本里**已经加好这套的 17 条任务**（花色合图会自动按列切成 4 张）。  
   **牌面底和牌背也要抠** —— 它们同样是洋红底。  
   跑完出一张体检图 `assets/_入库预览/入库预览-gilded.png`  
   （**左深绿 / 右浅灰**，两种底都不该有描边）。
3. 产出落到 **`assets/cards/gilded/`**：
   ```
   cards/gilded/suit_spade.png   suit_heart.png   suit_club.png   suit_diamond.png
   cards/gilded/pip_2.png … pip_10.png  pip_J.png  pip_Q.png  pip_K.png  pip_A.png
   cards/gilded/card_face.png    card_face_sel.png    card_back.png
   ```
   **一共 20 个文件**（花色 4 + 点数 13 + 牌面 2 + 牌背 1）。  
   **一个现有文件都不覆盖** —— 经典那套、尖塔那套原样不动。
4. 编译一次：`bash ../dou-spire-rules/tools/build-mod.sh .`
5. 游戏里 **F9 收桌再开桌**，或者**直接点桌上那个牌面按钮**换档 —— **不用重启游戏。**

**加载顺序**（和现有素材一致）：**自己的图 → 游戏自带的图 → 纯色兜底**。
