## 二、游戏里根本没有的四样

翻遍 pck 确认过，这几样**游戏本体一张都没有**，所以只能自己画：

| 缺的东西 | 最接近的替代品（找手感用） | 为什么没有 |
|---|---|---|
| **圆桌 / 俯视桌面** | `images/packed/combat_ui/combat_nameplate_background`、`map_bgs/map_middle_*` | 游戏是横版闯关，没有俯视桌面这个视角 |
| **星盘 / 罗盘** | `images/atlases/relic_atlas.png` 里的环形徽记 | 同上 |
| **皇冠** | `ui_atlas.sprites/card/energy_star`、`sprite_fonts/star_icon` | 游戏的"君主"概念用王座和悬浮剑表达，没有皇冠图形 |
| **扑克花色 ♠♥♣♦** | `images/atlases/card_atlas_*.png` | 游戏是构筑卡牌，不用扑克牌面 |
| **大小王牌面** | `card_frame_ancient_s`（古神牌框） | 同上 |

所以 `素材清单.md` 里标 🔴 的 8 项，**五项是因为游戏没有，三项是因为风格不对**。

## 三、座位立绘怎么参考

库里角色相关有三种东西，**用途完全不同，别搞混**：

**① `images/packed/character_select/char_select_<角色>.png`（132×195）—— 最有用**
选人界面的**半身胸像**，五个角色各一张，干净的正面胸像，带描边带高光。
**要画"坐在桌边的半身像"，直接照这个的构图和上色，补下半身就行。**
五人：`ironclad` / `silent` / `defect` / `necrobinder` / `regent`

**② `images/ui/top_panel/character_icon_<角色>.png`（88×88）+ `_outline` —— 小的**
顶栏圆头像。**没画立绘时的兜底**就是它，所以现在界面不会空。

**③ `animations/rest_site/<角色>/restsite_<角色>.png`、`animations/character_select/<角色>/characterselect_<角色>.png` —— Spine 拆件表**
这是游戏里**坐着的角色**的原始图集，但**被拆成了一块块身体零件**，不是成品图。价值是两点：
- **配色**：整张表的色域就是这个角色的色域，取色直接抄。
- **画法**：每张表里都有一块**灰色炭笔涂抹的阴影**和一块**纯黑剪影**。
  游戏里的角色就是这么画的 —— 身后一层糊状阴影、身上一层纯黑轮廓，最后才贴彩色部件。
  **你的座位立绘也要这么分层**，不然贴到桌边会浮起来。

带 `_bg` 的是选人界面背景渐变（`silent` 绿、`necrobinder` 一张）。

## 五、注意

这些图**版权归 Mega Crit**。库的说明里有完整规则，这里只说一条最要紧的：

**在代码里 `res://` 引用 = 安全**（玩家跑的是他自己那份游戏，你没分发任何东西）；
**把图拷进 `assets/` 打进 mod 发布 = 分发，不能做。**

所以：能 `res://` 借的就借，缺的那 8 项自己画 / 自己生成。
