# 生成提示词 · GPT 图片版 v2（加长版）

> 这是 `素材清单.md` 里标 🔴 的 **8 项必须画的素材**的提示词。
>
> **v2 相对 v1 改了三件事**（都是照你说的改的）：
>
> 1. **每条提示词大幅加长** —— v1 太短，AI 会自己脑补；这一版把材质、形貌、光照、构图、负面项全部写死。
> 2. **圆桌加了"联动分区"** —— 桌面上不再只是一块空台呢，而是刻好一块块**留给代码往上叠东西的凹槽/刻线**（出牌区、底牌位、牌堆位、三张座位牌、倍数牌匾、勋章座、回合箭头…）。对照表见 **§4**。
> 3. **五张立绘改了写法** —— 先**锁死官方半身像当参考图**，再把形貌描述写成"照着参考图校对"的样子。铁甲战士 v1 出成了生锈发绿的兽人骑士，**不像**，v2 明确写成"**干净的浅暖赭铁，不要锈、不要苔藓、不要绿**"，并写清角的走向和 V 形眼缝。
>
> 写法仍然是**专门为 GPT 图片（ChatGPT 4o 图像 / gpt-image-1）调的** ——>   
> 一整段像跟画师交代需求的英文简报，**可以直接整段复制粘贴**，不要再拆成关键词。

## 0. 五条铁律（不长，但每条都踩过坑）

### ① 一整套图在**同一条对话串**里连着出，而且**每次都附同一张参考图**

GPT 图片会在同一个对话窗口里延续前面的风格。**开一个新对话，第一条跑圆桌，然后别关，接着跑皇冠、勋章、卡框……** 风格会自己收敛。每张图新开一个对话 = 五张立绘像五个游戏。

每条都附上同一张参考图 —— **`projects/sts2-asset-library/风格基准/00_风格基准图.png`**（色板 + 五个样件的板子）。**有参考图比改十句文字都有效**：描边粗细、上光方向、饱和度上限它会直接抄。

画立绘时**再额外附上**官方半身像 **`images/packed/character_select/char_select_<角色>.png`**，并在提示词里明确写"照着这张参考图的轮廓、配色和比例来"。这一条是解决"不像"的关键。

### ② 比例写在**最前面**

所以每条第一句都是 `A wide 16:9 game asset: …` / `A square 1:1 game asset: …` / `A portrait 4:5 game asset: …`。生成时在界面里选对应尺寸（每项都写了选哪个）。

### ③ 颜色写 **hex 色号**，别写颜色名

「深桃木色」它每次都理解得不一样，`#5A4230` 每次都一样。下面已经把整套配色 hex 化，**不要改成 "dark brown" 这种**。

### ④ 别要透明底 —— **要"纯色抠图底"，自己抠**（实测结论）

实测这个通道**不产出真 alpha**，生成出来是 **RGB（`color_type=2`）**，根本没有 alpha：

| 你怎么要                           | 实际拿到                       |
| ------------------------------ | -------------------------- |
| 提示词里写 `transparent background` | **烤进像素的棋盘格** —— 是真的像素，不是透明 |
| 用生成接口的透明底开关                    | 依然是 **RGB 无 alpha**        |

自己验一下（`sts2-asset-library/tools/check_alpha.py`）：

```bash
python tools/check_alpha.py 02_皇冠_示例.png
#   bpp=3 (RGB 无 alpha)      ← 没有 alpha 通道
#   顶边独立颜色数 = 87       ← >50 就是画上去的棋盘格
```

**所以正确做法：让它画在纯色底上，然后本地抠掉。** 每条的 `<KEY>` 位置拼上 §2 的 `<KEY>` 段。

**为什么用品红 `#FF00FF`**：它不在我们的调色板里（旧铜 / 暗红 / 深青 / 胡桃褐 / 骨白 / 熔金），抠的时候**不会误伤主体**。

⚠️ **主体是白的绝对不能拿白当底** —— Silent 的骨面具、Necrobinder 的骷髅、小王（纯骨白+银）都属于这一类，**必须用品红**。

抠图（零依赖，不需要 PS / PIL）：

```bash
python tools/keyout.py 生成图.png --trim
#   生成图.png -> 生成图_keyed.png   底色=(175,31,99)   不透明像素 51%
```

- 底色**自动从四角估计**：生成图的品红不是纯 `255,0,255`，实测约 `181,29,102`，**必须给容差**
- `--tol` / `--soft` 控制容差和软边过渡带（默认 55 / 105），边缘不干净就调
- `--trim` 裁掉四周透明边；水印压到主体上的先 `--wipe` 或 `--crop`
- 抠完**在深色底上叠一下**再放进游戏 —— 白边在深色桌面上最显眼

### ⑤ 别在提示词里描述场景、别写分辨率

- 写「在黑暗森林里」→ 它就会给你画一片森林，纯色底直接废掉。
- 写「512×512」→ 它会给你画"假的低分辨率像素感"。**全尺寸出图，事后再缩。**

## 1. 三个公共段落（每条末尾都拼上，顺序别换）

### `<STYLE>` —— 风格母版

```
Art direction: a crisp hand-drawn 2D game asset for a dark-fantasy deckbuilder, in the
style of a high-quality indie card game. Clean, confident shapes built from a few large
readable masses, each with a bold, deliberately drawn dark outline (near-black #1A1512)
of even, controlled weight running all the way around the silhouette. Flat-to-semi-flat
cel shading with a single hard terminator line dividing lit from unlit areas — no soft
gradients inside a form, no ambient occlusion smudging, no rendered bounce light. Surface
texture is minimal and suggested with a few deliberate marks only; there are no visible
brush strokes, no canvas weave, no speckle, no noise. It must look deliberately
illustrated — not painterly, not airbrushed, not photorealistic, not 3D, not a
photograph, and not clean flat vector either; the ink line is what gives it its
character. Palette, used strictly: aged brass #B08D57 with highlight #E8CF9A and shadow
#6B4E2E; oxblood #6E1F1F deepening to #4A1414; deep teal #14494E; dark walnut #3A2A1E and
#5A4230; bone white #E8E2D4; molten gold accent #F2C453; near-black ink #1A1512. Keep a
strong separation between light, mid and dark values so that the silhouette still reads
instantly when the image is scaled down to a very small icon. A single warm key light
comes from the upper left, so every upper-left facing surface is lit, the lower-right
sides fall into shadow, and each form carries one bright rim on its lit edge. Tone:
playful, slightly uncanny and charming — never grim, never gory, never bloody, never
scary for its own sake. Present one single subject, centred in the frame, with nothing
else in the image.
```

### `<KEY>` —— 纯色抠图底

```
The background is a single flat uniform pure magenta #FF00FF covering everything around
the subject — completely even, with no gradient, no vignette, no shadow cast onto it, no
texture, no grain and no other element. The magenta colour appears nowhere on the subject
itself. Show only the subject, with nothing behind it: no scene, no environment, no
floor, no wall, no sky, no horizon, no reflection, no glow and no light spilling onto the
background, and no border or frame around the image. Leave a small margin of flat magenta
around the subject so that nothing touches the edges of the frame.
```

### `<AVOID>` —— 负面清单

```
Avoid: any text, letters, numbers, runes, captions, labels, signature, watermark or logo
anywhere in the image, including anything written or engraved on the object itself; a
filled white, grey, black or coloured background other than the flat magenta; multiple or
repeated copies of the subject; mirrors or reflections of the subject; photographic
realism, 3D rendering, oil-paint or canvas texture, airbrush softness, motion blur, depth
of field, film grain, noise or jpeg artifacts; harsh or long cast shadows; the subject
being cropped by, or touching, the edge of the frame; a visible border, vignette or
frame around the whole image.
```

GEOMETRY.

## 5. 出图后怎么落地

1. **抠底**（本地脚本，零依赖，不需要 PS / PIL）：
   ```bash
   cd projects/sts2-asset-library
   python tools/keyout.py "生成图.png" --trim                 # 单张
   python tools/keyout.py "生成图目录/" -o "抠好/"             # 整批
   ```
   底色自动从四角估；边缘不干净就调 `--tol` / `--soft`；**水印压到主体上**的图先 `--crop` 再抠。
2. **修毛刺** —— 白边在深色桌面上特别明显。抠完**一定要在深色底上叠一下**看边。
3. **验一下有没有真 alpha**（别信预览）：
   ```bash
   python tools/check_alpha.py "抠好的图.png"
   #   bpp=4 (有 alpha)   alpha 取值数=157  最小=0  最大=255     ← 这才对
   ```
4. **缩放到清单里的尺寸**；九宫格那几项**再确认一次中间是平的**。
5. **按清单里的文件名改名**（代码写死名字取图，**改错名等于没放**）。
6. 丢进 `projects/dou-spire/assets/<子目录>/`。
7. 编译：`cd projects/dou-spire-rules && bash tools/build-mod.sh ../dou-spire`     
   （⚠️ 游戏开着会拷不进去，见下面的注）
8. 游戏里 **F9 收桌 → 再按 F9 开桌**（不用重启游戏）。
9. 开桌日志会打「**斗地主素材：用自己的 N 个…**」—— 数一数 N 有没有涨。

> **注**：编译最后一步要把 dll 拷进 `mods\DouSpire\`，**游戏运行时 dll 被锁住会失败**。>   
> 只是换图的话不用管这个 —— 直接往 **`mods\DouSpire\assets\`** 里丢图，F9 就能看到，一行命令都不用敲。

> **先对着 `projects/sts2-asset-library/风格基准/` 那几张看一眼**再动手 ——>   
> 特别是 `00_风格基准图.png`，把它当参考图附进每一次生成，风格会自己收敛。
