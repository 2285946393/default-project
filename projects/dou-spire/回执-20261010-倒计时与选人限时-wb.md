## 一、出牌倒计时环（每人 20 秒，可见）

### 为什么没有去魔搭出图
用户说"没有素材就去魔搭画"，但**这一件真的不需要素材**：

1. 环要**跟着剩余秒数实时收短** —— 贴图做不到（除非做几十张序列帧，还对不上秒）；
2. 配色要跟着 `DouSpireUi.Gold`（UI 主题）走 —— 出成贴图后换主题就得重画；
3. 矢量画**任意分辨率都不糊**，出图反而会糊。

所以用 `_Draw` 现画，一行素材依赖都没有。

### 新文件 `DouSpireCode/Table/DouSpireTurnTimer.cs`
一枚套在**当前出牌那家 HUD 头像外圈**的环。

| 状态 | 长什么样 |
| --- | --- |
| 真人（我 / 联机队友） | 金环从正上方顺时针收短 + 右下 45° 一枚圆形徽章写剩余秒数；弧头有颗小亮点 |
| 告急（≤5 秒） | 环转红 + 外面套一圈**呼吸**红光（7 Hz 正弦） |
| 电脑那一家 | 暗环 + 一小段**慢慢转**的弧，**不读秒**（电脑 1.5 秒就出牌，读 20 秒是骗人的） |
| 其余时候 | 全收起来（选人 / 明牌 / 抢地主 / 加倍 / 扣牌 / 结算） |

尺寸（都在 `DouSpireUi.Px` 里，换分辨率不跑位）：
控件 **108×108** @ 偏移 `(0, 6)` → 环心正好落在头像中心 `(54, 60)`；
半径 = 控件短边 × **0.415**；徽章半径 15。

### 驱动：`DouSpireTable.SyncTurnTimer()`
挂在 `_Process` 里 `TickTurnMark(delta)` 之后。判定"该不该亮"：

```
!_broken && _roundStarted && _game.Winner is null
&& !_askingShow && !_askingDouble && !_bidding && !_discarding
&& 0 <= _game.Current < SeatCount
```

⚠️ **只在"换人"那一帧 Arm**（靠 `_timerSeat` 记着上一帧是谁）。
每帧 Arm 一次 = 秒数永远停在满格 —— 这个坑很容易踩，注释里写死了。

### 顺带修的一处不一致
远程真人的出牌宽限从 `TurnTimeLimit + 10` 收到 **`+ 2`**。
原来屏幕上环读到 0 之后还要干等 10 秒才被主机接管，看着像卡住。
（留 2 秒只是给网络往返兜底。`StatusText()` 里那行"还有几秒"同步改了。）

## 二、选人阶段限时

原来**已经有**超时兜底（`TickPickWait`：主机等不到人点「开始打牌」就自己开局），
上限是 `TurnTimeLimit + 20` = 40 秒，但**屏幕上没有任何提示** —— 干等 40 秒像卡死。

改了两点：

1. **上限收到 `TurnTimeLimit`**（默认 20 秒）—— 用户要的就是"选人也要限制时间"，
   和「出牌时间上限」共用同一个设置滑条，不用再多记一个数字。
   设 0（不限时）时退回 60 秒兜底 —— 绝不能因为一个人不点就把全桌永久卡住。
2. **加了一行倒计时**（选人面板里 `_pickCountdown`）：
   `还差 N 个人没点「开始打牌」· X 秒后自动开始`

客机新增 `TickPickCountdown` —— **只读数、不裁定**（真正"到点自动开局"只有主机干，
客机自己开局 = 两端各开各的，必炸）。

## 三、电脑那一行也能选角

原来 `PickArrow` 一刀切：联机时 `seat != MeSeat` 直接 return，箭头也只在"自己那一行"显示。
用户要的是：**真人席仍然只能自己选，但电脑席应该谁都能替它挑。**

### 界面
- `ApplyPickerSize`：`mine = !_netOn || s == MeSeat || (那一席不是真人)` → 电脑席亮箭头；
- `RefreshPicker`：电脑席那一列文案改成 **「电脑 · 可换」**（不点出来没人知道能点）。

### 网络（`DouSpireNet.cs`）
新增 `InPickSetAi = 14`（客机 → 主机：`U8 全局座位 + I32 池子下标`）
+ `SendPickSetAi` / `PickSetAi` / `HostPickSetAi`，收信口加了对应 case。

**主机侧 `HostPickSetAi` 必须校验三件事**（这三条是这条通路的安全底线）：

1. 座位号在 `[0, Seats)` 内；
2. **`!IsHumanSeat(globalSeat)`** —— 座位号是客机报上来的，不校验的话任何一个客机
   都能把队友的角色改掉（那就不是"帮电脑选"，是"抢队友的角色"了）；
3. 池子下标合法。

过了才 `SetCharIndex` + `CastPickSet` + `Live.NetPickSet`（和原有的 `PickSet` 同一套落地方式）。
