## 二、「鸡煲代打」三个模式现在长什么样

### 斗地主（本来就有，这轮没动）
`_autoPilot`（**static**，收桌重开不忘）+ 按钮切文案 + `TickAutoPilot()` 替答问话阶段
（明牌 / 抢地主 / 猜拳 / 加倍）+ 主循环和 `StepDiscard` 两处放行给 `StepAi`。

### 德州扑克（本轮新加）
- 字段：`private static bool _autoPilot;` + `private Button _autoBtn;`
- 按钮进操作行（`_actions`），文案 `鸡煲代打` ⇄ `✓ 鸡煲代打中`
- 主循环 `_Process` 里新开一支，**排在"不是我的回合"那支前面**：

  ```
  if (!HandOver && isMine && _autoPilot)  → 每 AiDelay 秒走一次 AutoMove()
  else if (!HandOver && !isMine)          → 原来的电脑 / 远端真人分支，一行没动
  else                                    → _remoteWait = 0（原样）
  ```

- `AutoMove()` = `PokerAi.Choose(当前性格)` → 不合法就 `SafeFallback()` → **`MyMove()`**。
  ★ 走 `MyMove` 而不是 `AiStep`，因为 `MyMove` 内部已经把
  「主机本地落地 + 广播」和「客机只发给主机」两条路分好了 ——
  代打在联机桌当客机时不会像 `AiStep` 那样本地乱推。
- 按钮**整手都露着**（不是我的回合也看得见），可以提前开着托管下一手。
- 操作行宽度 `900 → 1020`（多了一颗按钮，最宽的一帧会顶出去）。

### 21 点（本轮新加）
- 字段同上；按钮进底部那排动作按钮（跟 要牌/停牌 同一套底图）。
- `_Process` 两处新支：
  1. **下注阶段**自动按「发牌」（`OnDeal()`）—— 不然每局还得手动点一下，代打就断了；
     这一支放在 `_game is null` 兜底**之前**（第一局开桌时 `_game` 还是 null）。
  2. **打牌阶段**轮到我时调 `AiAct(MySeat)` —— 复用电脑席那套 `BlackjackAi.Decide`
     （基本策略：要牌 / 停牌 / 加倍 / 分牌），节奏也是同一个 `AiThinkSeconds = 0.9s`。
- 按钮**两个阶段都露着**，随时能收回托管。

> ⚠️ 三个模式的开关是**各自独立**的（各存各的 static），不是全局一个。
> 想"全都托管"就三个模式各点一次；想全手动就再各点一次。

## 三、语音「概率触发」怎么改的

### 不是回到老路
2026-10-08 晚你要求把**按秒数节流**那套频率阀门整个撤掉（"我没让你们加频率阀门啊"），
之后是"每次事件都开口"、句句都响。响了一个多月，你觉得太密太尬。

**这轮没有把按秒节流加回来** —— 那个当年的玩家体感是"出牌没声音"，被骂过。
改成**按台词要紧程度掷骰子**：

| 档 | 哪些台词 | 默认概率 |
|---|---|---|
| **碎嘴** `Chatter` | 出一张小牌 / 对子 / 要不起 / 压别人一手（一局重复几十次的那几句） | **35%** |
| **普通** `Normal` | 三带 / 顺子 / 连对 / 飞机 / 四带二 / 轮到我 / 点提示 | **60%** |
| **关键** `Important` | 炸弹 / 王炸 / 报单 / 胜负 / 抢地主 / 发牌 | **100%**（照旧必说） |

### 代码位置
`DouSpireVoice.Say()` 现在是这样：

```
① 概率闸门 RollAdmit(priority)  ← 新加，这一句这次要不要说
② Pick(file, seat)              ← 挑文件（多版本随机轮播，原样）
③ Admit(seat)                   ← 取本席的播放器（原样）
④ 放
```

`RollAdmit()` 三条判断：`>=100%` 直接放（省一次随机）、`<=0%` 直接吞、中间掷骰子。
**只影响"说不说"，不影响"说哪句"** —— 放行之后的选文件还是老逻辑。

### 三条滑条（设置页）
- `DOUSPIRE-VOICE_CHANCE_CHATTER.title` —— 语音概率：碎嘴（出小牌 / 要不起）
- `DOUSPIRE-VOICE_CHANCE_NORMAL.title` —— 语音概率：普通（顺子三带 / 轮到我）
- `DOUSPIRE-VOICE_CHANCE_IMPORTANT.title` —— 语音概率：关键（炸弹 / 报单 / 胜负）

**想全开就把三条都拉 100%，想彻底清净就都拉 0%。** 中英文文案都注进 `settings_ui` 了。

### 覆盖面
斗地主、德州、21 点三张桌的**所有**语音包（鲸鱼娘 / 八千代 / 橘雪莉 / 椿 /
本体四角色 / 储君借包）都走同一个 `Say()`，所以**一次改完全都生效**。

## 五、怎么验

### 语音概率（最好验）
1. 游戏里进任意一张桌（斗地主最快 —— 一局能出几十张牌）
2. 听：出小牌 / 要不起 应该**明显变少**（默认 35%）；炸弹 / 赢 / 输 **照旧每次都响**
3. 设置 → 模组配置 → 把「语音概率：碎嘴」拉到 0% → 再打一局，那几句应该**一声不吭**
4. 拉回 100% → 恢复"句句都响"的老样子

### 德州代打
1. 进德州桌 → 点「鸡煲代打」（按钮上变 `✓ 鸡煲代打中`）
2. 轮到你时应该**不用点任何按钮**，AI 自己弃/跟/加/全下
3. 点一下收回 → 立刻变回手动

### 21 点代打
1. 进 21 点桌 → 点「鸡煲代打」（按钮上变 `✓ 代打中`）
2. 下注阶段应该**自动按发牌**，然后自动要牌/停牌，一局接一局
3. 点一下收回 → 变回手动

> ⚠️ **测之前先确认你开的是哪一份 mod**：本机同时存在
> `mods/DouSpireDev`（开发版，刚编的这份）和工坊订阅的 `DouSpire`（线上 0.2.42）。
> 两个都启用会**各加一份入口**。要测这份新代码：
> 模组列表里**停用工坊那个 `DouSpire`、启用 `DouSpireDev`，然后重启游戏**。
