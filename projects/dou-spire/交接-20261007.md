## 二、这一版做了什么

### 1. 编外角色系统（全新的东西）

原来桌上只有**游戏本体的五个职业**（铁甲战士 / 沉默猎手 / 故障机器人 / 摄政王 / 亡灵束缚者）。
这一版加了一类**「编外角色」** —— 不是游戏角色，只有立绘 + 名字 + 待机动画 + 表情。

**代码入口**：`DouSpireCode/Table/DouSpireCharacters.cs`

```csharp
// 加新角色 = 往这里加一行
public static readonly Guest[] Guests =
{
    new("whale", "DS鲸鱼娘", "#5B7FBF", 96),
    new("chun", "椿", "#C0554E", 96),
    new("yuki", "八千代辉夜姬", "#4FBFB0", 96),
    new("sherry", "雪莉", "#4A7BC8", 96),
};
```

**关键类型**：`SeatPick(Model, GuestId)` —— 把「游戏角色」和「编外角色」统一成一种东西，
桌边三席走同一套代码。**调用处的 `Name` / `ColorOf` / `SeatArt` / `Icon` 有 `SeatPick` 重载**，
所以从 `CharacterModel?` 换成 `SeatPick` 时改动很小。

**素材结构**（每个编外角色一个目录，`assets/<id>/`）：

```
<id>/base.png              常态立绘（兜底）
<id>/idle/fNN.png          待机循环（96 帧 @24fps）
<id>/face/<名字>.png       静态表情
<id>/faceanim/<表情>/fNN.png   「会动的表情」（12 帧）
~~seats/char_<id>.png        座位立绘~~
~~seats/icon_<id>.png        选人头像~~
> ❌ **2026-10-11 这 13 张已按用户要求全部删除** —— 本体角色走游戏活模型、
> 四位客人走待机动画。详见 `assets/素材清单.md` 第四节。
```

### 2. 立绘是**渲染**出来的，不是画的

四个角色的素材全部来自 **Live2D 模型**，用一套自建管线渲染成 PNG：

**`D:\software\live2d-render\`** —— Chrome headless + pixi-live2d + Cubism core。
三种模式：静态立绘 / 模型自带 motion 逐帧 / **表情+呼吸叠加**（"会动的表情"）。
脚本：`prepare_model.py`、`render_char.sh`、`render_faceanim.sh`。

**素材来源与授权**：见 `notes/斗地主尖塔-角色与素材出处.md`（上工坊前必看）。

### 3. 语音：四套，全是用户自己生成的

| 角色 | 素材目录 | 语言 |
|---|---|---|
| 鲸鱼娘 | `assets/voice/whale/` | 中文（可莉音色） |
| 椿 | `assets/voice/chun/` | 中文（御姐） |
| 八千代 | `assets/voice/yuki/` | 日语 |
| 橘雪莉 | `assets/voice/sherry/` | 日语 |

**代码入口**：`DouSpireVoice.cs`。文件名约定 `<编号>_<事件>_<第几句>.ogg`
（鲸鱼娘/椿带 `_1` 后缀，八千代/雪莉没有 —— **加角色时注意**）。

**每席一个 `AudioStreamPlayer`**（不是共用一个），所以三家同时说话不会互相掐。
自己那席满音量、对手按 `DouSpireConfig.OpponentVoiceScale`（默认 0.75）压低。

**台词稿**：`notes/斗地主尖塔-<角色>台词.md`。

### 4. 明牌 / 加倍 / 筹码

**流程**：`发牌 → 明牌? → 抢地主 → 加倍? → 开打`

- **明牌**：`BeginShowCards()`，选了底注 ×2
- **抢地主**：`BeginBidding()`，最长四次（1要2抢3抢1再抢），**连续两家不抢提前收摊**
- **加倍**：`BeginDouble()`，AI 按 `_bidScore >= 12` 自动决定
- **筹码**：`_money[3]`，开局各 1000，`PayOut()` 按「地主一人对两个农民」结算
- **倍数**：`_multiplier`，明牌/加倍/炸弹都会 ×2，顶部常驻显示，翻倍时中央弹大字

### 5. 音效

`DouSpireSfx.cs`。事件名是从 `sts2.dll` 里扫出来的（完整 364 条见
`notes/杀戮尖塔2-音效事件全表.md`）。

**新加的原版音效**：超能光束（炸弹）、雷击（王炸）、主权之刃（当地主）、
三档金币 + 开宝箱（赢）、清场声（输）、攒能量（报单）。

**同时拆掉了三处"音效叠在一起"**（发牌 / 开局 / 抢地主）—— 以前一次响两三个，糊成一团。

### 6. 特效（**没做完，见待办**）

  **不知道能不能显示**（那些场景是给战斗的 Node2D 用的，塞到 UI 层不一定渲染）
- ❌ **闪屏**：做过一版纯色闪屏，**用户明确否决**（"啥用没有，还影响观感"），已撤

## 三、怎么改 / 怎么编译

```bash
cd "C:/Users/有花无实/Documents/Default Project/projects/dou-spire-rules"
bash tools/build-mod.sh ../dou-spire        # 只编译
```

**⚠️ 必须带代理**（nuget 要连网，直连有时也通、有时不通）：

```bash
export HTTP_PROXY=http://127.0.0.1:7892 HTTPS_PROXY=http://127.0.0.1:7892
```

编译后 **csproj 的 `CopyMod` / `CopyAssets` 会自动把 dll 和 `assets\` 拷到游戏目录**
（`local.props` 里的 `Sts2Dir`）。

**游戏目录里有个"启动快照"**：`.combatsolver-precombat/process-*/startup-mods/` ——
游戏每次启动会把 mod 复制过去。**改了 dll 必须重启游戏**（光收开桌不够）。

## 四、踩坑（这一天踩的）

1. **挑错动作文件**：Live2D 模型根目录的 `aidale.motion3.json` 看着像待机，
   实际是"抡大锤"的动作。真待机在 `motions/idle.motion3.json`（**看曲线条数**）。
2. **页面 JS 报错 → 截图是 2KB 空图**（用了没定义的变量）。
3. **`dotnet build` 平时不用网，触发还原就要 nuget** → 必须挂代理。
4. **Chrome headless 截图的 `--screenshot` 用相对路径 → 一个文件都不出**。
5. **bash 读 Windows 生成的清单，行尾带 `\r`** → 文件名非法（用 python 写文件要 `newline=''`）。
6. **`xargs` 遇空格会拆错参数**（`Slay the Spire 2`）—— 用 python 列目录才准。
7. **中文 zip 解压：文件名修了编码、顶层目录名漏修** → 目录名乱码。
8. **游戏自带日志找不到**（`godot.log` 停在旧日期）→ 自己在 `mods\DouSpire\voice-log.txt` 记。
