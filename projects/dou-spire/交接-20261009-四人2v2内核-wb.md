## 二、内核规则（2v2 口径，全在 dou-spire-rules）

| 项 | 规则 |
|---|---|
| 牌 | 两副牌**去掉 3、4、5** → 84 张（`Deck.Build(2, strip345: true)`） |
| 发牌 | 每人 20 张，剩 4 张作**暗底**（没人拿，`g.Bottom`） |
| 组队 | **对家组队**：座位 0+2 一队（Team 0）、1+3 一队（Team 1），`PlayerState.Team` |
| 地主 | **没有地主**；随机（或指定 `firstSeat`）一家先出，他所在队先手 |
| 扣牌 | **后手队每家开局扣 1 张**（摊开进 `g.DiscardPile`）；`g.PendingDiscards` 列出待扣座位，逐家 `g.TryDiscard(seat, card)`；**没扣完 TryPlay/TryPass 直接报错** |
| 王炸 | **3 张王就是王炸，4 张王更大**（`ComboJudge(2, rocketJokers: 3)`）；两张王只是对子 |
| 炸弹 | 同点 ≥4 张，**先比张数再比点数**（最高 8 张同点）；已被独立实现印证 |
| 胜负 | **队里任何人先出完，全队赢**：`g.Winner` = 先走完的座位，`g.WinningTeam` = 他那队 |
| 结算 | （桌面层还没接）赢家队每人 +1×、输家队每人 −1×（零和） |

**3 人老玩法一个字没变**：54 张、17/17/17+3 底、地主 ±2×；`Team` 在 3 人里=地主 0/农民 1，
`SameSideAs` 从"比 IsLandlord"改成"比 Team"，3 人语义完全等价（有自测盯着）。

## 六、坑与注意

- **`SameSideAs` 现在按 Team 比**：mod 里如果有地方自己 new PlayerState 而不设 Team，
  全都会默认同队（Team=0）—— 联机代码要检查（今晚编译过了，语义要人肉过一遍）。
- `ComboJudge(2)` **老口径仍然存在**（4 王才炸），只有 `rocketJokers: 3` 才是 2v2；
  NewGame(…playerCount: 4) 会自动选对，别在桌面上自己 new 一个。
- 扣牌是**必须步骤**：跳过它会 TryPlay 报"还有玩家没扣完底牌"——
  桌面层千万别把 PendingDiscards 忘了。
- layout.txt 是 3/4 人**共用**一份：行号按位置固定（0=我 1=右 2=左 3=上），
  4 人模式座位→行映射 {0,1,3,2}，别改回"座位号=行号"。
- DouZero 只有 3 人模型，4 人 AI 继续走 RuleAi（设计稿第六节）。
