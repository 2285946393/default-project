## 怎么用这张表

- 想做什么效果 → 搜关键词（`slash` / `fire` / `smoke` / `distortion` / `ring` / `spine` …）
- 找到中意的 → 打开对应 `.tscn`，抄节点树 / 参数；**运行时也可以直接引用本体路径**（纹理不用抽，pck 里有）
- 三层链：**场景 .tscn → 材质 .tres → 着色器 .gdshader**，看效果时三层都要翻
